# 草原样区花带与蝴蝶

接续 [空间群落](GrasslandSpatial.md) 与 [灌木风动](GrasslandShrubWind.md)，只将当前样区的三片花带接入已有访花生态。其他群系继续保持原美术。

## 资源与显式入口

执行 **Magic Island > Art > Link Grassland Flower Visit Sample (Explicit)**。在原 `IslandTerrain` 的 `WorldWaterEcology` 内烘焙三条 `MeadowFlowerVisit`：原花草 Renderer、真实花粉顶点索引及已有蝴蝶槽位。花位不另存一份坐标，绑定时从实际 AA 网格读取。每片花带安排一只现有蝴蝶，三处间距超过八米；原蝴蝶总数量、其他个体、萤火虫与小兔保持。

只选择样区中仍被三角面引用、具有花种 UV、暖色花粉及向上法线的小花；避开主路，沿三片已有群落选择落点。保留所有植物、地面、道路和昆虫顶点、法线、颜色、UV、面、GUID、材质及对象数量。原昆虫合并网格只在需要时扩大 bounds，包含迁入个体完整的访花、体型及受惊范围。

`FlowerVisitVersion=0` 表示原生态，`1` 表示完成；写入前先完整预检与备份，先持久化 `-1` 进行中状态，最后保存三条关联及完成版本。异常恢复原文件。中断、重复槽、无效／已删除顶点、自定义来源／变换或不完整状态拒绝覆盖；重复入口与普通 Setup 保留已完成关联和后续合法手调。不要删除版本来强制覆盖。

## 表现与拥有者

复用 `MeadowInsectMotion` 的固定 32 槽数组、错峰访花周期、短途飞行、局部受惊和逐渐返回。迁入个体的活动中心跟随所属小花，其余槽位保留原栖息位置。没有新增昆虫对象、Renderer、碰撞、Update、Manager、材质实例或玩法随机数。

原 `WorldWaterEcology` 在 Bind 时读取关联，Tick 使用原 OceanSurface 时钟；零秒不推进受惊，暂停／室内冻结，昼夜与雨天沿用已有活动量。Clear 恢复完整原 MaterialPropertyBlock 并丢弃会话数组，重绑不会继承上次惊扰。

花朵与停落蝴蝶共用 `MeadowFlowerWind.cginc` 的花茎风动和原 `MeadowTouch` 函数。蝴蝶保持花粉顶点上方 0.025 米的间隙，使用原根、权重、相位、拨草场与风场，避免独立近似导致脱离。原建设遮盖拥有者仍唯一写入花草属性块；昆虫只读取结果，覆盖整株花时隐藏对应蝴蝶，回收后恢复。渲染前沿已有 OceanManager 相机回调再同步一次拨草／遮盖，避免两个 Update 先后顺序导致一帧误差，不推进动画或玩法。

没有新增配置、AA 地址或进度字段，存档仍为 v31；访花、惊扰和停落不会写盘，唯一进度保存点仍为床边确认睡觉。

## 验证与使用

`GrasslandFlowerVisitVerification.BakeAndVerify` 在隔离工程检查真实花顶点、三片分布、原昆虫全频道和其他美术保护、非法关联与部分状态拒绝、重复和普通 Setup。`GrasslandFlowerVisitVerification.After` 接续现有草原 Packed AA 与五岛流程；新增实际花位、局部避让／回归、暂停／室内／雨天、建设遮盖／回收／重绑、完整裁剪范围、共享材质／随机数、属性块清理及无白天保存检查，录制实际相机画面。

更新正式项目后执行 **Magic Island > Build Prototype Addressables**。隔离工程、日志和演示保存在忽略的 `Logs/GrasslandFlowerVisits`，不提交。
