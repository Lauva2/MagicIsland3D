# 昼夜与天气

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

WeatherManager 控制当天晴雨、昼夜光照、雨滴表现和雨水浇灌；GameManager 统一初始化、读档、跨日和清理。ConfigurationManager 通过 AA 地址 `WeatherConfig` 加载 `Assets/Config/WeatherConfig.asset`，雨滴材质作为配置依赖随 AA 加载。季节与降雨概率由 AA 配置 `SeasonConfig` 和 CalendarManager 提供。

## 每日天气与农田

新游戏第一天固定晴天。每次睡觉或点击调试“下一天”，先按当天浇水状态结算作物，再按目标日期的季节推进天气，回到 06:00 并睡觉时统一保存。默认春／夏／秋／冬降雨概率为 30%／20%／40%／15%，在 SeasonConfig 中调整。WeatherConfig.RainChance 保留给没有 CalendarManager 的独立天气初始化使用，正常游戏采用季节概率。

雨天全部已种植的露天农田自动浇水，包括雨中新播种的作物；空地和仅耕地的地块不会浇水。雨水不消耗体力、种子或金币，不直接增加生长进度。跨日最多成长一次，成熟后不继续累积。次日晴天时浇水状态正常清除，次日仍下雨时立即重新浇水。

天气结果由新游戏生成的 WeatherSeed、目标日期和配置概率确定，独立于 Unity 的随机序列。当天结果与种子写入存档，读档恢复当天结果；在配置相同的前提下，未来天气序列保持一致。调整季节概率会影响未来跨日生成的天气，不会重新抽取存档中当天的天气。季节与日期说明见 [日期、季节与播种](CalendarAndSeasons.md)。

## 光照与表现

TimeManager 的游戏分钟决定阳光强度、颜色、方向、环境光和相机天空背景。默认 05:00 开始天亮，08:00 达到日间光照，17:00 开始变暗，20:00 进入夜间；黎明和傍晚平滑过渡并带暖色阳光。

白天以暖白直射阳光为主，采用 Trilight 环境光：天空提供偏冷补光，水平方向更弱，地面仅提供少量暖色反射，保留受光面与背光面的明暗差。太阳方位从 -105° 移至 75°，高度沿弧线变化，最高 65°；默认 12:30 达到最高点。08:00–17:00 的日照平台内，太阳和阴影仍持续移动。晴天峰值强度 1.05，采用柔和阴影；雨天直射光降为 32%，阴影减弱、天空变灰蓝。

MainGame 为叠加加载，主菜单场景保留时，其方向光同样可能影响岛屿。GameManager 在进入游戏时关闭缓存的主菜单灯光，返回菜单或加载失败时恢复原来的启用状态，避免额外太阳叠加；直接打开 MainGame 的编辑器流程不关闭游戏灯光。

日落后阳光强度为 0，独立 Moonlight 方向光提供 0.12 的微弱冷色月光（沿用项目现有光源强度设置）。夜间天空、环境光与反射明显压暗；海洋着色器同步降低水色、泡沫和波光亮度，避免水面自行提亮夜景。庭院灯、小屋照明等局部暖光保留。太阳和月光均排除室内层，室内继续由房间自身的灯光照明。

WeatherConfig 中可调整四个时刻、阳光峰值、月光强度（NightIntensity）、太阳方位与最高高度、天空 / 水平 / 地面三组日夜环境色、反射强度、阳光 / 月光 / 天空颜色、雨天倍率和雨滴数量。时刻需严格递增且处于一天之内，月光强度为正，雨天倍率大于 0 且不超过 1；配置无效时停止启动。现有 AA 配置已更新为以上数值；编辑器创建缺失资源，重复配置保留已调整的参数。

背包、商店和睡觉弹窗暂停时钟及雨滴运动；关闭后恢复。HUD 的 WeatherText 位于 `FarmHudPanel.prefab`，由 FarmHudModel / FarmHudController / PrototypeHud 显示中文“晴天”或“雨天”。面板继续使用 AA 同名地址和 Common 层。离开场景后清理月光、雨滴、场景引用和天气状态；在原场景内清理时恢复原有方向光、阴影参数、环境光模式和三色、反射及背景，重复进入只创建一盏月光。

天空的 IslandClouds 预制体通过 AA 加载并由 WeatherManager 更新。晴天投下稀疏柔和的移动云影，暂停冻结，进入室内隐藏；雨天与夜间取消独立云影。资源、参数和渲染检查见 [云层与云影](Clouds.md)。

## 存档与验证

存档保存 WeatherSeed 和当天 Weather；本次光照调整不新增存档字段。版本 1–5 沿用原有迁移规则，再补固定种子 1 与晴天；版本 5 原有的混种农田、当前种子、金币、时刻和体力保持不变。非法天气枚举或非正种子拒绝恢复。读档雨天只补浇水，不增加生长进度或赠送种子。

- `Tools/VerifyWeather.cs`：1001 项断言，检查概率边界、天气序列恢复、非法数据、日照边界与太阳路径、雨水幂等、跨日成长、存档快照和版本 5 迁移。
- `LightingFlowVerification.Run`：独立 Unity 工程构建 Packed AA，验证太阳移动、三色环境光、日落、夜间亮度与海水、雨天与暂停、真实 AA 庭院灯、室内灯光与光源层、退出清理和再次进入，并输出对应画面。
- `PauseSleepFlowVerification.Run`：检查实际暂停、床边睡觉与清晨存档、失败快照重试；早期 WeatherFlowVerification 中的自动保存断言属于旧行为。
