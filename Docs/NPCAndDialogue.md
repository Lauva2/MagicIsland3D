# NPC 与对话

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

岛务员“林舟”上午在办事处，下午前往海岸，傍晚返回。走近点击角色开启交谈，点击“下一句”逐句推进；最后一句的按钮变为“结束交谈”。右上角关闭按钮或 ESC 可中途退出。

## 台词与见面规则

- 首次对话包含三句介绍：欢迎玩家、说明公告栏订单，以及介绍农场设施；随后加入当前季节和天气各一句，总计五句。
- 已见面后使用一句日常招呼，再加入季节和天气台词，总计三句。四季和晴 / 雨各有独立配置。
- 对话显示关系阶段和好感度，完成首次交谈后开放“送礼”按钮。熟悉和友好阶段由 RelationshipCatalog 提供日常招呼；初识仍使用原有 Repeat。每日礼物、喜爱物品及保存规则见 [好感度与送礼](Relationships.md)。
- 往事按钮由 StoryEventManager 提供下一个事件，达标后可进入专属台词；事件中禁用送礼和再次进入事件，完成最后一句才记录并保存。详见 [好感度事件](StoryEvents.md)。
- 开始时固定本次台词快照，逐句推进不会重新选择台词。文字即时显示，不使用打字机效果。
- 只有推进完最后一句才标记已见面；显示最后一句后直接关闭仍视为未完成。中途关闭或面板加载失败不记录见面，下次重启首次介绍。
- 完成首次对话在睡觉时统一保存。保存失败保留运行中的已见面标记，显示错误；返回主菜单前保存可重试，不会重复首次介绍。直接关闭程序仍只保留最近成功写入的快照。
- 对话不扣体力、不发金币或物品，也不触发收获 / 出售等新手任务。

## 交互与界面

对话需满足范围限制，工具动作中不能交谈。重复打开、UI 上的点击和远距离点击均不启动对话；角色射线拦截后不操作背后的农田。对话加载和打开期间暂停时间、天气效果及玩家 / 镜头输入，禁止工具操作，并与背包、商店、睡觉、订单、工具升级、储物和料理面板互斥。

交谈时角色暂停行走并转向玩家，结束或取消后恢复原朝向并继续日程。角色头顶显示名字，采用面向镜头的 TMP 文本。日程、路线、阻挡和途中存档见 [NPC 日程](NPCSchedules.md)。

`DialoguePanel` 属于 PopUp 层，以奶油白、草绿和暖沙色搭配，使用中文 TMP。MVC 分别管理说话人、正文、句子进度和按钮事件，关闭时解除控制器绑定。

## 管理与资源

`NPCManager` 负责见面状态、AA 角色实例、距离和朝向；`DialogueManager` 负责对话会话及台词选择；`GameManager` 调度配置、初始化、打开 / 推进 / 关闭、保存和退出清理。NPCState 和 DialogueState 为纯 C# 模块。

| 资源 | 路径 | AA 地址 |
| --- | --- | --- |
| 角色配置 | `Assets/Config/NPCCatalog.asset` | `NPCCatalog` |
| 台词配置 | `Assets/Config/DialogueCatalog.asset` | `DialogueCatalog` |
| 角色模型 | `Assets/Art/Prefabs/Characters/IslandSteward.prefab` | `IslandSteward` |
| 面板 | `Assets/Art/Prefabs/UI/DialoguePanel.prefab` | `DialoguePanel` |

默认角色 ID 为 `island_steward`，配置名称、身份、模型地址与相对办事处位置。默认偏移 `(1.7, 0, -3.55)`，避开建筑、公告栏、工作台和最大农田范围。模型位于 Characters AA 分组。可替换正式角色预制体，须保留根 NPCActor 和碰撞体；NameText 为可选名字引用。

台词配置按 NPC ID 匹配，包含 Intro / Repeat 列表、按春夏秋冬排序的四句季节台词、按晴雨排序的两句天气台词。空台词、重复或未匹配 ID、条目数错误和单句超过 160 字符时拒绝配置。角色 ID / 顺序用于严格存档校验，改动可能使旧存档不兼容。

编辑器只创建缺失配置、角色和面板，保留已有模型、台词和完整布局；UI 的 AA 地址与预制体名称一致。

## 存档

版本 12 新增 NPCs，保存每个角色的 ID 与 Met 标记；对话的当前句不单独保存，读档按见面状态重新开始。版本 1–11 迁移补未见面角色，保留农田、物品 / 食物、储物箱、体力、金币、任务、订单、采集与工具等级。

读取前严格校验 NPC 数量、ID、顺序和非空记录，先在临时状态验证，再恢复世界。结束或退出时释放角色 AA 实例并清理会话，重新进入不重复创建角色。

## 验证

`Tools/VerifyNPCDialogue.cs` 覆盖见面标记、深快照 / 原子恢复、所有季节晴雨组合、首次与日常台词、重复会话、逐句推进、取消包括最后一句、单次完成和版本 11 迁移。

`NPCDialogueFlowVerification.Run` 在独立 Unity 项目构建并运行 AA，检查两个配置、模型和 MVC 面板、支持的农田尺寸、距离 / UI / 工具动作 / 模态限制、取消与完成语义、保存失败 / 重试、读档后的冬季雨天对话、迁移、非法 ID、资源释放和中文排版。
