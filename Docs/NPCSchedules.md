# NPC 日程

林舟每天往返办事处和海岸。走近点击角色仍可交谈、送礼和进入好感度事件；鼠标指向角色时，HUD 显示他目前的活动。

| 时间 | 活动 |
| --- | --- |
| 06:00–12:00 | 留在办事处旁 |
| 12:00–18:00 | 步行至海岸，抵达后休息 |
| 18:00–24:00 | 沿原路线返回办事处 |

午夜前未睡觉时仍按返程处理。移动速度默认每真实秒 1.4 个世界单位，与游戏分钟换算独立。若傍晚到来时尚未抵达海岸，会沿原路返回。睡觉结算后恢复次日 06:00 的办事处位置。

## 配置和管理

`NPCScheduleManager` 控制日程、路线进度、物理检查和移动朝向；`NPCManager` 控制 AA 角色实例、见面状态、范围及交谈转向。`GameManager` 调度初始化、世界更新、睡觉、保存和退出清理。

配置位于 `Assets/Config/NPCScheduleCatalog.asset`，AA 地址为 `NPCScheduleCatalog`，由 ConfigurationManager 在主菜单前加载并校验。编辑器只创建缺失配置，保留已编辑参数。日程条目按 NPCCatalog 的 ID 与顺序匹配。

- `WalkSpeed`：真实秒移动速度，允许 0.2–4。
- `CoastStartMinute` / `ReturnMinute`：开始前往海岸与返回的游戏分钟，默认 720 / 1080。
- `CorridorX`：东侧通道位置，默认 11.2。
- `CoastOffset`：相对钓鱼点的休息位置，默认 `(-1.25, 0, 1.4)`。
- `HomeYaw` / `CoastYaw`：抵达后的朝向，默认 180 / 90 度。

办事处位置由农田尺寸与 NPCCatalog.HallOffset 推导；海岸位置由 FishingCatalog.SpotPosition 推导。路线为办事处 → 同 Z 的东侧通道 → 与海岸同 Z 的通道 → 海岸，支持农田尺寸 1–12。每段分别推进，即使单帧时间较长也不会斜穿拐角。

## 避障与暂停

配置校验保证路线位于岛内并绕过农田。角色与设施 AA 加载完成后，对整条路线进行胶囊重叠 / 扫掠检查，避开建筑、商店、工作台、储物箱、料理台和钓鱼平台。静态障碍导致初始化失败时，清理世界并显示错误。修改场景布局后应同时调整路线。

行走期间同样进行胶囊检查。玩家或其他实体挡路时停下，移开后继续，不穿过实体。低矮地面与触发器不拦截路线。这一版使用配置的通道，阻挡后等待；后续地图扩展可增加寻路。角色当前以位置移动和朝向表现行走，未加入骨骼步行动画。

所有现有模态面板的加载及打开期间暂停日程。对话、送礼、事件期间额外检查 NPCManager 的 Focus 状态，保持面向玩家；关闭后恢复路线朝向并继续行走。模型应保留根 NPCActor 和直立、居中的 CapsuleCollider，默认高 1.7、半径 0.3，支持半径不超过 0.35。

## 存档

版本 15 新增 `NPCSchedules`，保存每个 NPC 的 ID 和沿路线累计距离。目的地由已保存的游戏时间推导，读档恢复途中位置与行走朝向；交谈会话不保存。保存触发点沿用现有操作、睡觉和返回菜单，未保存的移动仍以最近成功快照为准。

版本 1–14 迁移按已保存时间安排位置：上午 / 傍晚在办事处，下午在海岸。迁移保留见面、好感度、礼物日期、事件、物品与世界进度。数量、ID、顺序、有限距离和路线范围严格校验；无效记录拒绝整份数据，可恢复有效备份。

## 验证

`Tools/VerifyNPCSchedules.cs` 覆盖时间边界、所有农田尺寸、移动速度、路线拐角、阻挡 / 恢复、模态 / Focus 暂停、傍晚反向、睡觉、深快照、原子校验与版本 14 迁移。

`NPCScheduleFlowVerification.Run` 在隔离 Unity 项目构建 AA 后验证实际尺寸 5 / 12 的路线、建筑 / 玩家阻挡、交谈 / 送礼 / 事件、GameManager 模态暂停、海岸活动提示、途中读档、睡觉、迁移、非法存档、路线失败清理、重新进入和中文显示。
