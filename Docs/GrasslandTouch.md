# 草原拨草与草浪样区

本轮只处理草原传送落点附近的样区：地形局部坐标中心 `(-124,447)`、半径 24 米，外缘 6 米羽化。玩家经过时草叶轻轻向外压弯，离开后平滑回弹；花朵幅度更轻。默认镜头确认效果后再决定推广范围。

## 资源与显式维护

入口 `Magic Island > Art > Prepare Grassland Touch Sample (Explicit)`。普通 Setup 不执行。工具原位细化 6 份既有合并网格中的 1,108 片低草叶，变化叶宽、叶高与侧向弯曲，完整保留叶根、原株位、数量、颜色、索引和 UV0–7。其他植物及样区外顶点保持，不创建对象、Renderer、材质、配置地址或碰撞。

参数随原 IslandTerrain AA 依赖保存在 SeasonalGroundCover.TouchSample，ArtVersion=0 为旧资源的禁用状态，显式准备后为版本 1。现有六份 Renderer 引用限定影响批次，中心、半径和羽化限定局部范围。默认影响半径 1.05 米、最大压弯 0.18 米、回弹 0.7 秒、花朵倍率 0.22；实际读取预制体，不由 UI 或普通 Setup 覆盖。

原风动相位与根部频道不变。原 Meadow Flora 仅在样区内增强低草的统一风向草浪，保留个体错相；原 WeatherManager 风时钟、方向与风力继续驱动。采用原已标记草／花权重，根部零权重始终固定。形变同时用于阴影，保留原双面法线。压弯与风动合计后限制在根部 1.30 米内，连同半格建设物与余量仍包含于原 1.85 米整株建设遮盖；样区批次 bounds 保守扩展，手调参数上限限制完整移动包络。

工具写入前检查全部模型、模板、材质、碰撞引用、频道、元数据及变换。只追加 GrasslandTouch.v1 importer 标记，保存失败还原原资源；未知源数据和部分迁移拒绝覆盖。版本完整时不再写入，保留合法参数、改形和配色。原花草入口按标记集合识别地表层，保留本轮追加标记。

## 调度与属性拥有者

WeatherManager 在原 Tick 中统一调用 SeasonalGroundCover.TickTouch，不新增 Update、Manager、玩法随机源、进度字段或全局材质参数。MeadowTouchSimulation 使用固定 16 槽接触数据，按移动距离补足低帧率路径，快速移动时适度增大采样间距；离开位置按平滑曲线衰减，站立时保留脚边压草。模态暂停不推进，远距／高度突变传送清除旧轨迹；室内、目标丢失和解绑清除。

MeadowCoverPresentation 是这些 Renderer 属性块的唯一拥有者，同时维护原建设遮盖和新接触数据；刷新建设不清掉压草，压草不清掉建设遮盖。只更新样区批次的实例 MPB，不写共享网格／材质，不产生逐草对象、物理查询或每帧动态集合。Clear 幂等恢复原完整 MPB 与 Renderer 开关，并解除原系统订阅。瞬时接触不保存，仍只有床边睡觉保存进度。

## 验证

在独立工程运行 GrasslandTouchVerification.BakeAndVerify，核对原 GUID、索引、颜色、全部 UV、叶根、未选中顶点、原碰撞与其他美术；覆盖自定义材质拒绝、重复执行／旧花草入口／普通 Setup 保留手调。固定接触模拟覆盖初次柔和接触、低帧率路径、暂停、回弹、传送与室内清除；独立 Renderer 夹具检查建设／接触属性共存、原 MPB 和材质还原。

GrasslandTouchVerification.After 构建真正 Packed AA，沿原五岛流程验证实际配置与网格、完整角色胶囊安全落点、默认镜头实走；隔离实际草地并关闭风力，确认 GPU 压草、暂停稳定帧和清除后的原画面恢复。继续检查共享风场、真实样区建设／整株隐藏／回收／旧建设重绑、进屋、床边睡觉、五岛读档、返回及 AA 清理。测试存档隔离，截图、视频帧与验证副本在 Logs/GrasslandTouch，不入库。

同步后重新执行 Build Prototype Addressables。效果以正常游玩镜头对比和行走预览为主，仍待用户确认；尚不推广到其他区域或群系。

## 本轮验证结果

隔离工程 Bake.log 与 Packed3.log 均退出码 0。前者核对 6 份原网格、1,108 片叶／3,324 个选中顶点、完整原频道、根部和其他美术保护，覆盖手调与重复入口；后者通过真实 AA、固定接触模拟、隔离草地零风力 GPU 压弯、暂停／清除画面恢复，以及 32 步角色实走。样区实际建设、GPU 整株隐藏、回收、旧建设重绑与原 6,936 步通路、进屋、睡觉、五岛继续和退出清理通过，白天不写盘。

静止帧至多允许 4 个像素、每通道 1/255 的 GPU 舍入差；压弯检查要求超过 16 个像素发生变化，树冠风动回归要求超过 64 个，不能用舍入差充当运动。构建未出现着色器或 C# 编译错误。未构建独立 Player 或测量 GPU 性能，本轮未重跑全历史存档迁移矩阵；没有新增存档字段或改变唯一保存点。
