# 存档系统

`SaveManager` 负责本地存档文件、校验和备份；`GameManager` 调度保存和恢复，不让 UI 或场景组件自行启动流程。

## 保存内容与入口

- 单存档，版本号目前为 1；JSON 保存日期、农田尺寸及每格耕作/种植/浇水/生长状态、背包各格的物品 ID 和数量、角色位置。
- 主菜单“新游戏”创建初始状态；“加载游戏”从磁盘读取并校验，再由各系统恢复状态。没有有效存档时禁用加载按钮。
- 每次推进日期、返回主菜单前自动保存。返回时保存失败会保留游戏和当前数据，在 HUD 显示错误，允许重试。
- 新游戏开始时保留旧存档，第一次自动保存时替换。当前没有多存档选择或退出时保存；直接关闭程序会保留最近一次自动保存的进度。

## 文件与异常处理

路径为 `Application.persistentDataPath/Saves/save.json`；前一次提交保存在 `save.json.bak`。先写同目录临时文件并刷盘，再原子替换正式文件，写入失败不会主动删除旧存档。

读取时校验版本、配置尺寸、农田状态、背包容量、物品 ID、堆叠数量和角色位置。先在临时数据中完成校验，再初始化世界并恢复，避免半恢复状态。

正式文件损坏时尝试有效备份；两个文件都不可用时允许新游戏。暂不迁移其他版本；配置改变导致存档不兼容时也会拒绝恢复，避免静默丢失物品。

## 验证

`Tools/VerifySave.cs` 检查快照独立性、格子顺序、恢复后的生长、非法数据拒绝、恢复失败时不修改原状态、原子写入与备份恢复。

`GameFlowVerification.Run` 在独立 Unity 工程和隔离存档目录中验证 AA 新游戏、自动保存、继续游戏、角色位置、保存失败时保留世界、损坏文件恢复和版本拒绝，同时检查 TMP 中文字形和 UI 分层。
