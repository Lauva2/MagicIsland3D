# 小屋升级与扩建

在办事处门前公告栏打开订单面板，点击“小屋扩建”，切换到 PopUp 层 HouseUpgradePanel。首版只提供一次扩建：初始小屋升级为舒适小屋。

默认费用为背包木材 20、石料 10、金币 300，施工 1 天。面板显示费用、持有数量、施工状态和保存反馈。必须靠近公告栏申请，备齐后点击“确认支付并申请”。材料与金币一起扣除并记录完工日期；不足、重复请求、施工中或已经完工均不重复扣费。申请成功自动保存；写盘失败保留申请，通过“保存进度”重试。

次日睡觉结算时完工，GameManager.AdvanceDay 调试入口执行相同规则。施工期间仍可进出、睡觉和布置原房间。读档恢复已支付费用和预定日期，不再次收费、不提前完工。面板打开及加载时暂停时间、移动、普通交互和其他模态操作，关闭或 ESC 恢复输入。

## 调度与存档

HousingManager 持有 HouseUpgradeState、费用、日期、扩建 AA 模型和表现。GameManager.HouseUpgrade.cs 调度办事入口、模态、支付、保存和重入保护。GameManager 统一跨日，推进农场日期后检查完工，再解锁 FurnitureManager 的新区域并保存完整世界。跨日执行锁避免回调导致重复结算。

SceneManager 继续惰性加载室内。扩建保留当前场景和实例，不重新传送角色。完工后室外读档恢复升级外观，第一次进屋先恢复扩建几何，再恢复家具与角色；室内读档顺序相同。返回菜单释放扩建实例、AA 句柄和状态。

当前存档版本 19，新增 HouseUpgrade，保存 Level（0 / 1）和 CompletionDay。未申请为 0 / 0；施工中等级仍为 0，预定日期晚于当前日期；完工为 1 / 0。申请和完工分别自动保存，失败保留完整运行结果，允许重试。

版本 1–18 迁移补 0 / 0，不赠送升级、不补材料或金币、不改变家具、区域、位置或其他世界状态。非法等级、过期 / 负数施工日期、完工却仍有施工日期拒绝读取。家具和角色按等级校验，未升级存档不能使用扩建区域。

## 验证

Tools/VerifyHouseUpgrade.cs 验证费用边界、原子通知与重入、日期溢出、施工 / 完工、非法状态、扩建范围、家具保留及版本 18 迁移。HouseUpgradeFlowVerification.Run 使用打包 AA 验证公告栏入口、MVC 和实时费用提示、距离 / 模态保护、申请和完工的保存失败重试、施工中读档、睡觉完工、旧墙移除、扩建区移动 / 摆放、家具实例与床 / 出口 / 角色保留、完工读档和中文 TMP。家具、小屋、订单、农务与任务继续回归。
