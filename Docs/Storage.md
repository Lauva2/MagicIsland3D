# 储物箱

农田前方偏左新增一个固定储物箱。走近后点击打开 `StoragePanel`，按 ESC 或关闭按钮退出。第一版没有制作、自由摆放、多个箱子或费用。

## 存取规则

- 默认 18 格，物品每格上限沿用 ItemCatalog（当前为 99）。左侧是随身背包，右侧是箱子；两侧独立滚动，可支持最多 36 格。
- 点击任意一侧格子后，操作按钮切换为存入或取出。可转移一个或当前选中格子的整组物品。
- 目标先补同类未满堆叠，再使用空格；源端只扣选中的格子，其他同类堆叠保持不变。
- 全部数量放不下时不转移，不进行部分搬运；整组不能放下而一个可以放下时，可用单个转移。
- 两边库存一起提交后才通知 UI。事务期间防止重入，避免只改一边或重复转移。
- 空格、非法格子和数量不产生变动。距离太远、动作进行中、未打开面板时不能存取。
- 不消耗体力或金币，不触发任务的收获、出售行为。箱内物品不计入背包；种子、交易、订单和工具升级仍只读取背包，需要先取出物品。
- 面板加载和打开期间暂停时钟与天气表现，禁止场景工具动作；与背包、商店、睡觉、订单和升级面板互斥。

## 架构与资源

`StorageManager` 负责储物状态、AA 箱子实例、存取和反馈。`StorageState` 使用独立 InventoryState 保存箱子库存，调用选定格子的原子转移方法。`GameManager` 统一调度初始化、交互、保存和退出清理，`UIManager` 加载 `StoragePanel`，其 MVC 控制器绑定按钮并显示两边库存。

| 资源 | 路径 | AA 地址 |
| --- | --- | --- |
| 配置 | `Assets/Config/StorageConfig.asset` | `StorageConfig` |
| 箱子 | `Assets/Art/Prefabs/Buildings/StorageChest.prefab` | `StorageChest` |
| UI | `Assets/Art/Prefabs/UI/StoragePanel.prefab` | `StoragePanel` |

StorageConfig 配置容量（1–36）和模型地址。箱子带 StorageChest 标记及碰撞体，位置由农田尺寸计算为 `(-1.5, 0, -FarmSize * 0.6 - 2.2)`，避开农田、床、商店、公告栏、工作台和已有资源节点。固定箱子位置不单独存档。

面板属于 PopUp 层，中文 TMP 字体、奶油白 / 草绿 / 暖沙色，与已有 UI 一致。编辑器只创建缺失配置和预制体，保留已有模型、参数和布局；AA 地址与 UI 预制体名称一致。

## 存档

版本 11 新增 `Storage`，按格子保存 ItemId 和 Quantity。每次成功存取立即保存，背包与箱子处于同一快照；关闭面板不再重复转移。保存失败保留本次运行的两边库存，显示错误；点击“保存进度”、跨日或返回菜单可重试。直接结束程序只保留最近成功保存的快照。

版本 1–10 迁移补空箱子，不搬动现有背包、不赠送物品，保留农田、任务、订单、采集、工具等级、金币和体力。箱子格子数必须匹配配置，格子缺失、未知物品、负数量、超堆叠上限及空格携带物品 ID 时拒绝恢复；先在临时库存校验，再恢复世界。修改容量可能导致旧存档不兼容。

## 验证

`Tools/VerifyStorage.cs` 覆盖双向存取、数量与容量边界、总量守恒、指定格子扣除、同类堆叠、单次通知、事件重入、深快照、非法恢复和版本 1–10 迁移。

`StorageFlowVerification.Run` 在独立 Unity 项目中构建并运行 AA，检查箱子和面板 MVC、距离 / 射线 / UI / 动作锁、两种存取按钮、空间不足保护、模态暂停、自动保存失败与重试、精确读档、非法物品拒绝、版本 10 迁移、退出清理和中文布局。
