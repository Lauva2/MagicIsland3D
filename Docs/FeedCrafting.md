# 饲料制作

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

在办事处前的工作台打开制作面板，通过“下一页”进入第三页“养殖用品”。使用随身背包中的玉米制作饲料。

| 配方 | 消耗 | 产出 |
| --- | --- | --- |
| 玉米饲料 | 玉米 × 1 | 饲料 × 10 |

配方默认开放，不依赖鸡舍建成，全年可制作库存中的玉米。制作不消耗金币或体力，箱内玉米需先取出。成品沿用 `animal_feed`，与商店购买的饲料合并堆叠，每格最多 99 份；每只鸡每天仍需要一份，十份可供两只鸡使用五天。详见 [鸡舍养殖](Animals.md)。

## 制作与容量

`CraftingManager` / `CraftingState` 沿用原子交换：检查全部材料，在临时背包中模拟扣料后的空间，再一起提交材料和全部成品，最后通知 UI。缺料或放不下全部十份时不扣玉米，不分批发放；只剩最后一份玉米时，腾出的格子可以容纳饲料，已有饲料堆叠的剩余空间也参与计算。

每次成功制作后由 `GameManager` 睡觉时统一保存。保存失败保留完整运行结果，通过面板“保存进度”重试，不再执行配方；材料通知回调中的重复制作、关闭、跨日和返回菜单请求被拦截。制作不计作收获或出售任务。

## 配方与 UI

AA `CraftingCatalog` 新增 `animal_feed` 配方，IsSupply 为 true，Yield 为 10，原料为 corn ×1。IsSupply 表示背包用品，当前支持 Crop 或 Material 原料、Material 成品，不需要世界模型；不能同时设置 IsFurniture。原装饰、家具仍使用木材 / 石料等 Material 原料和对应 Placeable / Furniture 成品。

`CraftingPanel` 继续位于 `Assets/Art/Prefabs/UI`，使用同名 AA 地址、MVC、PopUp 层和中文 TMP。三类配方分别分页：农场装饰、室内家具、养殖用品；每页最多三张卡片，显示需求、库存、产量、缺料 / 空间反馈及上下页边界。分类按类型组织，编辑器中调整配方顺序不会把用品混入装饰页。关闭重开回到首类第一页。

沿用原卡片布局和配色，只有一张饲料卡时隐藏另外两张。工具升级面板的制作入口使用“工作台制作”。编辑器只补缺失配方，并仅替换原默认标题和提示，保留已编辑参数、完整布局、美术和资源 GUID。

## 背包、摆放与存档

`PlacementManager` 和 `FurnitureManager` 只加载可摆放配方的 AA 模型。用品不进入占位定义或模型加载队列，直接请求摆放也会在 AA 加载前拒绝。背包选择饲料仅显示详情，不提供播种、食用或摆放按钮。饲料保留 Material 分类，可放入储物箱，取出后在鸡舍照常喂食、次日产蛋。

存档现在使用 v22，复用已存在的饲料 ID 和背包 / 储物格子，不增加字段或迁移。旧装饰、家具和饲料库存正常恢复，不赠送玉米或饲料；伪造将饲料存为装饰 / 家具的记录会被拒绝。

## 验证

`Tools/VerifyFeedCrafting.cs` 覆盖背包容量、玉米数量、饲料堆叠边界、扣料后空间、完整十份产量、失败不扣料、原子通知和重入、储物 / 当前版本保存，以及一份玉米供两只鸡五天并产十枚蛋的纯规则循环。

`FeedCraftingFlowVerification.Run` 在隔离 Unity 工程构建 AA，验证真实种植 / 浇水 / 收获玉米、调整配方顺序后的分类和按钮映射、用品无需模型、实际制作按钮、背包 / 堆叠边界、保存失败重试、距离 / 模态、中文排版、背包动作排除、摆放记录拒绝、储物读档、用制作饲料喂鸡 / 产蛋 / 读档、新游戏及资源清理。
