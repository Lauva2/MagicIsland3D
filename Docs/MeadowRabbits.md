# 草原小兔

2026-10-18。接续 [花丛生态](GrasslandEcology.md)，在草原主路、西湖岸和东侧林缘支路附近增加四只环境小兔。它们低头觅食、侧头观察、短跳移动；玩家靠近时警觉并沿安全路肩避让，离开后回到活动区中央。没有捕捉、掉落、交互或进度状态。

## 资源与显式烘焙

Blender MCP 源场景和顶点色导出位于 `SourceArt/MeadowRabbit`，可复现脚本为 `Tools/Art/BuildMeadowRabbit.py`。脚本默认拒绝覆盖已有输出并恢复用户原活动场景。圆润奶油色兔子每只 1,784 三角面，头、耳、前爪和后腿有独立枢轴标记；运行时不读取 Blender 或 JSON。

显式入口为 **Magic Island > Art > Add Grassland Rabbits (Explicit)**。四只合并为 `Meadow Rabbits.asset` 一个网格及同名共享材质，放在原 IslandTerrain 的 `World water ecology / Grassland rabbits` 下，由原 AA 依赖加载。没有逐只 GameObject、Animator、碰撞、灯光、材质实例或独立 Update。普通 Setup 不添加或重建兔子；已有完整子树保留后续网格、材质与布置调整，孤立同名资源或不完整引用拒绝覆盖。

工具先准备全部候选活动区，再写资源。每条活动区长 3.6 米、25 个实际地面采样点，避开主路中心、可建设格、既有花丛、树干和景观石灌丛。完整动画身体查询半径 0.46 米、高 1.15 米；脚周边地面高度差最多 0.08 米。保持旧地形、碰撞、路线、建设资格及全部原 UV 频道，仅在新兔子网格 UV0–2 记录个体、关节与烘焙中心。裁剪 bounds 覆盖全部活动区与跳跃高度。

## 调度与安全移动

`WorldWaterEcology` 持有可选 `MeadowRabbits` Renderer 和 `RabbitHabitats` 数组，旧资源的空引用仍合法。`MeadowRabbitPopulation` 是绑定时创建、清理时释放的普通 C# 状态；以原环境秒数固定 30 Hz 推进，渲染插值位置、转向和头耳四肢动作。最多八只，当前烘焙四只；个体相位错开，不消耗玩法随机数。

`MeadowRabbitHabitat` 的 Track 使用生态拥有者局部坐标。默认跳距 0.65 米、自然速度 0.85 米／秒、避让速度 1.7 米／秒、停留 3.2 秒、惊扰距离 3.5 米；已感知玩家时另保留 1 米释放余量。修改活动区或扩大身体／动作范围须重新检查整个地面、建设格和碰撞包络。仅缩短范围或调整合法参数时，显式工具与普通 Setup 均保留配置。

起跳前完整检查路线，转身平滑到目标方向后才起跳，每步复查新障碍。非分配物理查询只检查所属世界，忽略原地面、隐形边界、触发器及其他世界，玩家体积沿用已有独立判定；查询缓冲区满时拒绝通行。途中受阻时停止水平位移并完成落地，再等待；不会穿过障碍或瞬移返回。旧玩家建设优先，绑定时整条活动区被覆盖则保持隐藏，空出后才渐显。已可见兔子与新物体重叠时只允许连续向外脱离，不删除或移动建设记录。

夜间减少自然活动，雨天减少移动并停止觅食；安全跳跃与避让继续使用实际环境秒数。暂停冻结全部姿态和状态；进屋随原生态隐藏且停止推进，出屋恢复。垂钓期间沿用海洋继续的既有规则。Bind 保存原 MaterialPropertyBlock，Clear 恢复完整属性块、清空导航与物理引用；重新绑定不保留旧惊扰或动作。共享材质、Transform、玩法随机数和存档 v31 均不变。

## 验证与交接

`MeadowRabbitVerification.BakeAndVerify` 仅在隔离工程运行，检查 Blender 动作包络、四处完整安全脚印、单批次及无逐只组件、旧碰撞与其他美术字节；还检查重复、普通 Setup 和人工改形／材质保护。

`OceanWaterAppearanceVerification.RunMeadowRabbits` 构建并加载真实 Packed AA，回归原花草和昆虫，再检查混合帧率连续移动、觅食／观察／跳跃、局部惊扰与返回、旧建设覆盖／新障碍、实际 GPU 暂停、室内冻结、共享资源与随机数不变、属性块清理。实际渲染序列写入忽略的 `Logs/MeadowRabbits`。`StarterIslandWorldFlowVerification.Run` 覆盖地图、睡觉、继续、进出小屋、返回与重进及 AA 清理。

正式资源合入后执行 **Magic Island > Build Prototype Addressables** 再启动游戏。验证副本、日志和截图不提交；源模型、导出、脚本、原生资源及 `.meta` 随代码交接。

## 草原生态组合与行为收尾

显式 **Magic Island > Art > Refine Meadow Ecology Composition (Explicit)** 将四条兔子活动区向原有蝴蝶花丛靠拢，兔子活动区中心距对应花丛 3.6–5.5 米，整条路线与花草中心至少相隔 1.7 米。保持花草 1.05 米风动脚印、兔子 0.46 米身体包络及额外余量，沿用完整地面／建设格／景观碰撞检查；不移动原花草或昆虫，不新增景观对象。工具读取现有昆虫网格的栖息中心，预检所有候选后才原位更新原兔子网格及生态配置，保留 GUID 和其他美术。

首次执行前比较原兔子形状、颜色、全部 UV、bounds、批次变换与原安全 Track，手工改动时拒绝覆盖；合法速度、停留、相位等参数与共享材质保留。原网格导入器 `userData=MagicIsland.MeadowComposition.v1` 标记已完成，拒绝已有自定义元数据。重复精修、Add Grassland Rabbits 和普通 Setup 保留完成后的手调；不使用旧地形的额外 UV 频道。

兔子的自然休息时长按个体相位及访问次数在配置 WaitSeconds 的 0.7–1.6 倍间变化；交替觅食、观察和休息。自然跳距在配置 HopDistance 的 0.6–1 倍内变化，到近处落点时可更短，速度为配置 Speed 的 0.82–1 倍；平时只在中心周边最多 0.85 米缓慢活动，避让仍可使用完整安全路线。离开边缘后连续短跳返回，不压缩成一次长跳或瞬移；转身时平滑抬头，再起跳。

左右耳使用不同时长的短促轻摆和安静间隔，额外旋转最多 0.04 弧度，由原固定 30 Hz 状态及 `_RabbitEars` 属性数组插值；shader 不读取独立时间。完整头耳、觅食、跳跃包络继续使用原查询体积。新增状态与原行为一起暂停、室内冻结和退出清理，不改源 Blender 模板、共享材质、玩法随机数或存档。

`MeadowPolishVerification.BakeAndVerify` 检查完整新动作包络、花丛关系、安全活动区、自定义网格拒绝、重复和后续人工调整保护。`OceanWaterAppearanceVerification.RunMeadowPolish` 运行原草原／昆虫／小兔验证后，补充四只可见性、左右耳差异、跳距与停留变化、耳朵暂停／室内／清理，以及四处道路上的原游玩镜头检查。画面使用实际镜头俯角与缩放，另输出局部动作序列，均写入忽略的 `Logs/MeadowPolish`。

本轮 `Bake.log`、`Packed.log`、`WorldFlow.log` 均通过。实际检查四张道路游玩视角，兔子与花丛清楚可见，道路留白保持；另输出 100 帧局部实机行为序列。原深海和湖泊的清晨／白天／夜间／雨天八张对照画面逐像素一致。原 2,333 条预制体记录全部保留，无新增景观节点，仅更改四条 Track；原兔子身体形状、法线、颜色、部件／枢轴、索引和 GUID 保留，移动烘焙中心并调整 bounds。其余 3,368 份原文件保持本轮快照，1,659 个 GUID 无重复，正式资源／源码与最终 Packed 副本字节一致。

没有重跑完整 OceanFlow、全部迁移或独立 Player 构建，没有测量 GPU 性能；存档、玩法与 AA 配置数量不变。正式工程仍须执行 **Build Prototype Addressables** 更新内容包。
