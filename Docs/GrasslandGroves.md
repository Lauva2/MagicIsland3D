# 草原树丛、花坡与路边小景

2026-10-19。在已有草原小径和生态基础上，增强树下、中景与花坡的疏密层次，继续只优化草原岛。

后续花色群落、株形变化与草／花分层风动见 [草原花草细化](GrasslandFlora.md)；完成该步骤后，既有地表批次改用 Natural Meadow Cover 共享材质，原拥有者、根部遮盖和批次数保持。

已有组合的叶团圆润化、苔石半埋与分层配色见 [草原灌木与苔石精修](GrasslandShrubStone.md)，原根部位置与整体水平范围保持。

## 资源和入口

显式入口：**Magic Island > Art > Refine Grassland Groves And Clearings (Explicit)**。`GrasslandGroveSetup` 先完成树冠、植被落点、全包络和资源冲突检查，再写入原 `IslandTerrain` AA 依赖。普通 Setup 不执行，已存在完整 `Grassland groves and clearings` 子树时保留后续手调。

- 原位调整草原内可识别的绿色树冠，高低、宽窄及顶部／底部色差随固定空间采样变化；树冠底部高度保持，原树干、其他群系、未选择顶点、三角面和全部 UV0–7 保留，不再分配额外 UV。只更新原群岛网格，保留 GUID；原碰撞引用的网格拒绝修改，自定义导入器元数据拒绝覆盖。
- 围绕现有树木布置高草、矮灌丛、少量地面落叶和野花，并强化三处不规则花坡与三处路边苔石／花草组合。独立固定种子 `195823` 在编辑器烘焙，进出、读档和跨日不重抽，不消耗玩法随机序列。
- 花、苔石使用原 `SourceArt/GrasslandComposition` Blender 模板，灌丛复用 `Shrub Cluster`；高草和小片落叶沿既有编辑器草甸网格构造。按 128 米区域合并，共用原 `Living Meadow Cover` 材质，没有逐株对象、运行时拼装、Collider、Update、灯光、掉落或新存档字段。
- 完整植被脚印避开原道路、树干／景观实体及小兔活动区，使用实际烘焙地面高度和坡度。单簇最大水平半径 1.18 米，保留风动余量，沿原根部元数据和 `MeadowCoverPresentation` 1.85 米遮盖范围；可建设位置保持原资格，既有或新建筑覆盖时整簇隐藏，回收后恢复。
- 新 Renderer 注册到原 `SeasonalGroundCover.MeadowBatches`，总数继续限制在 64 以内。风动、季节、室内隐藏、摆放事务和退出清理由原 Manager 与组件负责，不新增运行入口或计时器。
- 原道路、地形、海洋、动物活动参数、其他群系和进度字段不变。源网格和新网格以 `MagicIsland.GrasslandGrove.v1` 标记；孤立同名资源在写入前拒绝，保存失败还原原网格／预制体并清理本次新建资产。

## 验证

`GrasslandGroveVerification.BakeAndVerify` 在隔离工程核对原树干／未选中顶点、完整 UV、面、GUID、全部原地形与碰撞、其他美术保护、自定义元数据拒绝，以及重复入口／普通 Setup 保留后续手调。

`Before` / `After` 接续实际 Packed AA 流程。新增视图覆盖树丛、西侧花坡、中心花坡、路边小景和林缘；默认游玩视图采用项目的 42°、Size=7、18 米跟随距离，检查真实阴影距离下的层次。隔离验证副本中的 `Assets/Editor/GroveBaseline` 仅保存本次修改前的原网格用于同一光照／镜头对照：临时恢复原树冠并隐藏本轮新增植被，取景后立即还原实际 AA 网格和 Renderer 状态，不写资源或存档，不进入正式项目。

新批次还会接续真实摆放／回收、GPU 整簇遮盖、旧建设恢复、室内隐藏；原草原路径实走、小兔／昆虫、床边睡觉、五岛位置读档、返回重进和 AA 清理继续回归。截图和日志输出到忽略目录 `Logs/GrasslandGrove`。

正式工程更新后执行 **Magic Island > Build Prototype Addressables**。历史草甸与小径说明见 [草原岛小径与生态](GrasslandIslandMeadow.md)。

## 本轮实际结果

调整 42 处既有树冠的 2,940 个顶点，分布在八份原群岛景观网格中。围绕 20 组树木位置和花坡／路边点补充 1,001 处组合：368 处野花、155 处灌丛苔石、73 处落叶，其余为高草；新增六个合并批次，地表批次总数为 38，沿用原共享材质与拥有者。

`Bake.log` 退出码 0，通过原树干、未选择顶点、其他群系、完整 UV／面／GUID、地形／碰撞、原生态与材质保护，以及自定义元数据拒绝、重复／普通 Setup 保留后续人工编辑。`Packed.log` 退出码 0，通过真实打包数据核对、默认镜头对照、新植被室内隐藏、真实摆放／回收及 GPU 整簇遮盖；同时通过 6,936 步原草原路线实走、小兔／昆虫、床边睡觉、五岛继续、旧档拒绝／备份、返回重进及 AA 清理。白天检查不写进度。

默认镜头的修改前对照来自本轮原始网格副本，取景时临时恢复原数据并隐藏新增子树，随后恢复实际 AA 数据；截图沿用项目质量设置、阴影距离、同一正午光照和原共享材质。总览视图的相机距离曾调整以纳入实际阴影范围，精确同镜头对照使用 `Before/After/Game*.png`。此临时夹具仅在隔离验证工程中，不发布。

发布审计核对 29 份目标美术／meta 与最终验证资源一致，2,186 个 GUID 无重复。原预制体 2,786 条记录全部保留，仅新增 26 条；原记录只改 Scenery 子引用和嵌套 MeadowBatches 数组。AA Profile 已有修改及其他人的工作区修改保留。没有增加存档字段或版本迁移。

本轮未构建独立 Player、未测量 GPU 性能，未执行四季专项或全历史存档迁移矩阵。日志、截图、原始网格夹具和验证工程均不入库。
