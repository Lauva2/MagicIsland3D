# 草原岛小径与生态

后续树下植被、花坡与树冠层次精修见 [草原树丛](GrasslandGroves.md)，本页数量为本轮历史记录。

2026-10-19。仅针对拆岛后的草原岛，衔接测试落点、草甸与灵辉古树，修整旧大陆遗留的直角转弯和断头路，并补充西侧、腹地和路肩的生态斑块。其他群系、海洋和原生活区保持原资源。

## 显式烘焙

入口：**Magic Island > Art > Refine Grassland Island Trails And Ecology (Explicit)**。由 `GrasslandIslandMeadowSetup` 在编辑器准备全部路面、花草、小兔及昆虫资源，再写入原 `IslandTerrain` AA 依赖；普通 Setup 不执行。

- 小径采用带圆角的中心线与单层网格并集，路岔没有重复叠面，末端圆收，沿用 `Living Meadow Ribbon` 共享材质和不规则软边。只移除旧道路中完整位于草原岛内的可见三角面，保留原顶点、频道、GUID、bounds 和其他群系面；没有新道路碰撞。
- 新路面完整脚印限制在原不可建设道路预留区，不修改 `CanPlace`、原地面高度、地形几何、树干或建设记录。草原编辑器测试落点从旧路肩向路中心微调约 6.7 米，旧档坐标不挪动；实际传送仍由 GameManager 检查真实胶囊落点。
- 低草按独立固定种子与多尺度斑块分布，避开旧草簇根部；花丛集中在路肩与五处不规则花田。少量矮灌丛／苔石落在原不可建设路肩或花田中，在可建设区域随整株根部遮盖一起隐藏，不改变格子权限。低草沿用已有草甸的轻量叶片构造；花与石头复用 `SourceArt/GrasslandComposition` 的 Blender 导出模板，灌丛复用现有共享模板。
- 低草、花、灌木按 128 米分区合并，通过原 `SeasonalGroundCover.MeadowBatches` 统一风动、季节、室内隐藏及摆放遮盖／回收。没有逐株对象、Collider、Update 或新增存档字段，旧建设始终优先。
- 四处小兔活动区重新选在草原岛内的原路肩，完整身体／跳跃包络检查实际地面、坡度与已有实体。模型复用原 Blender 小兔模板，一个合并网格沿用原 `WorldWaterEcology`、固定步进、受惊、避障、休息、转头和耳朵动作；没有新增动物 Manager 或独立计时器。
- 六处花丛加入蝴蝶与萤火虫，沿用原昆虫模板、共享材质、访花／局部受惊和雨天收敛；新蝴蝶仅使用原 32 个槽位中未占用的相位地址。白天蝴蝶、入夜萤火虫，由原 OceanSurface 时钟驱动，暂停／室内冻结，退出恢复完整属性块。

工具以原预制体中的完整命名子树作为一次性标记，已烘焙后重复执行保留后续手调。新网格使用 `MagicIsland.IslandMeadow.v1` 导入器标记；孤立同名资源和旧道路自定义元数据在写入前拒绝覆盖。保存失败还原原道路／预制体字节并清理本次新建资源。不要删除标记或子树来强制覆盖手调结果。

## 兼容与验证

沿用 [群系岛屿](BiomeIslands.md) 与 [岸线精修](GrasslandIslandCoast.md)，没有新增存档字段、迁移或白天保存入口。此前大陆草甸文档记录的是历史数量，拆岛后有效批次已筛选，本轮数量以实际烘焙日志为准。

- `GrasslandIslandMeadowVerification.BakeAndVerify`：隔离工程烘焙、原地形／碰撞和其他美术保护、旧道路频道与非草原面保留、完整道路预留范围、相位与引用、重复／普通 Setup／人工编辑及自定义元数据拒绝。
- `GrasslandIslandMeadowVerification.Before` / `After`：实际 Packed AA，正常镜头前后对照、角色沿主路和支路实走、小兔／蝴蝶活动、暂停／室内／雨天、旧建设优先、完整属性块清理，并接续五岛传送、床边睡觉、读档、返回重进与 AA 释放。
- `Tools/VerifyGrasslandIslandCoast.ps1`：原地形与建设规则回归。

验证图、日志及独立工程输出到忽略的 `Logs/IslandMeadow`，不入库。更新项目后执行 **Build Prototype Addressables**；编辑器直接运行未打包资源不能代替 AA 验收。

## 本轮实际结果

最终补充 7,928 处草甸组合，其中 502 处花丛、40 处矮灌丛／苔石，合并为 18 个地表批次；连同原批次共 32 个。另有六处访花点、12 只蝴蝶、18 只萤火虫和四处小兔活动区，小兔仍为一个共享网格。只有少量分区批次对象，没有逐株／逐动物对象；全频道完全相同的顶点合并后保留平面法线、根部、风动、相位和双面叶片。

`BakeFinal.log` 退出码 0，通过地形／碰撞、旧路顶点频道／GUID、其他群系美术、原建设预留、自定义元数据拒绝及后续手调／重复 Setup 检查。实走发现古树旧窄堤旁的陡边，最终将转弯点内移到原古树平地，未修改地面；实景发现的少量路面穿地则通过 0.5 米网格与原 4 米地形相同三角面方向修正，不用额外碰撞或抬高地形遮盖。

`FittedAccepted.log` 退出码 0，验证实际 Packed AA、6,936 步 CharacterController 路线行走、四兔跳跃／觅食与活动区约束、蝴蝶访花点及局部反应、暂停／室内／雨天、旧建设覆盖时小兔隐藏、完整属性块清理、真实摆放／回收和 GPU 整株遮盖。接续五岛传送、地图、床边睡觉、五岛位置读档、返回重进、无白天写盘及 AA 释放均通过。最终正常镜头检查包括落点、草甸、古树入口、古树、西侧、生态近景和夜间。

发布审计核对 49 份目标美术／meta 与验证资源逐字节一致，2,178 个资源 GUID 无重复；保留原预制体全部 2,692 条记录，仅新增 94 条。旧记录仅改动两个父节点的子引用、WorldWaterEcology 三个可选生态字段和嵌套 MeadowBatches 数组；原碰撞／Renderer 记录和 AA Profile 已有修改保留。没有增加进度字段或新版本号。

未构建独立 Player、未测量 GPU 性能，未跑全版本存档迁移矩阵和四季美术专项。正式工程仍需重新构建 Addressables 内容；本轮日志、截图和验证副本不提交。
