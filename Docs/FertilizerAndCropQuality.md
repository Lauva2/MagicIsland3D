# 基础肥料与优质作物

工作台新增“农田用品”页：木材 ×2 制作基础肥料 ×5，制作失败不扣材料。肥料进入背包，可存入储物箱；供给和品质处理沿用 Manager、AA 配置及 MVC。

## 操作

- 按 7 或点击底部“7 肥料”，走近后左键点击已耕作农田。
- 空的耕地或未成熟作物均可施肥，每轮种植一次；已成熟时不能施肥，也不会误触收获。
- 每次成功消耗基础肥料 ×1、体力 2。距离过远、体力 / 肥料不足、重复施肥和动作忙碌均不消耗。
- 施肥地块使用略暖的土色；作物信息显示本轮是否施肥，成熟时显示实际品质名称。
- 肥料保留到本轮收获，收获成功后清除。空耕地施肥跨日保留，并应用于下一次播种；背包满时成熟作物、品质和施肥标记全部保留。

## 品质与价格

作物支持普通和优质两档。默认不施肥 10% 优质概率，施肥后 40%。播种时根据存档品质种子、地块索引和该地块种植次数确定结果；生长中施肥使用同一个随机值提高门槛，不再次抽签。品质在本轮种植中固定，读档和收获重试不重新随机。

| 收成 | 普通售价 | 优质售价 | 优质物品 ID |
| --- | ---: | ---: | --- |
| 芜菁 | 25 | 38 | quality_turnip |
| 番茄 | 50 | 75 | quality_tomato |
| 玉米 | 85 | 128 | quality_corn |

普通 / 优质使用独立物品 ID，背包、储物和出货按 ID 分开堆叠与计价。商店增加优质作物选项，只收购、不出售；成功出售仍计入新手作物出售任务。出货箱继续隔夜统一售卖，日报分别显示数量、成交单价与收入。

料理、每日订单和用品配方允许用对应优质作物替代普通作物，优先消耗普通库存。若配方明确要求优质物品，先预留该需求，避免被普通需求的替代处理抢占。作物品质不改变食物恢复体力、订单奖励或产出数量；普通 / 优质鸡蛋的原有替代规则继续有效。

## 管理与资源

- `FertilizerManager` 管理施肥规则和场景反馈，`FarmManager` 管理品质与收获，`ToolManager` 协调距离、动作锁、表现和操作结果。
- `FertilizerConfig` 由 ConfigurationManager 使用 AA 同名地址加载，配置肥料 ID、两档概率与体力消耗。
- CropCatalog 配置每种作物的优质收成 ID，售价及图标来自 ItemCatalog，配方来自 CraftingCatalog。
- 复用 AA 的 FarmHudPanel、CraftingPanel、ShopPanel、CropInfoPanel、InventoryPanel、StoragePanel、ShippingPanel、CookingPanel、OrderPanel。当前 24 份 AA 配置、26 个 UI 预制体。
- 编辑器仅补齐缺失配置、物品、配方和一次性 UI 扩展，保留已经编辑的完整资源。

## 存档

保持仅每天睡觉结算后保存；施肥、制作、收获、交易、料理和订单白天均只更新运行状态，返回菜单不保存。

版本 27 新增 CropQualitySeed，以及每格 Fertilized、Quality、PlantingNumber。品质和施肥随农田一起捕获、校验与恢复，不能通过读档重抽。未知品质、负种植次数、无效种子、未耕地施肥和空地优质收成等拒绝读取。

版本 1–26 按原迁移保留世界、金币和库存，然后将旧农田补为未施肥 / 普通品质，不追溯奖励；已种植地块次数补 1，空地补 0。当前版本重复升级不改变已有品质与肥料。

## 验证

`Tools/VerifyFertilizer.cs` 覆盖概率采样、固定品质、完整提交与重入、同轮限制、空地施肥、跨日恢复、体力不足、背包满及重试、品质材料优先级和版本迁移。

`FertilizerFlowVerification` 使用打包 AA，实际操作工作台、工具栏、耕地 / 播种 / 施肥 / 收获、品质商品、料理、订单、出货及床边睡觉，验证中文排版、白天无存档、版本 27 读档、异常记录、旧档升级和清理。`PauseSleepFlowVerification` 回归暂停、设置独立持久化和固定睡觉快照重试。
