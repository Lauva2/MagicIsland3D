范围边缘羽化，并排除原沙漠入口、雪地入口和靠湖林缘工具的有效范围；完整原景观组件触及这些范围时整体跳过，保留之前的手调。地标周边 45–65 米渐退，海岸、湖岸和北侧溪流留白。草原和林地的开阔区域继续保留可建设资格。

原 `Land` 网格仅调顶点色，位置、法线、三角面、物理高度及原 UV 不变。原 `Landscape` 按现有连通组件识别叶片、仙人掌和砂岩，保留全部棕色树干；不新增／移动固体树干。只对统一初始颜色的组件应用规则，非均匀手绘组件保留。旋转按角度羽化，压缩保持原水平半径，不通过插值相反位置压扁叶团。保留原顶点数、索引、GUID 和未选中顶点。

新增草原／沙漠／雪地小簇只占既有不可建设路肩；林地内部没有新路，只在已经不可建设的斜坡上落点，避开原树干及可建设空地。找不到安全落点时保留该区的树冠／地色优化，跳过新增装饰，不放宽建设检查。整簇包围脚印密集采样、最终每个顶点复查，不增加碰撞、拾取、掉落或逐件脚本。按 128 米区域合并在各群系的 `* biome dressing` 子树，随 IslandTerrain AA 加载，复用 Biome Details 共享材质；没有新材质、光源、纹理动画或 Update。

沙滩只改两个原共享模型。椰树树干、可见／碰撞根、实例位置／旋转／大小、椰果、镜头淡化／风动引用及所有海岸布置保留；两面椰叶的重复顶点保持同位置。原树冠半径不扩大，不重抽椰树、灌木、贝壳或生态。

## 手调与重建

原网格在 UV5（Unity `GetUVs(5)`／`SetUVs(5)`，第六组 UV）记录 -740 与已完成步骤位：1／2／4／8／16 分别对应五个群系，整个网格使用同一个步骤集合。已有标记跳过该步骤；其他自定义 UV5 或不完整标记在写入前拒绝覆盖。UV0–4、之前的沙漠／雪地／林缘标记全部保留，业务与着色器不读取此新标记。

Unity 构建可以剥离未使用的编辑 UV 频道；运行验证直接核对 Packed 网格的顶点集合、数量和配色与本次烘焙资源一致，不要求这些编辑标记出现在打包网格中，不为验证关闭构建优化。

保留 `.meta`、标记和装饰子树。重复执行和普通 Setup 保留结果及后续改形／调色；孤立同名合并网格在写入前拒绝覆盖。整岛显式重建会重置原大陆网格，之后可重新执行本工具，已有小簇子树继续保留人工编辑；不会覆盖原海岸两个独立共享模型。更改规则需明确版本迁移，不能清除标记来自动覆盖成员的美术。

## 验证

资源入口 `BiomePolishVerification.BakeAndVerify` 仅在隔离工程运行，逐区核对地面几何、原索引／UV／alpha、未选中树干和景观、完整碰撞集合、旧层级、树冠圆润轮廓与原半径、两面椰叶对应、新植被法线、装饰脚印和可建设格。覆盖自定义频道拒绝、每区重复、整套重复、普通 Setup 和后续人工改形／调色保留。

`OceanWaterAppearanceVerification.RunBiomeBaseline/RunBiomes` 使用真实 Packed AA、相同镜头与光照，输出清晨／白天／夜间／雨天的五群系远近景和原入口对照，并实走草原／沙漠／雪地／林地路线。独立执行 `StarterIslandWorldFlowVerification.Run` 与 `TerrainCoastFlowVerification.Run` 覆盖大陆、原海岸、实际移动、睡觉／继续、摆放兼容、室内／返回／重进与 AA 清理。输出保存在忽略的 `Logs/BiomePolish`，正式工程需执行 **Magic Island > Build Prototype Addressables** 使用新打包内容。
