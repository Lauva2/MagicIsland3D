# 草原草簇形态与成片分布样区

后续地色与草根贴地融合见 [草甸地色与草根融合](GrasslandBlend.md)，保留本轮几何、株位与活动包络。

继续只处理原草原传送落点附近的 `TouchSample` 样区，中心、范围及拨草／草浪参数沿用原 AA 预制体。前一轮高度和柔和配色见 [草原草丛可见度](GrasslandReadability.md)。

## 表现与维护

入口 **Magic Island > Art > Refine Grassland Meadow Patch Sample (Explicit)**，普通 Setup 不执行。原低草叶保留草根、株位、颜色、全部 UV 和面序，只调整非根顶点及法线，混合直立、弯垂和偏向一侧的轮廓，减少放射状小簇的重复。原株完整水平半径不扩张，样区边缘羽化还原。

通过独立固定种子与连续空间场在样区安全空隙补充小草簇，保留较大的自然间隙；花丛附近增加低草衔接，岩石附近使用较矮草。新草采用三段弯曲叶片，每簇 6–11 片，轮廓、朝向、株高错落。新增草按区追加到原两份 `Meadow undergrowth` 合并网格，不增加对象、Renderer、材质、AA 地址、碰撞或运行组件。叶片根部、季节与物种数据沿用原三个 UV 频道；原 UV0–7 不改，不占额外频道。

新草静态完整半径最多 0.82 米，含风动／拨草的完整水平包络按 1.30 米检查；避开原道路中心、真实实体、花朵／其他非草景物完整轮廓与小兔活动路线，检查实际地面和周边高差。邻草可适当交叠形成连续草甸。新草的根部仍按原建设整株遮盖，旧建设优先、回收后恢复；地形、道路、碰撞、建设资格、其他群系和海洋生态不变。

工具写前完成全部规划与验证，保留原 GUID、顶点前缀中的所有未选中数据、原面前缀与索引格式；只追加新草数据及保守 bounds，容纳最大风力与压弯的组合形变。只在两份网格 meta 追加 `MagicIsland.GrasslandPatch.v1`。未知材质／变换／频道／元数据、不可识别草叶、索引溢出与部分迁移拒绝覆盖；失败还原原网格／meta。完成后的重复入口、旧高度／拨草／花草入口与普通 Setup 保留合法人工编辑。

运行中继续使用原 `SeasonalGroundCover`、`MeadowCoverPresentation`、`WeatherManager` 和共享着色器，不新增 Update、玩法随机源、进度字段或保存入口。原地形预制体保持不变，资源随原 AA 依赖加载；同步后重新执行 **Build Prototype Addressables**。

## 验证

在隔离工程运行 `GrasslandPatchVerification.BakeAndVerify`：核对精确计划、原根部／颜色／UV／面前缀／GUID、未选中的花朵与样区外顶点、新草完整包络和道路间距、索引格式、三段叶片数量和保守 bounds；字节保护其余美术、地面／碰撞及整个预制体。覆盖自定义材质／元数据与部分迁移拒绝，以及重复／旧入口／普通 Setup 保留后续手调。原网格夹具保存在隔离工程的 `Assets/Editor/GrasslandPatchBaseline`，不发布。

`GrasslandPatchVerification.After` 构建真正 Packed AA，复用前一轮同镜头比较程序，输出白天／黄昏／雨天的前后对照，并核对真实打包网格与新增根部。建设测试优先选择本轮追加的草簇，实际确认摆放、GPU 整株隐藏、旧建设重绑和回收恢复。继续覆盖原拨草 GPU 响应／暂停／清除、角色实走、完整通路、室内、床边睡觉、五岛读档、返回与 AA 清理。验证存档隔离，日志与截图位于忽略目录 `Logs/GrasslandPatch`。

## 本轮结果

最终 `Bake.log`、`Packed.log` 均退出码 0。细化 1,049 片原有草叶，新增 375 个小簇／3,243 片三段草叶（22,701 个顶点、32,430 个双面三角面），只写入两份原合并网格和对应 meta。原株颜色／UV／面前缀、所有未选中顶点、地形与碰撞、共享材质、其他美术和整个地形预制体保护检查通过；不新增对象、Renderer 或进度字段。草簇生成有上限，完整运动包络保留道路与小兔通路。

覆盖自定义材质／元数据、单份完成标记的部分迁移拒绝，以及重复、旧入口和普通 Setup 保留手调。最终 Packed 前另模拟“几何已写入、完成标记未写入”的中断状态，确认工具在写入前拒绝二次叠加，恢复原 importer；实际运行与元数据审计仍通过。Unity 后续序列化产生的两份 meta 空字段行尾空格，核对除本工具标记外所有字段与原文件一致后，仅去除行尾空格。

查看本次同镜头白天／黄昏／雨天前后对照，确认草叶混合直立、弯曲／垂尖和侧倾，局部形成相连斑块，仍有道路和自然空隙。首轮画面后进一步降低弯垂叶尖，再烘焙并重新运行完整 Packed 流程，最终 `Preview.png`、`Walk.gif` 与交付资源一致；首轮编译缺少命名空间引用已修正，最终没有 C# 或着色器编译错误。

原拨草 GPU 响应／暂停／清除与实走、6,936 步完整路线、本轮新增根部上的真实建设／GPU 整株隐藏／旧建设重绑／回收、进屋、床边睡觉、五岛继续、返回与 AA 释放均通过；白天不写盘。发布审计仅同步四份目标美术／meta，原 GUID 和预制体、AA Profile 保留，正式资源与最终隔离资源一致。
