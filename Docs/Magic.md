# 魔法启蒙、月光花、唤雨术与岛屿记忆

本模块由 GameManager 统一初始化、暂停、跨日与清理。魔法进度随整份睡觉快照保存，白天不写盘；现行版本为 v31，保留 v1–30 迁移链。

## 游玩流程

右上「魔法（K）」或 K 打开魔法手札。手札中的符文石拓本是启蒙入口，不新增挡路的世界设施，不影响旧摆放与通道。

1. 研读古老符文，领取月光花种子，默认 3 粒。整批容量不足时不发种子、不推进进度；领取后不能重复获得。
2. 从背包选择月光花种子，正常耕地、播种、浇水。默认四次浇水睡觉后成熟，四季都能播种。三个阶段模型随 CropCatalog 的 AA 地址加载，成熟花瓣夜间泛光，不增加局部灯或碰撞。
3. 亲手成功收获月光花后，手札开放研习。失败收获、购买花朵、库存已有花朵、读档、雨水和自然成熟不替代成功收获。
4. 背包交付 1 朵月光花学习唤雨术，优先普通、缺少普通时允许优质。储物箱内的花不直接参与。交付和学习一起提交；之后不可重复扣花或领取种子。

月光花种子可以在原商店补充；普通和优质收成沿用商店、储物与出货规则。默认种子价格 25、普通售价 60、优质售价 90，实际读取 ItemCatalog。原作物、物品与新手任务的 ID、顺序和奖励保持，未扩展料理、订单与居民喜好。

## 唤雨术

关闭手札，把鼠标指向附近已耕作农田，按 R 施法。保留工具快捷键 1–7，施法不改变当前工具或种子选择。中心沿用 InteractionManager 的同一射线深度和实时距离判定；UI、失焦、室内、模态加载/显示及动作锁期间不施法。

默认范围为中心周围 3×3 格，靠边时裁到真实农田边界。仅浇灌已种植、未成熟、当天尚未浇水的作物；空地、成熟和已浇水地块保持。默认一次消耗 6 体力，独立于实际浇水格数。未解锁、越界、过远、体力不足或范围内没有缺水幼苗时不扣费、不启动动作，不播放成功表现。

所有地块和体力一次提交后通知，回调期间拒绝重复施法。不改变时间、天气、作物生长与品质，不消费玩法随机序列；不把范围雨水记成水壶新手任务操作。施法沿用 ToolManager 的动作锁、角色转身与接触时序；成功音效复用水声。接触时显示烘焙符文圈和单套局部粒子雨，最多 128 粒，不逐雨滴创建对象。暂停冻结接触和已有雨滴，室内冻结并由原镜头层隔离；睡觉清理残留施法表现，退出释放实例后释放 AA 依赖。

## 配置与资源

- 新 AA 配置 `Assets/Config/MagicConfig.asset`，地址 `MagicConfig`：魔法作物/种子/普通/优质物品 ID、首次种子数量、范围半径（1–2 格）、施法体力（1–100）和特效地址。
- CropCatalog 追加 `moonflower`；ItemCatalog 追加 `moonflower_seed`、`moonflower`、`quality_moonflower`，不增加 ItemType。
- `Assets/Art/Magic` 保存三阶段烘焙网格、原位预制体、共享材质和 `MagicRainEffect`。花瓣使用 `Magic Island/Moonflower`，MagicManager 从统一昼夜计算 `_IslandMagicNight`，退出恢复原全局值。
- `Assets/Art/Prefabs/UI/MagicPanel.prefab` 为 UIManager 管理的 PopUp MVC；原 HUD 补缺魔法按钮，原商店补缺两个商品按钮，保留已有按钮布局和组件身份。
- 普通 Setup 只补缺失资源、配置项、引用和地址，重复执行保留人工调整。新建网格仅在编辑器烘焙，正常进出不重建。显式 `Rebuild Magic Rain Rune Facing` 仅修正符文圈正面，保留网格 GUID 和其他编辑。

## 保存与兼容

`SavedMagic.Stage` 依次为未研读、种植中、等待献花、已学会，共四个合法值。Capture 深拷贝，未知/缺失记录拒绝整份当前存档。v29→v30 只初始化未研读阶段，不给旧档种子、金币或魔法，不重置原任务、农田、库存与位置；v1–28 继续原迁移后进入该步骤。

MagicManager 在原农务成功事务中记录魔法作物收获，库存观察者收到通知前可见完整进度。研习只修改内存；睡觉捕获到同一份 JSON，失败重试沿用固定快照，不重复发种子、扣花或施法。

## 验证入口

- `Tools/VerifyMagic.ps1 -UnityEditorDirectory <Unity Editor 目录>` 执行 `VerifyMagic.cs` 和海滩迁移回归：纯规则验证种子容量、阶段推进、事务重入、普通/优质消耗、独立快照、非法恢复、范围边界、只浇幼苗、体力失败与实际收获记录。
- `MagicFlowVerification.Run`：独立工程与独立存档，Packed AA，手札 MVC/中文与两种分辨率、真实种植/四次床边睡觉/收获、学习、实时射线与距离、动作/暂停/表现、旧档迁移/非法主档备份、睡觉读档与退出再次进入。
- `PauseSleepFlowVerification.Run`：统一结算、固定 JSON 失败重试、主菜单放弃进度与重新进入。
- `InteractionPromptFlowVerification.Run`：原七工具及普通交互的目标、点击和提示回归。

团队同步代码、配置、预制体、网格、材质、字体与对应 `.meta` 后，按项目常规重建 Addressables；不需要重新随机岛屿。实际执行结果记录在交接说明；本地日志、截图和隔离工程不入库。

2026-10-17 实际执行：纯规则 62 项断言、海滩及迁移回归 163 项断言通过；隔离工程的 Packed AA 魔法全流程、睡觉存档、普通交互与农务美术流程均通过。魔法流程包括特效加载失败、加载中取消、迟到结果释放、面板取消后重开和退出再进入。已检查 1280×720 / 1024×768 手札截图、夜间花朵和白天施法表现；农务美术检查按配置统计模型地址，兼容新增作物。尚未执行独立 Player 构建或性能分析。

## 岛屿的记忆（v31）

学会唤雨术后，K 手札显示下一处探索线索，M 全岛地图同步说明。顺序固定为月光花林、灵辉古树、琥珀遗迹；霜晶石阵仍为景观。三处地标南侧各有一枚蓝色符文，走近后左键聆听，默认交互距离沿用 GameConfig.InteractionReach。提前点击后续符文、室内、过远、UI 遮挡、动作锁或其他模态期间不开始阅读。

故事围绕园丁分享种子、古树保护土地、琥珀记住阳光展开，每处默认两页。显示最后一页后还需“确认收录”才完成；关闭、ESC、加载取消和退出均丢弃本次阅读页码，重新聆听从第一页开始。阅读期间按原手札的加载／显示模态规则暂停世界。

默认奖励依次是月光花种子 ×3、肥料 ×5、月光花种子 ×8，实际读取 MagicConfig.Memories。奖励只放背包，全部容量不足时保留未完成和最后一页，不部分发放；腾出位置后可重新阅读领取。库存和完成数先一起提交，再各通知一次，提交期间禁止重复、下一段奖励和退出重入。重复点击已收录符文不再发奖，也不更改原启蒙阶段或唤雨规则。

MagicConfig 追加三条有序配置的稳定 Id、名称、线索、平面坐标、故事台词、奖励物品及数量；改变顺序／Id 要评估迁移。普通 Setup 只在数组缺失时补默认，保留已有合法配置。当前符文坐标为 (480,637)、(-8,690)、(-420,576)，初始化通过 TerrainManager 的实际地面恢复高度。地图保留原地标中心标记，描述指明符文位于南侧，不提供传送。

新 AA 地址 MagicMemoryRune，位于原 Assets/Art/Magic，包含烘焙石台网格和复用的蓝色符文环／共享材质。MagicManager 持有单份预制体依赖并实例化三枚符文；只加供点击的触发器，装饰网格位于 Ignore Raycast，不改变原地形、碰撞、通道或建设资格，无独立 Update、掉落、材质克隆和运行时网格生成。清理先销毁实例，再释放依赖；加载失败／取消以代次拒绝迟到结果并释放句柄。

快照 SavedMagic.Exploration.Completed 为 0–3；完成数非零要求 Stage=RainLearned。v30→v31 只初始化完成数为零，保留原启蒙和全部旧状态，不赠送物品、不补发奖励。v31 缺失／非法探索记录整份拒绝。唯一保存点仍为床边睡觉，失败重试使用同一固定 JSON；探索中的会话与页码不保存。

验证入口：Tools/VerifyMagic.ps1 包含原魔法、海滩迁移和新增 VerifyMagicExploration.cs；MagicExplorationFlowVerification.Run 使用隔离工程／独立存档和真正 Packed AA，覆盖三地标的实际行走与点击、顺序、容量、原子奖励、取消／重开、部分和完成状态睡觉／读档、v30 迁移／非法主档备份、AA 失败／取消／迟到释放、返回重进与新游戏。独立 Player 与性能分析需另作验证。
