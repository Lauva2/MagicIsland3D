# 草甸野花组合样区

后续小景与草甸衔接见 [草原样区小景](GrasslandEdge.md)，保留本轮花朵与蝴蝶落点。

仅继续细化原草原落点 `TouchSample` 样区，配合前序 [草簇形态](GrasslandPatch.md) 和 [地色融合](GrasslandBlend.md)。减少独立七株花束的重复，混合单株、两三株和少量较密小组；花色以奶白、淡黄为主，少量淡紫点缀。

## 资源与显式维护

入口 **Magic Island > Art > Refine Grassland Wildflower Sample (Explicit)**，普通 Setup 不执行。原样区六份合并网格中识别原 Blender 七株／双株花束，按完整枝条筛疏，仅移除选中整枝的面，保留全部旧顶点、其余原面顺序及原 UV0–7。保留花枝略微缩放、旋转、错高及配色，完整水平范围不扩张，样区边缘平滑衔接。非花草叶、石头／灌木、被筛去但保留的原顶点数据、样区外内容不变。

独立固定种子在实际草甸边缘选择断续花带候选，保留自然空隙；单株与两三株组合从原 Blender 模板整枝抽取，尺寸、朝向错开。完整运动半径按 1.30 米检查，避开道路中心、真实实体、非草景物与原小兔路线，检查实际地面与周围高差。新增花仅追加到原两份 `Meadow undergrowth` 网格，不新增对象、Renderer、共享材质、AA 地址、碰撞或运行系统；沿用原花朵物种、根部、季节与风动频道，不新增 UV。

蝴蝶实际停落点来自独立 `Meadow Foliage` 花丛网格的原花粉顶点，本工具不修改这些网格及昆虫／活动区，也不添加新的停落目标。原地色图、地形、道路、碰撞、建设资格、预制体、运行脚本和其他群系保持。花朵继续随原 AA、`SeasonalGroundCover` 和 `MeadowCoverPresentation` 处理风动、拨草、整株建设遮盖、室内隐藏及清理；不增加存档字段或保存入口。

首次写入前完成源模型、完整枝条、材质、变换、碰撞引用、频道、索引容量与已知元数据验证。只给六份 mesh importer 追加 `MagicIsland.GrasslandWildflower.v1`，不改变 GUID。写前备份，并先持久化首份网格的 `MagicIsland.GrasslandWildflower.Pending.v1`；其他标记完成后最后提交首份完成标记。中断、部分标记和未知数据拒绝再次筛疏／追加；异常还原原资源。完成后的重复入口、旧入口和普通 Setup 保留合法手调。

## 验证

隔离工程 `GrasslandWildflowerVerification.BakeAndVerify` 检查精确计划、完整枝条面筛疏与原剩余面序、原顶点／UV 前缀、原草与非花美术、完整水平包络、样区及道路范围、索引格式和 GUID；字节保护其余资源，特别是蝴蝶停落花粉／生态网格、地色图、地面／碰撞、材质及原预制体。覆盖自定义材质／元数据、进行中／部分完成标记拒绝，以及重复／旧入口／普通 Setup 保留手工调色。比较夹具仅在隔离工程的 `Assets/Editor/GrasslandWildflowerBaseline`，不发布。

`GrasslandWildflowerVerification.After` 构建真正 Packed AA，用相同正常镜头输出白天／黄昏／雨天对照，并核对实际打包网格。接续原蝴蝶／小兔生态、草叶 GPU 拨动／暂停／清除、实际通路、建设遮盖／回收与旧建设、进屋、床边睡觉、五岛继续、返回与 AA 清理，白天不写盘。日志与截图仅在忽略目录 `Logs/GrasslandWildflower`。

本轮隔离烘焙与真正 Packed AA 验证均通过：六组原花束保留 13 枝、筛去 24 枝，新增 64 组共 123 枝，其中奶白 61、淡黄 46、淡紫 16。发布六份网格及对应元数据，共 12 个资源文件，原 GUID、预制体、地色图、蝴蝶停落资源与 AA Profile 保持。

实际运行通过 6936 次角色碰撞移动采样、草叶 GPU 拨动／暂停／清除、生态、建设遮盖／回收、旧建设恢复、进屋、床边睡觉至第二日、五岛继续与 AA 清理；白天未写盘。输出同镜头白天、黄昏、雨天对照和行走动图。未单独执行 Player 构建、GPU 性能分析或完整历史存档迁移矩阵。

同步后执行 **Build Prototype Addressables**，前往草原测试落点查看。仅在当前样区验收，用户确认后再决定推广。
