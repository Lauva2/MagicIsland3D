# 海岸钓鱼

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

按数字键 6 或工具栏“鱼竿”装备鱼竿，走上岛屿东南侧木码头，靠近尽头的垂钓位置，点击码头抛竿。浮漂与鱼线显示在场景中；咬钩后浮漂下沉，面板显示橙色倒计时和“立即收竿”。

## 规则

- 抛竿等待 2–5 秒；咬钩后 2 秒内点击收竿才捕获鱼，截止时刻即失效。较长帧跨过整个窗口也不会自动捕获。
- 捕获成功获得 1 条鱼并消耗 5 体力。提前收竿、超时、取消、距离过远、体力或空间不足均不消耗体力，不获得鱼。
- 抛竿前要求足够体力，背包可容纳任意一种潜在鱼获：至少一个空格，或两种鱼的现有堆叠都有空间。收竿时再次检查实际鱼获容量、体力及距离。
- 开始后暂停游戏时钟、天气效果、移动、镜头、工具和其他弹窗；钓鱼自身计时和海浪继续。可重新抛竿、关闭或 ESC 退出；加载失败不开始会话。
- 成功收竿先同时提交鱼获、体力和已捕获状态，再通知观察者；重复收竿和事件重入不能重复发鱼或扣体力。

| 鱼 | 默认权重 | 商店收购价 |
| --- | ---: | ---: |
| 沙丁鱼 | 70 | 35 金币 |
| 鲈鱼 | 30 | 65 金币 |

权重相对计算，第一版不按季节、天气或时刻区分。每次抛竿选择一次鱼获，等待和收竿不重新抽取。鱼类每格最多 99 条，可以存取储物箱，并用于烤沙丁鱼、鲈鱼蔬菜汤；原鱼不能直接食用、播种或送礼，成品可以食用和送礼。详见 [鱼类料理](FishCooking.md)。

## 商店与保存

商店增加两种鱼的选项，鱼类只收购，不出售。每次卖 1 条，原子扣鱼并增加金币；库存不足或金币达到上限时保持原状态。售鱼不记录出售作物的新手任务。

捕获和售鱼成功后由 GameManager 在睡觉时统一保存，鱼、体力、金币写入同一世界快照。睡觉写盘失败保留结算快照，由日报重试；钓鱼 / 商店面板没有手动保存按钮，不重复执行捕获或交易。

沿用当前版本 27 的背包、储物、金币和体力字段，无需新增存档字段或迁移。抛竿会话不保存，关闭或返回菜单即取消；读档后从未抛竿状态开始，保留最近成功保存的鱼获和交易结果。

## 系统与资源

`FishingManager` 持有配置、纯 C# `FishingState`、AA 鱼竿与钓点实例、浮漂 / 鱼线和反馈。`ToolManager` 负责选择鱼竿，`GameManager` 调度加载、输入、抛竿、收竿、保存和清理。`ShopManager` 负责鱼类收购，`UIManager` 加载 MVC 面板到 PopUp 层。

默认码头根位置 `(14.8, 0, -8.2)`，实际垂钓点由 FishingSpot.ReachPoint 指定，距离检查使用该点。码头提供真实地面和护栏碰撞，预留入口通道；鱼竿保留 FishingRodVisual / Tip，码头保留 FishingSpot、ReachPoint、单位缩放的 Deck、Bobber、Label 和交互碰撞体。浮漂高度与 OceanSurface.HeightAt 同步，LateUpdate 将鱼线连接竿尖和浮漂。FishingPanel 位于左下方，给海面留出视野，详见 [可行走海岸与码头](WalkableCoast.md)。

配置校验鱼类类型、非重复 ID、正权重及收购价、有限时间参数、体力上限、位置和 AA 地址。新增枚举追加在末尾，保持既有类型数值；鱼竿单独映射至 FishingRod 表现，保留原有 Harvest 表现。鱼竿不能操作农田或采集资源。

编辑器只创建缺失配置、模型和面板，一次补齐第六工具按钮与鱼类商店选项；已有完整布局与参数保留。UI 使用中文 TMP、奶油白 / 草绿色主题和同名 AA 地址。

## 验证

`Tools/VerifyFishing.cs` 检查权重与计时边界、完整体力范围、堆叠容量、提前 / 超时 / 取消、收竿再次校验、原子捕获和重入、单向收购 / 溢出、储物及存档字段。

`FishingFlowVerification.Run` 在隔离 Unity 项目构建并运行 AA，检查模型 / 第六工具 / 农田保护、射线 / UI / 范围 / 动作锁、模态暂停、真实咬钩、失败不扣除、两种鱼、读档、新游戏、资源清理与中文排版。海岸接入后的实际行走、钓鱼 UI、浮漂 / 鱼线、白天不保存及清理由 TerrainCoastFlowVerification 覆盖；历史 FishingFlowVerification 的即时保存断言需要按睡觉存档规则调整后再使用。
