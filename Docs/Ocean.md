# 风格化海洋

OceanManager 由 GameManager 创建和调度，在玩家区域恢复后、显示游戏 UI 前通过 AA 加载 `IslandOcean`。海洋预制体位于 `Assets/Art/Prefabs/Environment/IslandOcean.prefab`，地址由现有 GameConfig.OceanPrefabAddress 配置。预制体携带海面、海床、浅滩生态和鱼群的网格、材质与组件依赖。

## Blender 动物模型

四种鱼、海鸥和螃蟹现使用 Blender 制作的八块共享网格：鱼身条纹和鱼鳍、鳐鱼胸鳍与斑点、海鸥头颈 / 羽翼 / 脚趾、蟹壳 / 腿节 / 双钳。基础网格共 10,138 三角面，沿用 `Assets/Art/Materials/Ocean/Ecosystem.mat`、顶点色及现有 GPU 动画，不新增材质、纹理、AA 地址、独立 Update 或存档字段。

源文件位于 `SourceArt/Ocean/OceanWildlife.blend` / `.fbx`；正式局部米制数据为 `Assets/Art/Meshes/Ocean/Wildlife.meshdata.json`。编辑、顶点色 / 关节约定和验收入口见 [海洋源美术](../SourceArt/Ocean/README.md)。执行 **Magic Island > Art > Rebuild Blender Ocean Wildlife (Explicit)** 才更新模型，随后 Build Prototype Addressables。

此操作与 Rebuild Fish Schools / Rebuild Coastal Wildlife 分开：保留 Ocean 预制体、原网格 GUID、鱼群数量 / 成员枢轴 / 旋转 / 缩放 / 色调 / 出生记录、鸟蟹位置及全部活动参数；只在现有合并鱼群网格内替换成员外观。新鱼身必须保持原上下界和水平包络，并在全部鱼群的完整身体初始化通过后才写资源。海床、珊瑚群落、材质和共享着色器保持，普通 Apply / Setup 不覆盖人工模型编辑。海鸥沿用原翼根与头颈形变，螃蟹在源模型中明确提供 100–103 腿部及 110 / 111 双钳关节属性；不通过旧参考模型猜测新网格部件。

## Blender 珊瑚与海底装饰

枝状 / 扇状 / 桌状 / 团块珊瑚、海草、管状海绵、海星和装饰贝壳使用八种 Blender 模型，原位更新 84 个合并群落中的 2,744 件装饰。成员的位置、旋转、尺寸、色调、群落计数及鱼群障碍保持；不改变鱼群、鸟蟹、海床、海面、岸线、材质或存档。草根固定，叶尖沿用统一海洋时间摆动，其他装饰不参与海草形变。

源文件、顶点色 / 权重、原始布局和显式导出入口见 [海底群落源美术](../SourceArt/OceanReef/README.md)。更新使用 **Magic Island > Art > Rebuild Blender Reef Models (Explicit)**，随后 Build Prototype Addressables；普通 Apply / Configure 保留手调，成员布局不匹配时拒绝覆盖。模板限制在原安全半径及上下界内，保持每群一个 Renderer，全海底三角面增加约 7.34%。枝状珊瑚、海草、贝壳沿用 Coast 目录下的共用模板，海岸嵌套模型同时获得新外观，原碰撞与位置保持。

## 目标附近的转向衔接

觅食 / 探索原来在距目标 0.8 米处突然加入固定偏移，现改为随距离连续混入小范围游动；活动及绕行路点改变时，临时 SteeringGoal 平滑接近新目标。受惊目标立即接管，仍由完整鱼身避障、接触分离及既有脱困规则决定实际移动。

朝向使用有角加速度的转弯：逐渐起转，接近目标方向时降低角速度；目标跨过正后方时保留已经采用的转向侧，减少左右反复。普通鱼 / 鳐鱼原最大角速度 135 / 75 度每秒保留。接触修正后的朝向从同一个步开始状态重新计算，不通过后续固定角速度覆盖平滑结果，也不在一次固定步内推进两次转弯惯性。

同时修正避障脱困时反向候选方向可能超过鱼身俯仰上限的问题：反向查询、受阻等待及最终提交均执行原 MaximumPitch 限制，停滞时也不能保留过大的俯仰。沿用原海床 / 波谷间距及身体包络，不放宽安全检查。

AA `OceanSurface.FishAnimation` 新参数：TurnResponseSeconds 默认 0.35 秒（0.1–1.2），TurnAcceleration 默认 540 度/秒²（90–1080），GoalBlendSeconds 默认 0.45 秒（0.15–1.5）。有限数与范围参与原 IsValid 校验，普通配置保留合法手调。YawRate 和 SteeringGoal 仅是 30 Hz 临时状态，暂停不推进、低帧率执行相同步长、退出随鱼群释放，不存档、不重新随机鱼群、不扩大鱼身或水域。

`VerifyOceanFish.ps1` 增加目标阈值连续、起转 / 换向的角加速度上限、持续游动及暂停惯性检查；邻居快照检查改为验证双方从原朝向对称缓转。`FishTurningFlowVerification.Run` 在隔离存档及 Packed AA 中验证实际转向参数、目标换向、暂停和共享资源，并录制 30 FPS 近景。它还用固定相机 / 根 / 光照对照确认新海草的 GPU 摆动及暂停图像。完整生态与生命周期继续由 OceanFlowVerification 覆盖。

2026-10-17 转向验收：48 秒托管回归通过 1,574,422 项实际群游 / 海床 / 障碍检查，另通过 111 项 Boids、9,012 项数量、86,418 项鱼身 / 节律及 25,957 项绕行检查。Unity 2022.3.62f2 隔离工程的 FishTurningFlowVerification 与完整 Packed OceanFlowVerification 均退出 0 并输出 PASSED，包含实际目标换向、暂停图像、鱼身间距、玩家惊扰、室内、失败 / 取消、返回及重新进入；已检查近景序列。海洋预制体仅增加三个转向参数，原生态记录、共享材质和 GUID 保持。未生成独立 Player 或测量 GPU 性能；资源同步后重新构建 AA。

## 海洋范围、地貌与生态

海面从 80×80 米扩大到 **240×240 米**，面积为原来的 9 倍。岛屿附近保留 1 米海面网格，远海采用 4 米间距；海床采用 256 个角向分段、128 个径向采样，覆盖半径 180 米。

`OceanGeography` 使用独立固定种子（默认 73192）生成海床。连续近岛浅滩的基准宽度从 29 米收窄为 11 米，外缘随方向与连续噪声变化；浅滩外新增基准宽约 10 米、水深约 1.6–2.7 米的珊瑚礁台地，再经约 14 米缓坡过渡到深海。18 处更小的离岸沙洲打破环形边界。干燥海岸与玩法地面高度保持原样，同一种子可复现，不消耗玩法随机序列。

生态生成 84 个群落：48 个浅水花园、36 个较深珊瑚群落，当前种子共 716 个小珊瑚、840 个大珊瑚。浅水种植低矮的各色小珊瑚，较深区域使用更大的枝状、扇状、桌状及团块珊瑚，混合海草、海绵、礁石、海星与贝类。按实际水深限制高度并贴合烘焙海床。海水采用低饱和青绿、灰蓝、深蓝渐变，沙底偏暖米色，珊瑚使用粉、紫、杏橙、灰青等柔和颜色；礁区保持比浅滩更深的明度，降低浪花、高光与焦散强度。

群落模型按区域合并为一个渲染网格，生态数量增加时控制渲染对象数量。海草使用顶点权重摆动，鱼群使用独立个体的轨迹和鱼鳍变形。OceanManager 通过 OceanSurface 的统一动画时间驱动生态、鱼群、海鸥和螃蟹，暂停冻结、钓鱼时继续运动，进入小屋和返回菜单沿用现有隐藏 / 释放流程。

## 浅滩与海岸生物

环境鱼保留 **群数、每群鱼数与位置均按种类范围随机生成**，分为银色小鱼、小丑鱼、蝴蝶鱼与斑点鳐鱼四类。分别使用细长银蓝体型、橙白条纹、黄色扁身体型与带斑点的宽鳍轮廓；小鱼在浅水巡游，小丑鱼邻近珊瑚，蝴蝶鱼优先分布于较深礁带，鳐鱼选择平缓沙底低速活动。每条鱼分别巡游、觅食、探索与归群，普通鱼摆尾，鳐鱼缓慢起伏胸鳍，平静时个体间距也会变化。

生成时检查整群鱼的活动包络与实际烘焙海床，为鱼身上下、摆动与波谷预留距离，并包含受惊逃离、个体散开与转向的最大范围；近岸浅水和平台外围均有分布。OceanSchool 记录种类、数量与游动参数，鱼群内部合并网格，使用共享生态材质与顶点色。

海鸥与螃蟹采用独立种子、数量范围与连续随机位置，默认海鸥 **6–10 只**、螃蟹 **5–9 只**，本次种子烘焙为 **8 只 / 6 只**。海鸥保留盘旋、低空掠水和岸边停栖三类，飞行速度、半径变化、扇翼 / 滑翔与休息周期各自错开，转向跟随实际位移并平滑倾斜；螃蟹交替停留观察和短距离横移，腿部随实际位移摆动，停止后逐渐收住步伐。夜间海鸥隐去，雨天飞鸟避雨，岸边海鸥保持停栖。

这些生物是 OceanManager 管理的海洋环境表现，全部由 `IslandOcean` AA 预制体携带依赖，不增加独立 Update、运行时网格生成或存档字段。OceanSurface 统一调度 CoastalBird 与 CoastalCrab，暂停时位置和翅膀一起冻结，室内隐藏，退出游戏时与海洋一起释放。生成代码位于 `OceanWildlifeSetup.cs`，模型资源仍位于 `Assets/Art/Meshes/Ocean/Ecology`。

地貌与生态由 `OceanBiomeSetup` 在编辑器烘焙到 AA 预制体，BiomeArtVersion 记录迁移，当前版本为 8，重复配置保留已有编辑。径向前 88 个采样以 0.5 米间距覆盖浅滩及珊瑚礁台地，生态重新贴合烘焙后的海床三角面。调整 OceanSurface.GeographySeed 后执行 `Magic Island > Rebuild Ocean Geography And Ecology` 可按新种子重新烘焙；该操作重建生成的海床和生态。旧网格及预制体 GUID 沿用，新增网格位于 `Assets/Art/Meshes/Ocean/Ecology`，生态材质为 `Assets/Art/Materials/Ocean/Ecosystem.mat`。

## 鸟蟹数量与活动配置

`OceanSurface.CoastalPopulation` 保存 Seed（默认 31847）、MinimumBirds / MaximumBirds（默认 6 / 10）、MinimumCrabs / MaximumCrabs（默认 5 / 9）。上下限均包含端点，允许相等；海鸥最少 3 只以保留三类活动，螃蟹最少 1 只，各自上限 24。使用单独的 System.Random，不消耗玩法随机数，也不依赖鱼群或地貌种子。

出生点连续随机采样，鸟类家园间距至少 10 米、蟹类至少 6.1 米；完整蟹身、短距巡游和最大 1.9 米逃离预留包络沿实际不规则岸线检查干沙地与码头入口。默认逃离仍是 1.7 米；手调超过预留包络会明确拒绝重建，不能静默截断。若数量过多而放不下全部安全点，同样拒绝整份计划，不能降低实际数量凑数。

修改上述字段后显式执行 **Magic Island > Rebuild Coastal Wildlife**，再 Build Prototype Addressables。此操作只替换鸟蟹节点并给原 Shore Crab 共享网格补腿部关节元数据，保留网格 GUID、海床、珊瑚、鱼群、共享材质和各活动类别的受惊参数；普通 Setup 不重建，进入、读档和进出小屋不重新抽样。生物不是可拾取物、不产生掉落，不增加进度字段（仍为版本 29）。

海鸥独立改变盘旋半径、速度、扇翼频率、滑翔及停栖周期，朝向跟随实际位移并限制转身与倾斜速度。受惊起飞保留当前飞行起点，持续威胁时在海侧绕行，离开后渐落。螃蟹每个周期先停留，再平滑横移到新位置；周期、停留比例、距离、体型和相位分别烘焙。实际位移推进腿部步相，通过 `_CrabMotion` 的 MPB 和原网格 UV 关节驱动八条腿的刚性摆动及法线，身体不跟着整块摇晃，不增加腿部 GameObject、材质副本或独立 Update。运动继续只用海洋统一可暂停时钟，室内隐藏 / 停止，退出随 AA 释放。

验证入口：`Tools/VerifyCoastalWildlife.cs` 检查 1024 个种子的数量端点、复现、间距、完整岸线包络和非法范围；`CoastalWildlifeVerification.Prepare` 会显式重烘焙，应在隔离工程运行，检查保留地貌 / 鱼群 / 材质、重复 Setup、连续运动、独立节奏、腿部数据及暂停 / 恢复。`OceanFlowVerification.Run` 验收 Packed AA、实际玩家靠岸惊扰、原抛竿与鸟蟹惊扰、室内、失败 / 取消加载、返回 / 再进入；输出 CoastalCrabMotion 连续帧与 CoastalPlayerFishReaction 预览。

`CoastalWildlifeVerification.RunVisual` 使用隔离存档与已构建的 Packed AA，录制 60 Hz 起步阶段（CoastalCrabWalk00–31），并在同一身体位置、相同相机与环境时刻关闭腿部动画做像素对照，确认变形实际到达 GPU；本轮退出 0 并输出 PASSED。该入口不重新烘焙资源或保存进度。

2026-10-16 本轮通过 891445 项鸟蟹数量 / 分布断言、2652 项惊扰计时断言；原鱼群 48 秒托管回归通过 1570323 项实际模拟检查（另通过 111 项 Boids、9012 项数量、86415 项鱼身、25957 项绕行检查）。隔离工程的 CoastalWildlifeVerification.Prepare、Packed OceanFlowVerification、CoastalAudioFlowVerification 和 PauseSleepFlowVerification 均退出 0 并输出 PASSED。实际干沙地玩家距被检测成员约 4.85 米，能触发警觉并在离开后恢复；确认 30 群鱼的原有参数 / 出生数据和 84 个珊瑚群落保持。已检查实际鸟类惊扰、蟹类连续步态和浅水鱼画面；本轮未重新构建独立 Player 或测量 GPU 开销。预览和日志仅保留本地 Logs，资源同步后重新构建 AA 即可。

## 昼夜与天气活动

沿用 OceanManager 从真实时钟、WeatherManager 取得的日照 / 晴雨与黄昏权重，交给 OceanSurface 统一调度。保留 FishAnimation 既有 NightSpeed、RainSpeed、TwilightSpeed、NightForaging 和 RainForaging，包括人工调整的合法值；本轮在它们之上增加探索与栖息偏好，不另设日期、天气或随机序列。

小丑鱼与蝴蝶鱼在原烘焙栖息范围内寻找已有珊瑚旁的安全位置，每条鱼有自己的偏移，黄昏逐渐混入目标，夜间进一步减少探索。其他鱼种使用各自原水域内的安静目标，不迁往别的礁区。目标仅影响转向，分离、三维 Boids、绕行、鱼身约束及最终完整区间检查仍全部执行；不瞬移到目标、不扩大 HomeRadius，不越过海面 / 海床或珊瑚。没有可用珊瑚时沿用现有安全点回退。受惊立即采用逃离目标，安全盘旋与脱困不受低活动倍率压制。

FishAnimation 新参数：NightExploration=0.25、RainExploration=0.55（合法范围 0.05–1）；TwilightShelter=0.75、NightShelter=0.85、RainShelter=0.4（合法范围 0–1）。夜间 / 雨天探索参数改变完成觅食后进入探索的概率，跳过时先归群，下一轮巡游按平滑后的觅食频率等待；已经进行的动作不会被环境直接截断。速度、觅食、探索与栖息混合权重继续使用原 TransitionSeconds（默认 5 秒）加群间 / 成员错峰，夜间不完全停止游动。保留原有黄昏短暂活跃参数，同时把活动目标移向安全礁区。

`OceanSurface.CoastalRhythm` 为岸边 AA 节律配置，不增加独立配置地址：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| BirdTwilightFlight / BirdRainFlight | 0.3 / 0 | 黄昏 / 雨天的自然飞行倍率 |
| BirdTwilightForaging / BirdRainForaging | 0.55 / 0.15 | 黄昏 / 雨天的停栖觅食倍率 |
| CrabDayMotion / CrabNightMotion | 0.75 / 1 | 螃蟹白天 / 夜间停留与横移节奏 |
| CrabRainMotion | 0.55 | 螃蟹雨天运动倍率 |
| CrabDayForaging / CrabNightForaging | 0.7 / 1.35 | 白天 / 夜间觅食倍率 |
| CrabRainForaging | 0.35 | 螃蟹雨天觅食倍率 |
| TransitionSeconds | 6 秒 | 活动倍率每单位变化的过渡时间，另加个体相位错峰 |

海鸥黄昏减少自然起飞，空中鸟放慢盘旋并增加滑翔，雨天岸边鸟逐渐收住自然飞行和啄食，理羽与观察仍保留。沿用夜间海鸥隐藏、雨天盘旋 / 掠水鸟隐藏的规则；岸边海鸥在雨天仍响应玩家，起飞只触发一次。螃蟹夜间有更频繁的探沙动作，白天较多观察 / 等待；雨天减少活动。CoastalBird / CoastalCrab 的原 Habits 等待区间、动作时长和 CrawlPeriod / ActivityPeriod 仍为基础参数，活动倍率只调等待推进、动作选择和自然周期，动作本身与受惊恢复按实际海洋秒推进。

CoastalActivityClock 对活动倍率平滑后精确积分为累计活动时间，不用新倍率乘旧总时间，因此切换天气、进入黄昏或低帧率跨过过渡终点都不跳位置 / 相位。每个生物相位决定过渡错峰，当前动作不会因普通环境变化硬切；玩家接近仍按原规则中断。首次绑定立即读取恢复后的环境，后续零秒 Tick 只更新目标，不推进倍率或等待；普通暂停冻结，钓鱼时继续，室内停止，退出 / 失败 / 重进沿原 AA 生命周期清理。所有节律为临时表现，不新增存档字段，保持 v29。

## 海岸避障与安全落点

OceanManager 在世界设施与旧摆放恢复后，为自己的 OceanSurface 绑定 `CoastalWildlifeNavigation` 与 `CoastalWildlifePhysics`。查询只接收所属世界的有效实体碰撞体，忽略触发器、地面和供玩家使用的隐形海岸围墙；玩家以独立体积检查，包含完整移动区间。OverlapBox / BoxCast 各使用固定 64 项缓冲区，满缓冲时拒绝通行；查询读取实际场景，因此晚加载的设施、新摆放、回收和移动角色不依赖另一套障碍注册表。

螃蟹先检查沿岸完整路线，直路受阻尝试内外侧短距绕行，再尝试另一侧安全位置。候选逐段检查干地、码头入口、原有家园活动范围与完整蟹身，全部通过才采用；移动时限速并再次检查下一段，低帧率也不会省去路径段。两侧均不可通行时原地等候后重试。新物体放到生物身上时，可沿离开方向连续脱出，不能瞬移到另一侧或改变玩家建设。默认 WalkSpeed=0.4、FleeSpeed=2.8 米/秒，ReturnStagger=1.1 秒，实际步相继续依据真实位移。

海鸥在下降前检查干地、玩家个人空间、树石 / 家具和其他海鸥的落点预留。默认 LandingSearchDistance=3 米，按原家园附近的有限候选换点；均不可用时在海侧盘旋并间隔重试，安全后渐落。落点只改变临时目标，AA Center 不变；同一预留带拥有者，不能两只鸟同时占用。飞行区间使用包含翅膀、俯仰和倾斜的保守空间，遇障保留短期绕行引导，避免每帧左右切换。默认 FlightSpeed=6 米/秒，ReturnStagger=0.65 秒。各个体相位决定额外安静延迟，持续威胁和持续等候不反复播放起飞音效。

## 玩家靠近与落水惊扰


OceanManager 将实际玩家位置、垂钓位置和可推进的游戏时间交给 OceanSurface，统一驱动反应。海鸥与螃蟹使用家园位置判断持续威胁；玩家仍在附近时保持逃离状态，离开后先等待安静期，再逐渐恢复，避免循环起飞 / 落地。

- 停栖海鸥在玩家约 3.2 米内受惊，约 0.65 秒展开翅膀、向海面升空；玩家离开后等待 4 秒，再用约 4 秒飞回，额外停栖 8 秒。低空海鸥也会回避附近玩家，高空海鸥照常盘旋。雨夜沿用原有避雨与隐藏规则。
- 螃蟹在玩家约 2.2 米内受惊，约 0.35 秒沿远离玩家的岸线方向横移，最多约 1.7 米。轨迹随岸线弯曲并保持原有离岸距离，完整逃离与恢复过程都留在干沙地，运动高度继续贴合海岸。玩家离开后等待约 2.5 秒，再用约 3.5 秒恢复。
- 首次在鱼群约 7 米内开始垂钓会惊扰鱼群；FishingManager 只在成功抛竿、浮漂入水后通过 OceanManager 再发出一次落水刺激，失败或忙碌抛竿不会触发。鱼群平滑加速并远离落点，鱼群内每条鱼沿自己的方向分散、略微转向，随后逐渐聚拢。安静期约 1.8 秒、恢复约 3.2 秒；持续等待浮漂不会每帧重新惊扰，重复成功抛竿可延长受惊。
- 玩家靠岸时检查每条鱼的实际模拟位置，水平距离默认 6.5 米且高度差小于 1.65 米才进入持续威胁；以首次感知的位置保留 0.8 米释放余量，鱼游开后不会立即返回再反复受惊。玩家离开后等待原安静期，再逐步归群。普通靠近不增加落水计数、不发水花，不改变完整鱼身的安全活动范围。停栖海鸥受惊升空后在海侧小范围盘旋，持续威胁只计一次起飞；落回后保持原额外休息期。

各组件 Inspector 的 Disturbance response 提供距离、速度和恢复时间参数。鱼群逃离与散开距离限制在已经烘焙验证的安全范围内（分别最多 0.85 / 0.38 米）；扩大上限时需要同步修改烘焙包络并重建。每条鱼的中心与分散相位保存在网格第二 UV 通道，OceanEcology 通过每群的 MaterialPropertyBlock 驱动变形，不拉伸鱼身、不复制材质。

WildlifeAlarm 的受惊强度、安静期与恢复均由同一暂停时钟推进。暂停和普通模态面板冻结位置、翅膀、散开程度和恢复计时；垂钓中继续推进，室内停止刺激和推进，返回菜单与 AA 实例一起释放。反应是临时环境状态，不写进度存档。

## 海岸互动特效

`OceanInteractionEffects.prefab` 位于 `Assets/Art/Prefabs/Environment`，作为 `IslandOcean` 的嵌套预制体，通过海洋 AA 实例携带模型、材质与着色器依赖。OceanManager 沿用成功抛竿的落水通知，OceanSurface 统一推进特效，不增加独立 Update 或运行时粒子物体创建。

浮漂入水生成两圈错开的扩散涟漪与八颗小水滴，约 0.3–1.4 秒内消散。涟漪着色器读取现有海浪时间、高度和水位，每个顶点贴合实际起伏，避免只把整圈固定在一个平面上。受惊鱼群移动时产生短暂、断开的细水纹；鳐鱼滑行时在尾后产生浅淡的水下沙尘，其位置查询实际烘焙海床三角面。螃蟹逃离时留下三颗细沙粒和一个小沙尘团；雨天省去岸边尘团。

预制体预置 **84 个复用槽位**：10 个涟漪、24 个水滴、12 个鱼群水纹、12 个水下沙尘、16 个岸边沙粒、10 个岸边尘团。槽位满时按种类复用较早的粒子，反复抛竿不会增加对象数量。各类使用共享模型 / 材质，透明度、时间和日照通过 MaterialPropertyBlock 控制，运动结束后归还槽位。

生态特效默认只在距玩家 26 米内生成，鱼群 / 鳐鱼 / 螃蟹分别约每 0.48 / 0.65 / 0.23 秒允许一次。Inspector 可调整这些距离、间隔与水花、水纹、沙尘强度。水下沙尘在透明海水之前绘制，水面涟漪与沙粒在海水之后绘制；低透明度和短寿命保留浅滩与生物轮廓。夜间统一压暗。

所有寿命、运动与发射间隔使用同一个可暂停时间。垂钓时继续，暂停时冻结，室内随海洋隐藏并停止推进，返回菜单时随 AA 实例释放。特效不写存档。`OceanInteractionEffectsSetup` 只在缺失时创建资源，EffectsArtVersion 当前为 1；重复配置保留特效预制体和参数，地貌使用 BiomeArtVersion 8。

## 海水表现

`Assets/Art/Shaders/IslandOcean.shader` 适配当前内置渲染管线和斜俯视正交镜头。依据镜头深度与海面的距离，平滑混合浅海青绿、中层碧蓝和深海蓝色；透明度随水深渐变，近岸保留更多真实海床、珊瑚和礁石颜色。正交镜头使用线性的近远裁剪距离还原深度。

海面保留两组轻微起伏，并用多组流动细波纹计算法线，形成随视角变化的天空反光。阳光反射读取 WeatherManager 的实际太阳方向、颜色和强度；正交镜头使用平行视线，平移镜头不会改变反光方向。雨天增加细碎波纹，压低阳光反射，夜晚阳光强度为零时不会残留太阳高光。

岸边浪花沿水深等值线向沙滩推进，分成窄浪线、碎泡沫和贴岸消散三部分。旋转叠加噪声打散浪花，减少原先单层噪声产生的方块状白边；浪线和浅水光纹使用屏幕导数柔化边缘。浅水中增加缓慢流动的网状光纹，随水深和日照减弱。

碎浪限定在默认约 0.23–0.57 米的贴岸水深内衰减，避免连续浅水平台在浪峰时出现大片白色泡沫；浮漂涟漪和生物扰动使用独立的小范围特效。

海水仍使用单个透明渲染 Pass，通过程序法线与颜色模拟天空反光和光纹；未增加 GrabPass、实时平面反射或全屏后处理。

OceanSurface 通过 MaterialPropertyBlock 设置动画时间、日照、雨量及太阳数据，不修改共享 AA 材质。OceanManager 读取现有时钟和天气：昼夜调整海色，夜间继续使用已压暗的水色和泡沫，雨天减弱波光；普通弹窗和暂停冻结动画，垂钓会话中继续推进海浪，场景切换时停止推进。进入小屋隐藏环境，出门继续使用同一个实例。

早期 `OceanSetup.UpgradeWater` 曾向原海床追加外缘坡面；当前由后续 OceanBiomeSetup 生成扩大后的不规则海床，沿用原网格身份和可行走海岸高度。水色与透明度依照真实地形深度共同过渡。

## 个体鱼群动画

`OceanFishSteering` 使用固定 30 Hz 步长，以三维 Boids 算法逐鱼计算实际位置、速度、朝向和行为状态。`OceanFishBoids` 负责分离、对齐和聚合，巡游提供较弱的共享目标。每步先捕获所有成员的位置和速度，再计算全部邻域；鱼身接触修正也先汇总再提交。渲染按剩余时间在前后两步的位置、偏航和俯仰之间插值，避免 60 / 120 FPS 画面直接跳到 30 Hz 位置。每条鱼通过 UV2 保留独立中心和相位，UV3 保存建模朝向和种类；先还原自身坐标，再进行尾部或胸鳍变形、俯仰和转向。每群仍只有一个合并网格和共享材质，姿态通过 MaterialPropertyBlock 的 `_FishPoses` / `_FishAttitudes` 固定数组写入，无逐鱼 GameObject、逐帧对象创建或材质克隆。CPU 顶点验证与着色器使用相同的俯仰顺序。

所有动画和行为依赖 OceanSurface 的可暂停时钟；受惊仍由现有 WildlifeAlarm 控制，暂停、室内隐藏、AA 释放和睡觉保存约束沿用现有流程。鱼群的 HomeRadius 固定在自己的栖息地，边界限制包含鱼身半径；巡游、觅食、探索和受惊都不会离开这个范围。Renderer 的实例包围盒覆盖整个安全水柱，不改写 AA 共享网格的包围盒。该表现属于环境生态，不参与背包鱼类、钓鱼掉落或进度存档。

OceanSurface 首次初始化时读取 AA 中已有海床网格，缓存与完整栖息圆相交的三角形最高点；水柱上界扣除海浪的最大振幅和安全余量。读取已有烘焙数据不会生成或覆盖地形。各鱼按身体厚度和俯仰后的保守包络收窄可用水层，再错开相位缓慢升降；浅水自动降低振幅和俯仰，鳐鱼保持低位小幅起伏。旧的合法参数与美术资源保留，旧出生点若重叠则在同一栖息体积内确定性地分开。无法容纳完整鱼身或没有安全出生点时初始化失败，由 OceanManager 清理 AA 实例与镜头状态。

`OceanEcologyPolishVerification` 检查两种深度生态、珊瑚数量、柔和配色的明暗顺序、鱼群个体相对距离变化、不同朝向、暂停和合批。`OceanFlowVerification` 检查的是变形后的实际顶点水深与包围盒，包含平静及受惊状态，并通过真实 AA 流程渲染鱼群连续帧和两种珊瑚群落。

## 数量配置、觅食与避障

OceanSurface 的 FishPopulations 同时配置每个鱼种的群数范围 MinimumSchools / MaximumSchools，以及每群鱼数范围 Minimum / Maximum，随机端点均包含。鱼群总数由各鱼种抽取结果相加，不再固定为此前的 32 群。

| 鱼种 | 随机群数 | 每群随机鱼数 |
| --- | --- | --- |
| 银色小鱼 | 6–10 | 6–10 |
| 小丑鱼 | 6–10 | 3–5 |
| 蝴蝶鱼 | 6–10 | 3–5 |
| 鳐鱼 | 4–6 | 1–2 |

群数范围满足 1 ≤ MinimumSchools ≤ MaximumSchools ≤ 16，四种合计最多 64 群；单群鱼数仍满足 1 ≤ Minimum ≤ Maximum ≤ 32。默认配置下总群数为 22–36；默认 FishSeed=90421 本次生成 30 群、142 条鱼，这只是该种子的结果。数量计划先完整校验，再按稳定鱼种顺序使用独立 System.Random 生成，不改变配置或消耗玩法随机数。

FishSeed 独立于 GeographySeed，控制群数、鱼数、相位、栖息地与成员出生点。位置在现有海床和生态斑块上连续随机取样：银色小鱼留在浅水，小丑鱼靠近珊瑚，蝴蝶鱼使用较深礁坡，鳐鱼选择平缓沙底。候选位置除了地形 / 浪高 / 障碍检查，还实际初始化整群三维鱼身及间距；过于拥挤则继续抽取同一数量计划，不能靠减少鱼数或放宽边界来通过。

调整 FishSeed 或上述范围后，显式执行 **Magic Island > Rebuild Fish Schools**，只重新烘焙鱼群合并网格和出生数据，保留原资源 GUID、海床、珊瑚、鸟蟹、材质及原鱼种群游 / 受惊参数。安全候选全部准备完成后才提交鱼群网格；失败清理临时网格和预制体内容。旧的未引用 School 网格保留，不擅自删除资源。改变整体地貌才使用 Rebuild Ocean Geography And Ecology。随后重新 Build Prototype Addressables。

正常进入、读档和进出小屋复用同一份烘焙结果，不重新抽取。种子相同数量及位置可复现，换种子产生另一套安全分布；表现状态不写进度，存档仍为 v29。普通 Setup 保留人工调整，不自动重生成。

编辑器从每块实体珊瑚、礁石及海绵的源顶点烘焙保守水平圆和上下高度。三维导航从 OceanSurface 的完整烘焙障碍中筛选附近对象，保留不同高度的障碍，避免沿用旧固定水层筛选后漏掉上方珊瑚。Boids 提前预测迎面接近，分离范围包含完整鱼身和转向余量；另有独立的接触约束，即使关闭社交权重也不允许身体穿入邻鱼。提交前检查整个三维位移区间，低帧率不会跳过细珊瑚或中间高度的障碍。

受阻后保持短时脱困方向，平滑转向，再重新规划；不会每步突然切换横向速度。等待避让时允许经过相同安全检查的小幅浮力起伏。正常速度按加速度变化，紧急避障和接触可安全减速；实际位移方向决定平滑朝向和俯仰。鱼群不添加物理 Collider。

### 正常镜头可见性与独立 Player 验收

OceanManager 初始化海洋时先准备一次完整姿态与包含水深的栖息包络，再绑定所属玩家镜头的 `Camera.onPreCull`。模拟阶段仍对所有鱼执行原有 30Hz 行为、分离 / 接触、三维避障与距离约束；渲染阶段在镜头跟随完成后，只为与视锥相交的完整栖息包络整理插值节点并上传 MPB。屏幕外不积攒补算时间，镜头返回时第一次剔除前就上传当前姿态，暂停且时间未变时跳过重复提交。

不使用 Renderer.isVisible，避免 Scene View 或其他镜头干扰。沿用原完整鱼身裁剪范围，不修改共享网格 / 材质，也不因世界距离降低可见鱼群帧率：当前为正交镜头，世界距离不等于屏幕尺寸。通用生态 MPB 循环在初始化时缓存非鱼群渲染器，鱼群不再被重复更新。回调归 OceanManager 持有，Clear / 失败 / 返回 / 重新加载时解除；无绑定镜头的独立规则验收继续使用完整提交路径。

### 障碍分流与逐渐归群

鱼接近目标方向上的实体珊瑚 / 礁石时，为自己准备临时弧段路线。成员交替首选两侧，首选不通则尝试另一侧；每一段先用现有完整鱼身导航检查所有障碍、海床 / 水面和栖息边界。两侧都不通则保留原有局部避障及脱困，不能为分流扩大活动范围。无高度交叠的珊瑚不触发绕行。

采用后保留绕行侧，不跟随邻鱼每步更换方向。起步按个体相位短暂减速，让鱼先后通过；绕行时降低对齐与聚合，分离和最后的同时接触检查保持不变。通过或超时后，临时引导和群游权重按个体节奏逐渐恢复，朝向 / 加速度继续使用原上限。落水惊扰立即取消临时引导，优先逃离。

当前已验证的绕行障碍由路线接管转向，避免局部切线力与选定的绕行侧互相拉扯；其他障碍和边界仍提前避让，最终每一步位移仍检查全部障碍，碰撞保护不跳过当前珊瑚。到达路线点附近或已经越过其径向平面时推进引导，避免擦过点后回头追点。
