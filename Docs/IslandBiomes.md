# 初始岛屿自然群系

> 2026-10-17：大型地图实装后，以 [大型初始岛屿](StarterIslandWorld.md) 为当前布局。本页保留早期 40 米原型群系参数与验证背景；原型沙漠／雪地模型组已隐藏，生活区改为草原与沙滩，正式群系转到北侧大陆。旧尺寸和微型群系验证不能代替大地图验证。

同一座初始岛屿包含草原、沙漠、常年雪地及外围沙滩。当前沿用原岛屿尺寸和岸线：中部农田 / 村落为草原，西侧为暖沙与仙人掌、砂岩，北侧为雪地、覆雪小松及雪岩。区域以连续权重混合，保留海岸沙带；这是常驻地貌，不以春夏秋冬替换，也不新增温度、降雪天气、作物限制或掉落。

## 资源和参数

`IslandTerrain.Biomes` 随原 `IslandTerrain` AA 预制体加载，不增加配置地址或单独异步链。DesertCenter / DesertRadii、SnowCenter / SnowRadii 和 EdgeBlend 控制分区，DesertColor / SnowColor 控制色板；默认中心为 (-13, -1) / (2, 14)，半径为 (8, 13) / (13, 8)。原点附近 7.8 米方形核心保留草原，外围至 10.8 米平滑过渡，最大 12×12 农田及原设施位置保持。

`BiomeArtVersion=1` 标记首次烘焙完成。**Magic Island > Art > Rebuild Island Biomes (Explicit)** 才重新应用上述空间、颜色、种子和装饰数量；随后执行 **Build Prototype Addressables**。普通 Setup 仅首次补缺，已烘焙后保留合法参数、模型、材质及手工布置。调整群系参数、原始地面颜色或显式重建四季地表后，应再执行群系 Rebuild，使地图、可见地表与区域筛选一致。

- `Assets/Art/Meshes/Terrain/Biomes/Biome Land.asset` 是单独的表现网格。保留原始顶点及沿岸全部三角形，只细分内部平面扇区，使颜色能在岛内平滑分区；原 `Island Land` 和 `Sea Boundary` 碰撞网格、GUID、陆地 / 海床高度及码头入口保持。
- `Island Biome Ground` 着色器的 UV0.x 只标记可受四季染色的草原比例。沙漠和常年雪地保留各自配色，仍接受同一昼夜及天气光照；原海岸 / 海洋材质不修改。
- 四种共享装饰网格为 Cactus、Sandstone、Snow Pine、Snow Rock，共用一份 `Biome Details` 材质。ScenerySeed 默认 60317，DesertPatches / SnowPatches 默认 18 / 22；最多合计 45，完整区域放不下或超过原地表 160 簇预算时拒绝计划。
- 装饰在编辑器烘焙，沿用原 `SeasonalGroundCover` 的绑定、道路 / 设施 / 最大农田 / NPC 通路和建设避让。原 107 簇地表记录保留，新增 40 簇仅作为地形预制体的覆盖；原四季地表源预制体不重建。实例数量区间相应增加，默认实际 147 簇；可见数量另受安全检查限制。
- 原四季花草只在草原权重大于 0.5 处显示。沙漠 / 雪地装饰四季使用同一网格，不加碰撞、交互、单独 Update、材质副本或运行时网格。成功建造遮盖装饰、回收恢复，旧建设优先；室内隐藏、退出解除原地表订阅并随地形释放。

## 新游戏与存档

NewGameSpawn 默认地形局部坐标 **(1, 0.05, -15.8)**，位于南侧干沙滩。只在没有载入快照的新游戏中传给既有区域恢复流程；TerrainManager 根据真实地面解析高度，HousingManager 检查完整角色碰撞，镜头沿原流程立即跟随。位置被实体挡住时沿用安全落点回退，不开放危险出生点。

继续游戏仍使用快照中的 PlayerArea 和位置；进出小屋及睡觉后的室内清晨位置不受新出生点影响。不改 IslandLayout、旧摆放、NPC 路线或存档字段；保持存档版本 30、26 份配置和 29 个 UI。新游戏第一次实际睡觉前不覆盖旧存档。

地图底图读取同一份 AA 群系设置，以草绿、暖沙、雪白显示分区；当前位置显示草原 / 沙漠 / 雪地 / 沙滩。原设施标记、真实道路、位置投影与点击不传送规则保持，室内仍以小屋门口为距离起点。新增文字在原 IslandUI 字体中补字形。

## 验证

- `Tools/VerifyIslandBiomes.ps1`：非法数值 / 配色 / 维度 / 出生点拒绝、固定分区、旧岛内地面及完整最大农田、合法手调色板。
- `IslandBiomeVerification.Run`：实际 AA 预制体、连续分区、表现网格与原碰撞一致、面数预算、完整装饰包络、共享材质、普通 Setup 保留人工资源和中文字形。
- `IslandBiomeFlowVerification.Run`：隔离存档和真正 Packed AA，沙滩出生 / 镜头、实际全角色脚印可达区域、GPU 草原四季染色与雪地 / 沙漠保色、地图显示、建设遮盖与回收、室内和真实睡觉、保存的旧室外位置恢复、新局保留旧档、返回及重新进入。
- `TerrainCoastFlowVerification.Run` 与 `PauseSleepFlowVerification.Run`：原海岸完整移动 / 碰撞、设施 / NPC / 旧摆放、码头、失败 / 取消及睡觉 / 读档 / 固定快照重试回归。
- `SeasonalFlowVerification.Run`：原四季地表、建设避让、飘叶暂停 / 砍树，以及实际跨季睡觉和冬季读档回归。

2026-10-17 已在 Unity 2022.3.62f2 的隔离项目执行上述检查：纯规则 5600 项、资源检查 118665 项通过，群系实景、海岸、睡觉及四季流程均通过。额外执行 `IslandBiomeVerification.VerifyRebuild`，确认连续显式重建结果稳定，普通 Setup 保留人工网格颜色。实景检查使用真正构建的 Packed AA 和 D3D11 渲染；最后将验证过的模型、共享材质、地形预制体和字体同步回主项目，保留原资源 GUID、351 个原预制体记录和旧字形映射。主项目的 AA 产物仍需按正常流程重新构建。
