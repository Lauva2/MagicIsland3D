# 草原地表层次、低草与花坡过渡

2026-10-19。在既有花色群落、树丛和小径基础上补齐贴地层，继续只优化草原岛。

## 入口与资源

显式入口：**Magic Island > Art > Refine Grassland Ground Layers (Explicit)**。普通 Setup 不执行。新地表批次和地面材质均属于原 `IslandTerrain` AA 依赖，沿用原加载、室内隐藏、建设遮盖和退出清理。

- 独立固定种子 `208731` 在编辑器烘焙不规则低草斑块，混合密集、稀疏与留白。低草为短而宽的折叶，原花坡外缘混入少量较矮的双茎小花，小花复用原 `SourceArt/GrasslandComposition` Blender 模板的完整分支；既有花草、石头、灌丛和树冠不改形或重排。
- 全脚印检查原道路、岸内距离、实际地面／坡度、实体和小兔活动区；新根部最大水平半径 0.86 米，继续使用原 1.85 米建设遮盖。新网格按 128 米区域合并，地表批次总数限制 64；无逐株对象、运行时生成、Collider、Update、灯光、掉落或存档字段。
- 共用既有 `Natural Meadow Cover` 材质，在新网格的 UV0 使用既有花／草负权重编码、原风场相位，UV1 为根部 XZ，UV2 为地面高度／季节权重。原网格全部 UV、GUID、碰撞和建设资格保留，不再占用其额外频道。
- 新 `MeadowUnderlay.png` 为 512×512、线性／Clamp／无 mipmap 的 RGBA 分布图：R 控制草甸明暗斑块，G 控制少量枯草／路肩暖土，B 为既有树冠下的柔和地色，A 在草原内陆渐入。分布图与植物疏密共用固定空间采样；保留原地色和季节表现，表现色变化不模拟额外光源。
- `Meadow Underlay` 为独立共享材质，复制原草原地面材质参数和原草甸纹理，使用 `MagicIsland/Meadow Underlay`。仅替换 `Grassland island` 原地面 Renderer 的材质引用，保留全部几何、法线、顶点色、UV、碰撞及其他群系材质。海岸淡出与原湿沙表现继续保留。

计划、脚印、源模板、原材质和资源冲突全部检查后才写入。新增资产 importer 使用 `MagicIsland.GrasslandGroundLayers.v1` 标记；孤立同名资产、原地面自定义材质拒绝覆盖。已有完整子树、重复入口和普通 Setup 保留后续手调；原花草细化入口识别并保留本轮新增批次。失败恢复原预制体并清理本次新建资产。

## 验证

`GrasslandGroundLayersVerification.BakeAndVerify` 在隔离工程核对全部既有美术文件，覆盖原地形、完整碰撞、道路、花草、其他群系、生态、原纹理／材质、UV 与 GUID；检查新网格根部范围、法线和拥有者。以临时自定义地面材质检查写入前拒绝，以后续材质手调检查重复入口、旧花草入口和普通 Setup 保留编辑。

`After` 使用真实 Packed AA，核对新网格、共享地面着色器和纹理依赖；同一默认镜头 42°／Size 7／距离 18 米对照白天、黄昏、雨天的花坡、树丛、入口和草甸。修改前取景仅临时隐藏新植被、恢复原共享地面材质，完成后立即还原实际 AA 数据。检查统一风动、暂停稳定帧与室内隐藏，接续原路线实走、生态、实际新草簇建设遮盖／回收、睡觉／继续及 AA 清理流程；不在白天写进度。

输出保存在忽略目录 `Logs/GrasslandGroundLayers`，日志、截图与验证副本不入库。正式工程同步后执行 **Magic Island > Build Prototype Addressables**。前序花草资源见 [GrasslandFlora.md](GrasslandFlora.md)。
