# 草甸地色与草根融合样区

后续野花形态、疏密和花色组合见 [草甸野花组合](GrasslandWildflower.md)，保留本轮地色与草叶渐变。

继续只处理原草原落点附近的 `TouchSample` 样区。前序 [草簇形态与成片分布](GrasslandPatch.md) 的模型、株位、数量和运动参数保持。

## 表现与资源边界

使用现有 `MeadowUnderlay.png` 分布图及原 `Meadow Underlay` 材质／着色器，根据样区周边实际草簇根部、株高和范围烘焙密度。密草区偏深灰绿，空隙略偏浅黄绿，花丛与石块／灌丛附近加入柔和过渡；仍按原季节颜色与真实光照显示。只修改原分布图的局部 RGB，分辨率、全部 alpha、其余像素及原手绘底图保持，局部与原值混合。只选择完整双线性采样范围位于样区内、并避开道路中心的像素，不让纹理插值影响样区外或道路中心。

原六份样区草地合并网格仅修改已标记草叶的 RGB。按实际地面上方高度在约 0.20 米内从根部稍暗过渡到叶尖稍亮，样区边缘平滑还原。保留 alpha、花朵、石头、灌木、未选中和样区外顶点颜色，以及全部几何、法线、UV0–7、面、bounds、GUID、株位和数量。地面几何／碰撞、原预制体、材质／着色器、其他岛与海洋不改；不增加纹理、Renderer、对象、AA 地址或运行系统。

颜色与分布图随原 `IslandTerrain` AA 依赖加载；草根仍沿原 `MeadowCoverPresentation` 建设遮盖与拨草，风动、季节、室内隐藏和释放由原拥有者处理。地色是烘焙美术底层，不随白天临时建设重新生成；不新增 Update、材质副本、玩法随机源、进度字段或保存入口。

## 显式维护与中断保护

入口 **Magic Island > Art > Blend Grassland Meadow Ground Sample (Explicit)**。须先完成原草簇样区。普通 Setup 不执行；合法材质参数和原分布范围从实际材质读取，不重新应用默认值。首次检查原资源拥有者、地面／草地材质引用、分布图导入参数、已知元数据、模型频道与完整足迹，未知材质、替换纹理、变换、导入设置、元数据或不完整迁移拒绝覆盖。

完整计划通过后备份目标资源，先在原分布图 importer 写入 `MagicIsland.GrasslandBlend.Pending.v1`，再保存颜色与像素，并给六份网格追加 `MagicIsland.GrasslandBlend.v1`。最后才将分布图标记提交为完成。异常还原全部原文件；若进程中断，进行中标记或部分完成标记会阻止再次叠色。完成后的重复入口、旧入口和普通 Setup 保留后续手工调色／手绘。旧草簇工具认识本轮追加的合法标记，原模型不完整检测继续有效。

同步正式资源后重新执行 **Build Prototype Addressables**。本轮仅处理当前样区，用户确认后再决定推广。

## 验证入口

隔离工程运行 `GrasslandBlendVerification.BakeAndVerify`：检查全部原几何／法线／UV／面／bounds／GUID、草叶渐变与非草颜色保护；逐像素核对计划、原 alpha、未选中像素以及双线性采样的道路和样区边界；对其余美术（包括原预制体、地面碰撞、材质／着色器及其他群系）做文件保护。覆盖自定义地面材质／分布元数据拒绝、进行中／部分完成标记拒绝，以及手工网格调色、分布图手绘在重复／旧入口／普通 Setup 中保留。

`GrasslandBlendVerification.After` 使用真正 Packed AA，GPU 读取打包分布图并与最终作者资源核对，排除旧 AA 内容；复用正常镜头白天／黄昏／雨天前后对照。修改前只临时切换比较网格和地面实例 MPB 的纹理引用，完整恢复原 MPB，不改共享材质。继续验证原拨草、暂停、真实新增草簇建设／遮盖／回收、完整通路、室内、睡觉、五岛继续、返回与 AA 清理。存档隔离；夹具仅在隔离工程 `Assets/Editor/GrasslandBlendBaseline`，日志与截图仅在忽略目录 `Logs/GrasslandBlend`，均不发布。

## 本轮结果

`Bake.log`、最终 `Packed.log` 均退出码 0。按样区附近实际 862 簇草、18 簇花石／灌丛采样，调整 848 个局部分布像素和 32,516 个草叶颜色顶点。发布六份原网格及 meta、一份原分布图及 meta，共 14 份资源；没有改变几何、法线、UV、面、bounds、株位、数量、预制体、材质／着色器或存档。原 GUID、AA Profile 及其他美术文件保留。

烘焙验证逐项核对计划颜色／像素、全部 alpha、未选中像素、完整双线性采样的道路／样区边界、非草与样区外颜色，覆盖自定义材质／元数据、进行中／部分完成标记拒绝。后续网格调色与分布图手绘在重复入口、旧入口和普通 Setup 后保持。

实际 Packed AA 中 GPU 分布图与最终作者纹理一致，并与原图不同；白天／黄昏／雨天采用同镜头对照，确认草根稍暗、叶尖略亮、局部地色衔接较轻，保留道路和原光照。原拨草 GPU 响应／暂停／清除与实走、6,936 步完整路线、新草簇真实建设／整株遮盖／旧建设重绑／回收、室内、床边睡觉、五岛继续、返回及 AA 释放全部通过；白天没有写盘。

首轮 Packed 被旧地表暂停截图的字节全等断言拦下，实际仅 1 个像素相差 1/255。改为项目既有的静止帧标准（至多 4 像素、每通道至多 1/255），并增加 WindSimulation 时钟和着色器风时钟的精确冻结检查后，完整复跑通过。不是通过放宽运动检测来掩盖暂停问题。最终运行没有 C#／着色器编译错误。

`Preview.png` 左侧调整前、右侧调整后，`Walk.gif` 为本次实际运行的行走预览；它们与资源审计保留在忽略目录 `Logs/GrasslandBlend`。未构建独立 Player、未测量 GPU 性能、未重跑全历史存档迁移矩阵；样区视觉仍待用户确认，不自动推广。正式工程重新执行 **Build Prototype Addressables** 后前往草原测试落点查看。
