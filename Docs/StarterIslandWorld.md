# 大型初始岛屿：概念图首轮实装

2026-10-17。对应 `SourceArt/WorldPlanning/StarterIsland-Large-v3-Magic.png`，本轮是可步行的地形与景观初版。

## 布局与兼容

群系按沙滩→草原→沙漠→林地→雪地逐区补充美术，保留本文件已精修的各入口与林缘。独立工具、手调标记、范围和验证见 [群系美术逐区优化](BiomeArtSequence.md)。

- 大陆约 1.5 × 1.2 公里。原有约 40 米生活区保持原点、设施、农田、NPC 路线、海滩出生点和码头坐标；向北以栈道连接大陆，避免缩放或搬移旧记录。
- 大陆中心约 `(0,650)`，西侧沙漠、中央草原、北侧雪山、东侧林地。湖心约 `(160,630)`，湖宽约 440 米、水面高 12 米；北侧入水溪流、东南侧出水河道，出水口使用木桥。西岸石径连接古树小岛。
- 四处魔法景观：琥珀遗迹 `(-420,590)`、灵辉古树 `(-8,700)`、月光花林 `(480,650)`、霜晶石阵 `(-40,1000)`。初版仅作景观；现已由 MagicManager 为月光花林、灵辉古树和琥珀遗迹追加有序记忆探索，交互与奖励见 [魔法内容](Magic.md)。霜晶石阵仍无玩法，原地标美术与碰撞保持。
- 琥珀遗迹通过 Blender MCP 制作：约 18.5 米主晶体、六组晶簇、双层石台及几何符文，共 786 个三角面，Unity 使用一个共享材质和一个合并网格。源文件、导出约定与复现说明见 `SourceArt/WorldPlanning/Models/README.md`；显式重建原位更新网格，普通 Setup 不导入源模型。
- 地形、湖河通行、主路及高度统一使用 `StarterIslandLayout`。`IslandLayout.CoastRadius` 与 `LegacyHeight` 保留原海岸生态协议；`ContainsLand/Height/CanPlace` 接入北侧新区域，原海床和鱼群栖息数据不重排。
- 不新增存档字段，版本保持 30。旧生活区坐标保持；新大陆坐标通过统一区域与高度校验，恢复时射线命中实际烘焙地面。保存仍仅在小屋床边睡觉完成结算后发生。

## 资源与生命周期

- `IslandTerrain.prefab` 新增 `StarterIslandWorld`，持有 117 块地形、栈道、石径和木桥的 120 个地面碰撞引用；景观按块合并。资源在编辑器烘焙到 `Assets/Art/Meshes/Terrain/StarterWorld`，跟随原地形 AA 加载释放，不新增 AA 地址或配置数量。
- 原地面碰撞网格保留，生活区另存草地表现网格；旧的微型沙漠／雪地模型组保留记录但隐藏。原海岸边界另存开放北口的版本，不覆盖原网格源资产。
- 树干及大型晶石有行走碰撞，树冠、花草和路径表现不阻挡点击。湖河通过同一完整脚印约束禁止入水；过河使用实际桥面碰撞。摆放使用实际地面射线与高度，保留步道、水岸、景观点和陡坡。
- 扩大原海面覆盖，保留原海床、珊瑚、鱼鸟蟹及其参数。湖与两条溪河使用独立共享湖水材质，由 OceanSurface 同一时钟和昼夜／雨量 MPB 驱动，没有额外 Update、材质克隆或运行时生成。
- 大陆上的有界雨场与云场跟随玩家位置和高度；云的水平漂移继续使用世界周期坐标。原生活区保持原场位置，暂停与室内冻结跟随，沿用 WeatherManager 调度及退出清理。
- 地图保留生活区设施视图，新增全岛视图与按钮；进入大陆后打开地图默认全岛。标记只展示用途和距离，不传送。MapController 关闭时解除缩放按钮订阅。

## 编辑与重建

显式菜单：`Magic Island > Art > Rebuild Large Starter Island (Explicit)`。它会重建新大陆、路径、景观、桥梁和四处地标，并更新原地形预制体的专用字段；保留原网格源资产、AA 地址、海洋生态和共享材质的合法人工参数。已有大陆网格美术修改在显式重建时会被覆盖，修改前应保存工作。

普通 Setup 只补地图缩放按钮和缺失中文字形，不重新烘焙大陆。新增网格与 `.meta` 必须一起同步；进入游戏前通过 `Build Prototype Addressables` 重新构建 AA 内容。
