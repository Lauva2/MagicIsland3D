# 暂停菜单、设置与睡觉存档

> 开发前先读根目录 [统一开发约束](../AGENTS.md)。本文保留专项实现与历史演进；旧版本号和旧保存入口描述不代表当前全局规则，现行约束以 AGENTS.md 为准。

在场景中按 ESC，或点击 HUD“暂停（ESC）”，通过 AA 加载 PopUp 层 `PausePanel`。菜单提供继续游戏、设置和返回主菜单，所有游戏进度仅在每天睡觉结算后保存。

## 暂停和返回

- 暂停及其设置弹窗会冻结时钟、角色、镜头、场景交互、NPC 日程和工具表现；继续后恢复。
- ESC 优先关闭设置，再关闭暂停；已有背包、商店等面板先关闭自身，不同时打开暂停。日报待查看时不能绕过结算开始下一天。
- 返回菜单先在 PausePanel 中显示确认，说明当日尚未睡觉的进度将丢失。选择“留在岛上”保留当前游戏；确认返回释放界面和世界，不写进度文件。
- 新游戏在第一次睡觉前没有该局存档。已有旧存档不会因创建新游戏或未睡觉返回而被覆盖；只有新局第一次成功睡觉才替换进度。

## 仅睡觉保存

GameManager 只有在小屋床边确认睡觉后，才能进入跨日、出货售卖、成长和日报结算。公开调试跨日和旧手动保存入口不能绕过床边确认。

白天农务、交易、订单、领奖、储物、出货、料理、送礼、钓鱼、建造、升级、整理、拖拽、拆分，以及进出小屋均只更新运行状态。各面板的手动保存按钮已隐藏，暂停菜单不提供保存按钮。

睡觉完成后，SaveManager 捕获完整的次日清晨快照，包含日期 / 06:00 时钟、区域与位置、库存与金币、农田、天气、NPC、订单、任务、家具、动物、出货和日报等。存档中的日报 Pending 为 false，运行中的日报仍显示；确认日报只关闭界面，不写文件。下次加载直接进入最近一次睡觉保存的清晨。

如果写盘失败，运行中的结算保留，日报禁止继续，提供“重试睡觉存档”。重试写入同一份已捕获 JSON，包括原位置和时间戳；不读取之后的活动状态、不再次跨日或发钱。成功后可以开始下一天。选择返回则放弃该次失败结算，下次从此前成功存档恢复。

## 设置

SettingsManager 单独管理音量与全屏，配置保存在 `Application.persistentDataPath/Settings/settings.json`。修改立即应用，停止调整半秒后或关闭设置时自动写入，下次启动恢复；该文件与游戏 `Saves/save.json` 及备份完全分离。

设置保存失败时保留当前应用值并显示反馈，关闭时再次尝试。损坏设置优先读取有效备份，无有效备份则回到默认值；音量限定 0–1，非有限值和未知格式版本拒绝读取。

## 架构与资源

GameManager 控制暂停、设置返回上下文、ESC 优先级、退出确认与睡觉授权；UIManager 通过 AA 同名地址创建 PausePanel / SettingsPanel。PauseModel、PauseView、PauseController 遵循 MVC。SettingsManager 保存设置，SaveManager 保存睡觉快照，各自持有并释放所需引用。

UI 资源位于 `Assets/Art/Prefabs/UI`，使用 TMP 中文和奶油 / 草绿配色。当前共 26 个 UI 预制体、24 份 AA 配置。缺失资源自动补齐，存档按钮和 HUD 标签采用一次性迁移；完整编辑资源不会反复覆盖。

存档格式为版本 27，兼容 1–26 迁移。旧档保留原快照的时间和位置，下一次正常睡觉后改为新规则的清晨快照；品质与施肥字段见 [肥料与作物品质](FertilizerAndCropQuality.md)。

## 验证

`PauseSleepFlowVerification` 在隔离工程使用打包 AA，验证暂停与设置、中文与布局、输入和时钟冻结、确认 / 取消 / 丢弃、白天无文件写入、睡觉全世界快照、读档回退、睡觉失败和固定快照重试、旧手动入口保护及资源清理。

`Tools/VerifySettings.cs` 检查设置范围、输入钳制、独立文件、原子替换和损坏备份恢复。已有纯规则测试继续验证背包、储物、出货、日报、任务和旧档迁移。较早的编辑器流程脚本曾假定操作自动保存 / 调试跨日 / 直接返回，保留作历史回归参考；当前存档流程使用本验证。
