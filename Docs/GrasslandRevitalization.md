# 草原完整一轮优化与内部植被

2026-10-19。用户要求持续优化草原至满意，并授权按地表、小径、花草组合、树木与生态的顺序完成整轮，重点改善空旷感。此前 [草原收尾](GrasslandFinish.md) 和 [生态组合](MeadowRabbits.md) 的资源继续保留，本轮不推进其他群系。

显式入口为 **Magic Island > Art > Revitalize Grassland In Order (Explicit)**。`GrasslandRevitalizationSetup` 先准备全部原景观修改、草甸落点和共享网格，检查自定义资源／元数据／材质后才写入；普通 Setup 不执行此入口。

## 四步资源范围

1. 地表：用编辑器烘焙的 `MeadowField.png` 记录原草原范围、低频草色、细部斑块与道路距离。Meadow Ground 材质继承原合法地面参数，只在原草原遮罩内增加柔和层次，保留原地形顶点、碰撞、全部 UV、草色权重与其他群系配色；沿用日期色板和真实光照。
2. 小径：原 Exploration paths 只将完整位于草原遮罩内的 1,560 个三角面划入第二材质区，其余路面继续使用原不透明 Biome Details 材质；Grass desert trail 使用继承原参数的独立 Meadow Trail 材质，在原草原内柔化边缘、增加轻微磨损和不规则缺口。保留原路面几何／GUID、道路连接、通行与建设预留；原有连续路面的 UV 和原四边形道路的世界距离分别沿用，原共享材质不改写。保留两种道路各自原有投影开关，草原软边不产生抬高路面的锯齿影；树木投在道路上的阴影保留。原道路全部三角面、顶点、法线、颜色、bounds 和 UV0–7 保留，只分配到两个材质区，其他群系继续原材质。
3. 花草组合：在原草原内部烘焙疏密不同的低草斑块，加入较大的花丛，并在安全不可建设路肩补充少量低灌丛和苔石。固定独立种子，复用已有 Blender 花朵／苔石和原灌丛模板，沿真实地面贴地；草叶直接在编辑器烘焙。全模型与风动包络避开道路、水岸和原实体景观，不新增碰撞、掉落或逐只对象。
4. 树木与生态：原位树冠收窄局部水平轮廓、微调高度与上下叶色，树干与碰撞不动。只筛疏仍符合原模板的完整等距路边植株，保留花瓣、花芯、花茎完整性及原生态栖息点；使用内部花草斑块衔接已有蝴蝶与兔子，不重抽或扩大生物活动范围。

原 Landscape／Route verge 的一次性标记保存在导入器 `userData=MagicIsland.GrasslandLiving.v1`，保留已知上一轮标记；自定义元数据在写入前拒绝覆盖。原合并道路另用同一前缀的 `.Road` 导入器标记。全部原 UV0–7 不变，不再分配额外频道。已有完整景观子树、后续人工改形／配色／布置和重复执行均保留；孤立同名资源拒绝覆盖。

## 建设遮盖与拥有者

内部低草／花丛可位于可建设草甸，建设资格不变。新合并网格使用自己的 UV0–2 保存风权重／相位、植株根部 XZ 与高度／季节着色权重，原网格不占新频道。全部新批次随原 IslandTerrain AA 加载，在 `Grassland living meadow` 下按 128 米分区合并。

`SeasonalGroundCover.MeadowBatches` 是可选数组，最多 64 个共享材质批次，旧资源的空数组合法；原 SeasonalGroundPatch 的 160 上限及配置不改变。TerrainManager 在恢复建设后沿原 Bind 初始化普通 C# `MeadowCoverPresentation`，通过原 Placed／Recovered 事件刷新局部批次的固定 128 槽遮盖数组，不增加 Manager、Update 或逐帧查询。

每处摆放以实际世界位置和 1.85 米保守半宽遮盖整株根部，包含原 1 米格、模型半径和完整风动余量。Shader 按统一根部隐藏整株及其阴影；只向与物体位置相交的批次上传遮盖，沿用原最多 128 件室外摆放限制。旧建设在首次 Bind 即遮盖，回收立即恢复，失败事务不通知。共享网格与材质不在运行时改写。

风动沿用 WeatherManager 暂停时钟，色彩沿用季节全局参数；室内通过原 Present 隐藏全部草甸批次。手工关闭的批次在室外也保持关闭；Unbind 恢复原 Renderer 启用状态和完整属性块，清空临时遮盖数组；返回、取消、失败与重新进入沿 TerrainManager 清理。无新增进度字段，存档仍为 v31，唯一进度保存点仍是床边睡觉。

## 验证与交接

`GrasslandRevitalizationVerification.BakeAndVerify` 在隔离工程核对完整原碰撞、树干和未选中顶点、全部 UV、原美术哈希、模型包络和道路净空，并测试自定义元数据拒绝、重复／普通 Setup、人工编辑保留。生成统计在忽略的 `Logs/LivingGrassland/Bake.json`。

`OceanWaterAppearanceVerification.RunLivingGrasslandBaseline/RunLivingGrassland` 使用真正 Packed AA，输出正常游玩镜头的主路、腹地、东部和湖岸，以及树木、总览及其他群系／海洋对照，覆盖清晨、白天、夜间、雨天。运行验证核对打包模型与原生资源、实际路线通行、室内隐藏、真实摆放／回收、GPU 整株遮盖、重绑旧建设、属性块清理与白天不保存。`StarterIslandWorldFlowVerification.Run` 覆盖睡觉读档、返回重进及 AA 清理。

## 本轮验收

最终资源包含 7,754 处草甸组合，其中 268 处花丛，26 个共享材质批次，327,924 个新增三角面；28 份原树冠／路边植株网格中调整 9,870 个树冠顶点、筛疏 28,514 个三角面。另将原 Exploration paths 的 1,560 个草原三角面分配独立材质，原完整三角面多重集合和所有原顶点频道保留。没有新增实体树干、地形碰撞、玩法物品或进度字段。

隔离工程 `BakeRefined.log` 通过原树冠／完整植株、碰撞、UV、元数据、自定义拒绝、重复／普通 Setup／后续人工编辑及无关美术保护。实景检查后已修正复用灌丛的零法线、细草背面发黑、草簇尺度／密度和软路缘锯齿影。其他群系对照发现整体更换合并道路材质会造成差异，最终改为草原路面独立材质区，由同一生产工具的 PartitionRoad 准备并验证，未采用整体道路材质替换作为最终结果。

`PartitionedPacked.log` 退出码 0，验证道路全部原几何／三角面／UV、实际打包网格、原主路和东行支路 CharacterController 实走、室内隐藏、真实摆放／回收、GPU 整株遮盖、重绑旧建设、完整属性块恢复及白天不保存；最终重复入口和普通 Setup 保留路面分区。48 张修改前／48 张最终 Packed 画面覆盖清晨、白天、夜间、雨天，检查正常游玩镜头的主路、内部、东部，以及树木、总览和湖岸代表视角。深海、珊瑚和沙漠四种光照逐像素一致，湖泊白天与林缘雨天各一个颜色通道有 1/255 舍入差，其余湖泊／林缘逐像素一致。浅滩跨次运行包含动态表现差异，未宣称所有水域画面完全一致；其原资源与运行代码保持。

`PartitionedWorld.log` 退出码 0，补充手工禁用批次／属性块保护，并通过大陆、湖河桥梁、天气与水域生态、地图中文／暂停、室内、真实床边睡觉、生活区／雪地继续、返回重进及 AA 清理。正式合入核对保留原 2,363 条预制体记录，仅增加 106 条景观批次记录，原记录只增加一个子节点、28 处材质引用和一处嵌套可选数组。122 份目标资源／meta 与最终验证副本字节一致，1,707 个资源 GUID 无重复，已有 AA Profile 未提交修改原样保留。

本轮未运行独立 Player 构建、GPU 性能测量、完整原海洋 OceanFlow 或全版本存档迁移。色板和风动继续使用现有系统，本轮画面检查不是四季美术专项验收。整岛显式重建会重做部分原地形／道路资源，应另行安排精修迁移；普通 Setup 不重建。正式工程仍需执行 **Build Prototype Addressables** 生成新内容包。日志、截图与验证工程不入库。
