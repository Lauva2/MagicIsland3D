# 草原岛岸线与海床精修

2026-10-19。针对五岛布局中的草原岛，增加不等宽的岬角、凹入海湾与浅滩，暂不继续其他群系美术和岛内道路整理。

## 入口与资源

- 显式菜单：`Magic Island > Art > Refine Grassland Island Coast (Explicit)`。
- 依赖原 `IslandTerrain` AA，沿用 `BiomeIslands` 网格目录、原地形网格 GUID 与共享材质，不新增配置、UI、运行组件、Update 或存档字段。
- `GrasslandIslandCoast` 与 `BiomeIslandLayout` 统一新轮廓和高度；地图、声音、地面恢复、建设和完整角色脚印使用同一范围。
- 原陆地不内缩，内陆高度保持，海侧增添幅度约 2–31 米的不对称岬角。岬角之间形成海湾，沙草交界按角度与固定空间纹理改变宽窄，不使用每次进出重抽的随机数。
- 海床从近岸向较深水域过渡，浅台宽度随方向变化，边缘扩展至足够水深；新海床限制在 Z≥100，避开原生活区海洋生态。原海洋、其他群系、植被、树干、地标、旧道路和源预制体不重建。

## 保护与失败处理

第一次执行前检查网格所属路径、变换、网格布局、原索引及 importer 元数据；自定义数据拒绝覆盖。先完成全部内存规划，再写入资源，失败恢复本次修改的网格与预制体字节并删除本次新建资源。

保留原 XZ 顶点、全部原三角面及 UV1–7，只调整海侧高度、局部顶点色与 UV0 草色权重；原有效建设格对应的完整地面支撑三角面保持原高度。距旧岸 68 米以外的内陆顶点色、权重和法线保留。`StarterIslandWorld.GrasslandCoastArtVersion=1` 与专用 importer 标记表示已应用，重复入口、群岛重建入口和普通 Setup 保留后续人工编辑。未知版本不能当作未初始化重做。

本轮不增加存档字段或迁移，不占用新版本号，不改变唯一床边睡觉保存点。原群岛干地坐标与建设资格保持有效；旧大陆在上次拆分中移除区域的兼容限制仍见 [独立群系岛屿](BiomeIslands.md)。当前源码存档版本 30 与 AGENTS.md 的 31 差异未在本轮改动。

## 可复现验证

- `Tools/VerifyGrasslandIslandCoast.ps1`：独立编译纯 C#；冻结的上轮群岛规则位于 `Tools/Fixtures/BiomeIslandsBeforeCoast.cs`，逐格核对原陆地、高度、建设资格、其他群系、海峡隔离和海床边界。
- `GrasslandIslandCoastVerification.BakeAndVerify`：隔离工程烘焙，核对旧支撑三角面、原索引/GUID/频道、其他美术字节、拒绝自定义元数据、重复入口与普通 Setup 保留手工颜色。
- `GrasslandIslandCoastVerification.Before / After`：实际构建 Packed AA，五处固定视角对照，完整角色胶囊与新岬角实走、水域排除，并复用五岛传送、地图、床边睡觉、五岛继续、旧档拒绝/备份保留和退出重进释放流程。
- 验证日志与截图在忽略目录 `Logs/GrasslandCoast`，不提交或上传；最终执行结果另记。
