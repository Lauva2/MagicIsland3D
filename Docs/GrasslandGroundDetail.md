# 草原样区地面细节与低草边缘

2026-10-21。接续 [地色融合](GrasslandBlend.md)、[空间群落](GrasslandSpatial.md) 与 [蝴蝶访花](GrasslandFlowerVisits.md)，继续只细化原 `TouchSample` 样区。

## 美术范围

原整岛 `MeadowUnderlay.png` 及全部手绘像素保持。新增 `Assets/Art/Textures/Terrain/MeadowSampleGround.png`，512×512 线性 RGBA 数据图，覆盖样区周围 50×50 米。R／G／B 分别记录暖土、苔色、细碎落叶，alpha 为不规则色块的样区过渡。实际草簇根部密度决定空隙与密草的地色，花带和灌木周围生成柔和苔色；落叶使用独立固定种子，集中于已有植物附近，不沿道路均匀撒满。

所有有效像素的完整双线性采样范围均在样区内，并避开主路中央 2.1 米范围；边缘像素为零。原 `Meadow Underlay` Shader 通过可选字段混合低饱和颜色，默认强度为零，未接入资源保持原路径。原材质只补充新图、实际范围与首次强度，其余人工材质参数保留。颜色继续受原季节和真实光照影响，不烘焙固定阳光阴影、不修改全局光照。

原六份合并网格仅对样区内稀疏边缘的完整纯草根组降矮并柔化 RGB。按真实地面锚定，保留原 XZ、根部、株数、alpha、全部 UV0–7、三角面顺序、bounds、索引格式与 GUID；花、灌木、苔石、混合根、道路附近纯草及样区外保持。蝴蝶关联的花粉顶点、相位和花朵风动不改。没有新增植物、落叶实体、Renderer、碰撞、材质副本或运行脚本。

地面细节是静态美术底层，不随临时建设重新生成；草叶继续由原风场、拨草、季节、整根建设遮盖、室内隐藏和释放拥有者管理。没有新增配置、AA 地址、进度字段或白天保存行为，存档保持 v31。

## 显式维护

入口 **Magic Island > Art > Refine Grassland Sample Ground Detail (Explicit)**。原地形 AA 预制体通过既有材质引用新图，不改原预制体层级或已有资源地址。普通 Setup 不烘焙、不重设材质、不重画分布图。

首次预检原样区、材质／纹理引用、原网格和已知元数据；孤立同名纹理、既有自定义细节参数、未知元数据、进行中或部分完成状态拒绝覆盖。完整计划通过后备份原网格和材质及 meta，先将材质 importer 标记为 `MagicIsland.GrasslandGroundDetail.Pending.v1`，再创建纹理并保存网格／材质，最后提交 `MagicIsland.GrasslandGroundDetail.v1`。失败还原原文件并清理本次创建的纹理。重复入口与普通 Setup 保留后续手绘、草色和强度调整，不通过删除标记强制重做。

## 验证与使用

`GrasslandGroundDetailVerification.BakeAndVerify` 在隔离工程核对计划像素、完整双线性边界、原 XZ／根／花朵、全部 UV／面／bounds／GUID、原材质参数及其他美术保护，覆盖自定义资源／部分状态拒绝，以及后续手绘与材质调节在重复／旧入口／普通 Setup 中保留。

`GrasslandGroundDetailVerification.After` 使用真正 Packed AA，GPU 读取新图并核对实际依赖，使用正常镜头与近景的白天／黄昏／雨天同机位前后对照。额外对照原／新 Shader 在零强度和样区外的画面，接续原蝴蝶、风动、拨草、建设、角色通行、室内外、床边睡觉、读档、返回重进和 AA 清理流程。

正式工程需执行 **Build Prototype Addressables**。日志、对照图、验证夹具和隔离工程保存在忽略的 `Logs/GrasslandGroundDetail`，不提交。独立 Player 构建、GPU 性能测量和全版本迁移矩阵不包含在本次美术验收内。

## 本轮实际结果

最终 `Bake.log`、`Packed.log` 均退出 0。局部图含 150,870 个有效 texel、174 处细碎落叶标记，调整 136 簇稀疏边缘纯草、2,828 个顶点的 Y／法线／RGB；株数和顶点数不变。其余顶点、花粉落点、所有 UV／三角面／bounds／索引格式／GUID 和原材质参数通过逐项保护检查。自定义材质／元数据、进行中／部分状态拒绝；手绘新图、草色和材质强度在重复、前序入口与普通 Setup 中保持。

首次 Packed 发现新增材质纹理引用未持久化，未发布该资源。定位后改为编辑器暂存新 Shader 属性、原位复制回原材质，并在保存、各次重导入及最终重载后检查真实纹理 GUID／引用；同步导入贴图，人工编辑夹具恢复时先导入贴图、后导入材质。完整重跑烘焙和 Packed 验收通过。最终原材质 YAML 仅增加新贴图、范围和强度三个字段，原材质 GUID、其他字段和手调参数保留，没有新增材质资产或运行时副本。失败日志保留在忽略目录供复核。

实际 Packed GPU 细节图与作者纹理一致；正常镜头和近景的白天／黄昏／雨天前后对照通过，并在实景检查后适度提高土色、苔色和细碎落叶的辨识度，重新完成 Packed 回归。原／新 Shader 在零强度及样区外通过既有静止帧标准，原道路与样区外外观保持。`Preview.png` 上为正常镜头、下为近景，左为修改前、右为最终效果；`Lighting.png` 为三种光照对照，没有对游戏截图重新调色。

接续草原 6,936 步真实 CharacterController 通行、100 帧实际样区行走、风动／拨草／暂停、蝴蝶真实访花与局部避让、建设／回收／整根 GPU 遮盖／旧建设重绑、室内外、床边睡觉、五岛继续、返回重进、无白天写盘及 AA 清理均通过。没有 C# 或 Shader 编译错误。

发布范围为六份原网格及 meta、原地面材质及 meta、新数据图及 meta，共 16 份资源；新增两个编辑器脚本及 meta，修改原地面 Shader、验证调度与已知迁移标记列表。原预制体、碰撞、整岛地色图、其他群系、AA Profile、配置及运行脚本保持，约束同步 AGENTS 和 README。最终资源／源码／依赖与验证工程一致，未拥有的原 Assets 保留，2,255 个 GUID 无重复。正式工程仍需单独重建 Addressables 内容。
