# 室内家具制作与摆放

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

玩家可以在办事处前的工作台制作家具，带进小屋后从背包选择摆放。室内和农场使用同一个背包；家具只在小屋内摆放，栅栏、石板路和庭院灯仍只在农场摆放。

| 家具 | 材料 | AA 地址 |
| --- | --- | --- |
| 木桌 | 木材 × 4 | WoodTable |
| 木椅 | 木材 × 3 | WoodChair |
| 小台灯（含矮木座） | 木材 × 2、石料 × 1 | SmallLamp |

每次制作产出一件，不消耗体力或金币。材料和成品原子交换，材料不足或背包空间不足时不扣料。现有 CraftingCatalog 经 AA 加载，新增 IsFurniture 标记区分两类配方。Furniture 追加为 ItemType 的值 7，原有类型值保持。

工作台沿用 PopUp 层 CraftingPanel 和 MVC，使用上一页 / 下一页查看配方；默认第一页为三个农场装饰，第二页为三个室内家具，第三页为不参与摆放的养殖用品，见 [饲料制作](FeedCrafting.md)。已有完整布局保留。三个家具模型位于 Assets/Art/Prefabs/Furniture，使用同名 AA 地址，根部保留 PlacedDecoration 和单个 BoxCollider，每件占一米格子。

## 摆放与回收

- 背包选择家具，点击“摆放一个”；室外显示“请带到小屋内摆放”，按钮禁用。
- WASD 移动，鼠标选择室内地板位置，R 或面板按钮每次旋转 90 度；绿色为可用，红色为不可用。左键 / 确认扣除一件并提交家具，ESC / 取消保留物品。
- 格子中心范围 X -5–5 / Z -4–4，总上限 128 件；墙体、固定家具、玩家及已有家具阻止摆放。床、出生点、出口之间保留连续通道。默认布局通道在纯规则中校验，运行时还根据实际出生点、床右侧及出口保护路径。
- 扩建后格子中心上界扩至 X 9 / Z 6，下界及上限不变，已有家具保留；读档先恢复扩建几何，再恢复家具，见 [小屋扩建](HouseUpgrades.md)。
- 摆放时暂停时间、天气与 NPC 日程，保留玩家移动和镜头，关闭普通世界交互；必须先结束摆放才能睡觉、进出或打开其他面板。
- 走近家具，右键回收到背包。距离太远、背包满或重复回收时不会丢失或复制物品。固定床、书架和床头柜保持原有布局，不属于可回收家具。
- 台灯预览时关闭光照和碰撞，确认后启用。家具与灯光使用室内显示层，出门后家具保留在室内，室外看不到室内模型或台灯照明。

默认通道为入口至出生点、出生点沿 Z -2.5 横向连接到 X -1.5，再沿 X -1.5 通向床的右侧。预览还检查实际家具和角色碰撞。修改室内布局时应保留这些默认通道，并检查出生点与床的实际连通位置。

## 管理与生命周期

FurnitureManager 继承 PlacementManager 的 AA 预览、旋转、提交、回收和释放逻辑，独立持有室内状态和家具实例。农场 PlacementManager 继续管理室外装饰，两个区域的 ID 和占位分别校验。GameManager 选择当前区域对应的管理器，统一调度制作、输入、睡觉、切换和保存；UIManager 加载 Common 层 PlacementPanel，MVC 绑定当前管理器。

进入游戏时校验并加载家具模型资源。室内场景保持惰性加载：室外读档时仅恢复家具记录，第一次进屋后绑定室内根节点，再创建已保存家具并检查实际布局。再次进屋复用场景和实例；返回菜单释放预览、家具、资源句柄及状态。

AA 加载预览失败时恢复输入和背包物品，允许重试。已保存家具与固定布局冲突时拒绝进入并回到菜单，卸载场景和释放部分实例，修正布局或有效存档后可以重新加载。

## 存档与验证

版本 18 引入 Furniture 数组，保存每件家具的唯一 Id、ItemId、局部 GridX / GridZ 和 QuarterTurns；版本 19 新增 HouseUpgrade，当前版本 22 继续使用，恢复家具前按等级校验范围。室外 PlacedObjects 保持原有含义。制作、摆放、回收、进出、睡觉等操作共同保存全部世界状态；保存失败保留已完成的运行结果，通过面板、背包或返回菜单重试。

版本 1–17 迁移补空 Furniture，不赠送家具、不返还材料、不重置背包、农田、NPC、装饰、玩家区域或位置。记录数量、类型、ID、范围、重叠、旋转及保护通道先在临时状态中校验；室内 AA 场景加载后再检查实际碰撞。

Tools/VerifyFurniture.cs 验证三份配方、扣料、地板 / 旋转边界、保护通道、占位、回收、防重复、深拷贝、存档及版本 17 迁移。FurnitureFlowVerification.Run 使用隔离 Unity 工程和打包 AA 验证真实工作台分页、中文 TMP、家具预览 / 确认 / 回收、碰撞、灯光、保存失败重试、室内睡觉、场景复用 / 惰性恢复、预览取消、AA 失败重试、布局冲突恢复和旧档迁移。原有 ConstructionFlowVerification、HousingFlowVerification 继续回归。
