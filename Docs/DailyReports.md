# 每日经营结算

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

睡觉或调试跨日完成后，展示刚结束一天的经营日报。日期为前一天，玩家和世界已进入次日 06:00，但在点击“开始新的一天”之前，时间、移动、镜头和普通交互暂停。

| 指标 | 口径 |
| --- | --- |
| 当天收入 | 成功发放的金币，包括作物、鱼和两种蛋的出售、隔夜出货、订单和任务奖励 |
| 当天支出 | 成功扣除的金币，包括种子、饲料、购鸡、鸡舍、工具升级和小屋扩建 |
| 金币净变化 | 当天收入减去当天支出，正数显示 +，负数显示 - |
| 当天收获 | 成功从成熟农田收到背包的作物份数 |
| 今晨新成熟 | 本次跨日从未成熟变为成熟的农田格数，已成熟格不重复计入 |
| 出货明细 | 刚结束一天的出货物品、数量、成交单价与收入；不再次发钱 |
| 今晨新产蛋 | 本次跨日新增的普通蛋和优质蛋数量，原有待收蛋不重复计入 |

初始金币、读档恢复、直接库存恢复、购买或订单交付的物品不计作收获；材料不足、背包已满、金币上限等失败操作不计入。收益在原交易时到账，日报仅展示统计，不再发放金币、作物或鸡蛋。新成熟作物和鸡蛋继续留在农田及鸡舍，需正常收取。

## 流程与保存

GameManager 在床边确认睡觉后统一执行出货、作物成长、产蛋、时钟 / 体力恢复及其他每日系统，生成日报并保存完整的次日清晨快照。白天累计只在内存中，未睡觉返回或退出会丢失当天变化。

跨日后运行中的日报为待查看状态，写盘快照中的 Pending 为 false；加载恢复清晨，不重复打开日报，也不重新跨日或结算品质。仅睡觉写盘失败时显示“重试睡觉存档”，重试同一 JSON 快照。返回菜单须确认丢弃未保存结果，返回不写盘。

点击“开始新的一天”只清除运行中的待查看标记、关闭面板并恢复输入，不写存档。睡觉保存失败时该按钮禁用，必须先完成固定快照重试。下一天累计从零开始。Esc 不跳过待查看日报，背包、商店、建造、睡觉、任务领奖和区域切换在日报期间被拦截。

## 架构与资源

- DailyReportState 为纯状态，维护今天的累计、最近一张日报和 Pending 标记；快照和查询返回独立副本。
- DailyReportManager 在游戏初始化时绑定 EconomyState 成功交易记录器和 FarmActions 成功收获记录器，清理时解绑。记录器不在交易中额外发事件，库存或金币观察者看到完整的原操作与统计。
- GameManager 控制初始化、跨日、确认、保存、返回和清理；跨日及确认期间拦截重入请求。
- UIManager 在游戏初始化时经 AA 预加载 DailyReportPanel，正常新游戏隐藏，跨日及待查看旧档显示。加载失败沿用初始化失败返回菜单流程，避免完成结算后才发现面板无法加载。
- DailyReportPanel 使用 MVC、PopUp 层、中文 TMP 和奶油 / 草绿主题，位于 Assets/Art/Prefabs/UI，AA 地址为 DailyReportPanel。编辑器仅创建缺失预制体，保留完整面板的美术及布局。当前含暂停为 24 份 AA 配置、26 个 UI 预制体。

收支和收获累计使用整数精确计算；存档以规范的十进制字符串表示，避免多次大额交易使当日流水超过单次金币范围时溢出或丢失精度。

## 存档

版本 26 增加 Last.Shipping 成交明细，收入在日报生成前通过原金币流水记账；旧档迁移为空明细，保留历史累计。详见 [出货箱](Shipping.md)。

版本 24 新增 DailyReport：Day、Today、Last 和 Pending。Today 包含 Income、Expense、Harvested，Last 包含结束日期、当日累计、NewMatureCrops、Eggs、QualityEggs。

日期必须与农场一致，最近日报必须为前一天；尚未生成日报时使用 Last.Day = 0 和空数据，避免 Unity 将空嵌套对象序列化为默认对象的差异。所有累计必须为非负规范整数，新成熟格数不能超过农田格数，两种新增蛋合计不能超过两只鸡的单日产量。待查看日报必须存在，且次日累计仍为零。缺失结构、负数、非数字、错日、异常产量等拒绝加载，并沿用有效备份恢复。

版本 23 及以前迁移后以旧档当前日期开始空累计，不补造历史日报、不追溯收入和收获；原金币、物品、农田、亲密度、品质种子、待收蛋和已支付订单保留。当前版本重复升级不清空累计和待查看状态。

## 验证

Tools/VerifyDailyReports.cs 覆盖成功 / 失败 / 静默交易、观察者顺序、收获容量、当日累计与次日重置、新成熟格排除、日报副本、待查看 / 确认 / 失败恢复、整数精度、非法恢复原子性、旧版本迁移及当前存档验证。

DailyReportFlowVerification.Run 在隔离 Unity 项目构建 AA，验证实际种子 / 作物交易、任务领奖、鸡舍建造、购鸡 / 饲料、普通与优质蛋收购、订单交付、收获、白天保存与读档、室内睡觉、两种新增蛋与成熟格、中文排版、暂停及操作拦截、结算 / 确认保存失败与重试、返回菜单和继续查看、仅确认一次、第二天和空日报、真实缺字段 v23 JSON 迁移、非法日报拒绝、已查看档与新游戏清理。

原有 Unity 功能验证在成功跨日后显式确认新日报，再继续各自测试；被模态或重入保护拒绝的跨日仍保持原检查。

新规则下，运行中的日报仍为 Pending，睡觉快照中的 Pending 为 false；确认无需再次保存。仅睡觉写盘失败时显示“重试睡觉存档”，成功后可开始新一天。
