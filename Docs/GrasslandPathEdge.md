# 草原样区小径边缘

接续 [草甸小景衔接](GrasslandEdge.md)，只细化原拨草样区的草土交界：路肩宽窄和颜色断续变化，少量贴地矮草与碎石衔接路外草甸，路中央保持清晰。没有推广到整个草原或其他群系。

## 资源与显式维护

入口 **Magic Island > Art > Refine Grassland Path Edge Sample (Explicit)**，普通 Setup 不执行。沿原 `Island meadow trail` 网格、Meadow Trail 共享材质及已有软边着色器，只改变局部 RGB 和原空白 UV1.y 遮罩；UV0、UV1.x、alpha、UV2–7、全部顶点／法线／三角面／bounds、索引格式和 GUID 保留。原材质、分布图、预制体、地面／碰撞和建设资格保持。

共享 Meadow Trail 着色器仅对烘焙标记 -913 至 -914 解码局部遮罩，在片元内采样连续噪声，避免直接改变半米网格的边缘权重产生锯齿；没有新 UV 频道、材质副本、纹理或运行时参数。其余原顶点解码为零，沿原着色路径。

网格外边界顶点不改，避免渐隐边缘在网格边界截断。任何接触距路中心线 0.85 米内清晰带、或离开样区的原三角面，其全部顶点均受保护；修改顶点的完整插值三角面仍在样区内，样区边缘渐回原遮罩与颜色。中央几何和原可通行范围不变，不增加道路障碍或碰撞。

矮草使用独立固定种子选在距中心线 2.2–3.05 米的断续路肩，复用两份原 `Meadow undergrowth` 合并网格。每组 4–6 片低草，少数组搭配原 Blender 石块模板缩小的碎石；没有新增逐株对象、Renderer、材质、Update 或 AA 地址。原草、花、灌木、苔石、根部、颜色和所有 UV／面前缀保持，只追加新部分。

完整静态半径最多 0.32 米；按照当前 AA 参数允许的最大风动与拨草位移校验，完整运动半径控制在 0.72 米内，距路中央至少留约 1.48 米。完整包络检查真实地面、高差、实体、非草景物、小兔路线及样区边缘；沿原 SeasonalGroundCover／MeadowCoverPresentation 的统一风场、季节、拨草、建设遮盖、室内隐藏和释放流程。蝴蝶停落花丛、动物、原地色、其他群系和海洋保持，不增存档字段或保存入口。

原三份 mesh importer 追加 `MagicIsland.GrasslandPathEdge.v1`。首次先完整规划并备份，原路面先持久化 `MagicIsland.GrasslandPathEdge.Pending.v1`，网格与草批次完成后最后提交路面完成标记；中断、部分标记、自定义材质／元数据／频道拒绝覆盖，写入异常还原资源。完成后重复、前序入口和普通 Setup 保留人工编辑，不删除标记来重叠烘焙。

## 验证与交接

`GrasslandPathEdgeVerification.BakeAndVerify` 在隔离工程检查精确计划、原道路全部几何／面／bounds／GUID、原 UV0／UV1.x／UV2–7、原 alpha，按完整插值三角面保护路中央和样区外。逐顶点保护原草／花／灌木／石块及全部频道和面前缀，检查新矮草完整运动包络和净空；逐文件保护原预制体、地形／碰撞、材质、分布图、生态和其他美术。覆盖路面／草自定义材质、自定义元数据／UV 维度、进行中／部分标记拒绝，以及重复／前序入口／普通 Setup 保留手调。

`After` 使用真正 Packed AA，核对实际打包的路面几何、法线、配色、全部 UV 与面，输出相同正常镜头白天／黄昏／雨天对照，并使用真实旧 Shader 夹具隔离路面，在原零遮罩网格上逐像素检查新旧 Shader 输出保持。旧 Shader 以改名前原文件保存于隔离日志 ShaderBefore.txt；SHA 与修改前清单核对，夹具仅修正 Shader 名称和 include 路径，普通项目不包含夹具。比较时临时切换原路面和两份草批次夹具，保留其余既有样区美术，并在完成及异常时还原。接续原通路实走、生态、拨草／暂停／清除、建设回收、进屋、床边睡觉、五岛继续和 AA 清理；不在白天写盘。

原网格夹具只存在隔离工程的 `Assets/Editor/GrasslandPathEdgeBaseline`，日志、截图和验证工程均在忽略目录 `Logs/GrasslandPathEdge`，不发布。更新项目后重新执行 **Build Prototype Addressables**，前往草原测试落点查看。仍须样区满意后再决定推广。

## 本轮烘焙结果

隔离烘焙通过：调整 125 个原路肩顶点的配色／局部遮罩，追加 24 组共 116 片低草，其中 5 组带少量碎石，合计新增 3,580 个顶点。原三份网格及元数据保留 GUID；道路几何、中央及边界保护、原草花／小景和完整插值范围、未知数据拒绝、重复与普通 Setup 保留手调检查通过。没有新增配置、玩法状态或进度版本。

最终 Packed AA 流程退出码 0，核对实际打包的路面顶点、法线、面、UV 和配色，并完成正常镜头白天／黄昏／雨天对照。三种光照下的零遮罩旧／新 Shader GPU 输出通过项目原静止帧标准（至多 4 像素、每通道至多 1/255 差异）；当前其他道路和历史源预制体没有标记冲突。初次直接改变网格边缘权重的方案在实景中显出网格锯齿，最终采用连续片元噪声，保留原 UV0。

原 6,936 步道路实走、小兔／昆虫生态、实际草叶 GPU 拨动／暂停／清除、建设／整组遮盖／旧建设重绑／回收、进屋、床边睡觉、五岛继续、返回重进与 AA 清理通过，白天未写盘。最终同步三份原网格／meta 及共享 Shader，原预制体、AA Profile、地色图和其他美术保留。日志、Shader／网格夹具和截图均不入库。

未单独构建 Player、测量 GPU 性能或重跑全历史存档迁移矩阵。
