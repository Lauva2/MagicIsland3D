# 岛屿地图与地点指引

游戏中按 M，或点击 HUD 右上角“地图（M）”，打开岛屿地图。点击地图编号或右侧地点按钮查看用途和大致距离；M、Esc 或关闭按钮收起地图。打开期间暂停玩家、农具、时钟、NPC 日程及其他世界交互。

地图显示农田、我的小屋、商店、办事处公告栏、工作台、料理台、储物箱、出货箱、橡树林、采石区、海岸钓鱼点和鸡舍预留地。鸡舍建成后，下次打开地图显示实际鸡舍。地点选择只更新说明，不移动角色。

## 数据与框架

GameManager 创建并初始化 MapManager，在世界资源和玩家区域恢复完成后绑定地图数据，返回菜单时清理。地图入口具有加载状态和代次保护，可取消未完成的加载，避免快速开关遗留面板。

MapManager 每次打开时读取设施实例的位置，采集区取对应资源节点的中心；道路取当前 IslandPaths 的实际线段。岸线由共享 IslandLayout.CoastRadius 绘制，农田范围使用真实尺寸。地图北方在上，世界 X 对应横轴、Z 对应纵轴。

MapProjection 将世界坐标投影到地图范围，并限制越界坐标。玩家在小屋内时，标记使用小屋门口位置，标题显示“我的小屋（室内）”；距离也以门口为起点，避免将独立室内场景的远端坐标画在海面。

## UI 与 AA

- `Assets/Art/Prefabs/UI/MapPanel.prefab`，AA 地址 `MapPanel`，位于 PopUp 层。
- MapModel 保存地点、道路、玩家标记及当前选择。
- MapView 持有 TMP、地图图形、标记和按钮引用，渲染数据。
- MapController 绑定选择与关闭事件，释放时解除监听。
- UIManager 统一拥有并释放地图 AA 实例；MapManager 不加载 UI。

IslandMapGraphic 是原生 UI Graphic，绘制海水、浅海、沙滩、草地、村落小路、农田和码头。地点编号、玩家标记和说明使用对应 UI 组件与中文 TMP 字体。配色沿用奶油白、浅绿及海蓝色。

地图为第 28 个 UI 预制体。MapPanelSetup 只创建缺失的地图面板和 HUD 按钮，保留后续 Inspector 调整。所有地图操作仅影响 UI 状态，不新增配置资产或存档字段；游戏进度仍只在睡觉时保存。

## 验证

VerifyMapProjection 检查坐标范围、对称、非法数值及完整岸线。MapFlowVerification 在隔离项目构建 Packed AA，检查 MVC 与 PopUp 挂载、实际地点和道路、中文布局、标记选择、室内定位、暂停和面板互斥、快速取消及监听释放、睡觉读档、设施变化、新游戏重置和退出清理，并生成地图预览。
