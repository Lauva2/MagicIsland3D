# 鸡舍养殖

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

在办事处公告栏打开订单面板，点击“鸡舍建造”，进入 CoopPanel。首版只有一个鸡舍，最多饲养两只鸡。建造确认后立即可用，不另设施工日期。

| 操作 | 默认费用 / 收入 |
| --- | --- |
| 建造鸡舍 | 木材 15、石料 5、金币 200 |
| 购买一只鸡 | 金币 50 |
| 购买一份饲料 | 金币 10 |
| 出售一枚鸡蛋 | 金币 25 |

商店面板的“养殖用品”进入 AnimalShopPanel。购买的鸡直接送到鸡舍，饲料放入随身背包；没有鸡舍不能买鸡，两只上限不能重复付款。饲料全年供应，背包放不下时不扣金币。鸡蛋在同一面板出售，出售不计入作物出售任务；原有作物和鱼类交易继续使用 ShopPanel。

工作台的“养殖用品”页可用玉米 ×1 制作饲料 ×10，成品与购买的饲料一致，可存箱或照常喂鸡。详见 [饲料制作](FeedCrafting.md)。

## 日常照料

每只鸡现在有独立名字、亲密度和今日状态卡，每天可摸摸一次增加 5 亲密度，首次成功喂食增加 2，上限 100；30 为熟悉、70 为亲近。规则、图形爱心和存档兼容见 [鸡的互动与亲密度](AnimalFriendship.md)。

靠近并点击鸡舍打开照料面板。“喂食未喂的鸡”统一喂食当天尚未喂过的鸡，每只消耗一份饲料；刚购买的新鸡也可以当天喂食。已喂的鸡不重复扣饲料，未喂鸡所需饲料不足时整次操作不扣除。

喂过的鸡在睡觉推进到次日时各产一枚蛋。室内睡觉也结算养殖；未喂的鸡不产蛋，重复结算同一天不重复发放。两种待收鸡蛋合计上限 99，喂食前预留次日产物容量；容量不足先收蛋，不浪费饲料。

“收取全部鸡蛋”将待收产物一次加入背包。空间不足时保留全部鸡蛋，清理背包后重试。成功收取清空待收数量和巢中的标记，重复点击不复制物品。鸡蛋使用追加到 ItemType 末尾的 AnimalProduct（值 8）；背包不提供播种、食用或摆放操作。

收集的鸡蛋可带到料理台制作煎蛋或蔬菜蛋汤，成品可恢复体力或作为普通料理送礼。详见 [鸡蛋料理](EggCooking.md)。

养殖不消耗体力。办公室只能建造，鸡舍旁才能喂食 / 收取，商店旁才能购买 / 出售；距离太远及室内远程操作均拒绝。面板加载和显示期间暂停移动、时间、普通世界交互和鸡的闲动，关闭 / ESC 恢复。

## 场景与资源

默认预留地在农场西侧 `(-10, 0, -1.8)`。鸡舍主体、围栏、两只鸡的位置与蛋巢存于 AA 预制体。未建造时只保留逻辑预留区域，不生成鸡舍模型；新的装饰不能占用预留地。旧存档已有装饰保留，建造前检查实际设施 / 角色 / 装饰，冲突时不扣费。已建成鸡舍的读档若与场景冲突，则拒绝初始化并返回菜单，释放部分实例。

鸡使用轻微闲动表现，保持在鸡舍预设位置附近。建造 / 买鸡成功后同步实例再发布库存 / 金币变化；收蛋时先同步巢的标记再通知背包。返回菜单释放鸡舍、鸡和 AA 模型句柄。

## 管理与存档

AnimalManager 管理配置、AnimalState、鸡舍 / 鸡实例、交易、喂食、产蛋、收取、反馈和释放。GameManager.Animals.cs 负责办事处 / 商店入口、面板、距离、互斥、原子提交和保存。GameManager 统一初始化、跨日结算、返回菜单与失败恢复；UIManager 加载对应 MVC。

版本 20 引入 Animals，当前存档版本 25 保存 Built、Day、Eggs、QualityEggs、QualitySeed 和每只鸡的 Id / FedDay / Affinity / LastPetDay，与背包、金币和完整世界一起保存。日期必须与农场一致；严格校验两只上限、唯一 ID、喂食与互动日期、亲密度范围、鸡蛋范围和已喂鸡的产物预留。未建造不能有鸡或待收鸡蛋。

版本 1–19 迁移补未建造、无鸡、无产物，养殖日期同步已有农场日期，不赠送动物、饲料或金币，不改变原世界、家具、扩建和玩家区域。读档保留当日已喂标记，不能重复喂食 / 产蛋 / 收取。

建造、购买、喂食、收取和出售成功在睡觉时统一保存；写盘失败保留完整运行结果，面板保存或返回菜单重试，不重复原操作。鸡的闲动位置不存档，读档按 ID 回到各自预设位置，养殖进度不受影响。

## 验证

Tools/VerifyAnimals.cs 检查费用边界、原子通知与重入、容量、购买、喂食、日期与产蛋、库存不足 / 满格、金币上限、鸡蛋预留、非法存档及版本 19 迁移。

AnimalFlowVerification.Run 使用打包 AA 验证办事 / 商店入口、真实模型与 MVC、距离、建造阻挡、保存失败重试、当日喂食读档、室内睡觉产蛋、未喂日期、收取 / 出售、防重复、非法存档、旧档迁移、最大农田、AA 失败恢复和中文 TMP。既有扩建、家具、摆放、订单、农务与任务继续回归。

优质鸡蛋可替代普通蛋，料理和订单优先使用普通蛋；品质、双产物收取与版本 23 迁移详见 [优质鸡蛋](QualityEggs.md)。
