# 游戏时间与睡觉

`TimeManager` 控制时钟、床引用和交互距离；纯 C# `ClockState` 保存含小数的游戏分钟。日期以 `FarmState.Day` 为唯一来源，由 `GameManager` 统一推进，HUD 同时显示日期和时刻。

默认每天 06:00 起床，现实 1 秒推进游戏 1 分钟。`GameConfig.SecondsPerGameMinute` 可调整速度。到 24:00 停表并提示到床边睡觉，不自动跨日。睡觉会恢复体力；四季与日期由 CalendarManager 推导，昼夜光照由 WeatherManager 控制，暂未接入强制昏倒。

农田西南侧有蓝色被子的占位床。靠近后用鼠标点击床、被子或枕头，打开睡觉确认框。确认进入下一天；取消或 Esc 返回当天。床交互检查距离并拦截 UI 点击，重复请求只加载一个面板。

背包、商店、睡觉面板及其加载期间暂停计时；睡觉面板同时暂停角色、镜头和农务输入。`SleepPanel.prefab` 位于 `Assets/Art/Prefabs/UI`，AA 地址为 `SleepPanel`，MVC 管理并自动挂到 PopUp 层，文本使用 TMP 中文字体。

睡觉由 `GameManager` 依次推进农场日期、处理已浇水作物生长、清除浇水状态、重置时钟到 06:00、回满体力、自动保存。保留“下一天”按钮作为调试入口，执行相同结算；打开弹窗时不能用此按钮跨日。保存失败保留已结算的当前世界并提示，之后可重试保存或返回主菜单。

当前存档版本 11 保存时刻和体力，包括部分分钟。版本 1 先补初始金币，再补 06:00 时刻；版本 2 保留已有金币，补 06:00 时刻；版本 3 保留原有时间。版本 1–3 补满体力后迁移，版本 4–9 保留已有体力和时刻。非法时间或未知版本会被拒绝。

验证：`Tools/VerifyClock.cs` 检查流速、暂停、部分分钟、日末边界及非法参数；`Tools/VerifySave.cs` 检查时间和旧存档迁移；`GameFlowVerification.Run` 在独立工程和临时存档目录验证 AA 睡觉面板、床射线及距离、实际时钟暂停、取消、重复确认、作物结算、06:00 自动保存和读档时刻。
