# 风格化海洋

OceanManager 由 GameManager 创建和调度，在玩家区域恢复后、显示游戏 UI 前通过 AA 加载 `IslandOcean`。海洋预制体位于 `Assets/Art/Prefabs/Environment/IslandOcean.prefab`，地址由现有 GameConfig.OceanPrefabAddress 配置。预制体携带海面、海床、浅滩生态和鱼群的网格、材质与组件依赖。

## 海洋范围、地貌与生态

海面从 80×80 米扩大到 **240×240 米**，面积为原来的 9 倍。岛屿附近保留 1 米海面网格，远海采用 4 米间距；海床采用 256 个角向分段、128 个径向采样，覆盖半径 180 米。

`OceanGeography` 使用独立固定种子（默认 73192）生成海床。连续近岛浅滩的基准宽度从 29 米收窄为 11 米，外缘随方向与连续噪声变化；浅滩外新增基准宽约 10 米、水深约 1.6–2.7 米的珊瑚礁台地，再经约 14 米缓坡过渡到深海。18 处更小的离岸沙洲打破环形边界。干燥海岸与玩法地面高度保持原样，同一种子可复现，不消耗玩法随机序列。

生态生成 84 个群落：48 个浅水花园、36 个较深珊瑚群落，当前种子共 716 个小珊瑚、840 个大珊瑚。浅水种植低矮的各色小珊瑚，较深区域使用更大的枝状、扇状、桌状及团块珊瑚，混合海草、海绵、礁石、海星与贝类。按实际水深限制高度并贴合烘焙海床。海水采用低饱和青绿、灰蓝、深蓝渐变，沙底偏暖米色，珊瑚使用粉、紫、杏橙、灰青等柔和颜色；礁区保持比浅滩更深的明度，降低浪花、高光与焦散强度。

群落模型按区域合并为一个渲染网格，生态数量增加时控制渲染对象数量。海草使用顶点权重摆动，鱼群使用独立个体的轨迹和鱼鳍变形。OceanManager 通过 OceanSurface 的统一动画时间驱动生态、鱼群、海鸥和螃蟹，暂停冻结、钓鱼时继续运动，进入小屋和返回菜单沿用现有隐藏 / 释放流程。

## 浅滩与海岸生物

环境鱼保留 **32 群，数量按种类范围随机生成**，分为银色小鱼、小丑鱼、蝴蝶鱼与斑点鳐鱼四类。分别使用细长银蓝体型、橙白条纹、黄色扁身体型与带斑点的宽鳍轮廓；小鱼在浅水巡游，小丑鱼邻近珊瑚，蝴蝶鱼优先分布于较深礁带，鳐鱼选择平缓沙底低速活动。每条鱼分别巡游、觅食、探索与归群，普通鱼摆尾，鳐鱼缓慢起伏胸鳍，平静时个体间距也会变化。

生成时检查整群鱼的活动包络与实际烘焙海床，为鱼身上下、摆动与波谷预留距离，并包含受惊逃离、个体散开与转向的最大范围；近岸浅水和平台外围均有分布。OceanSchool 记录种类、数量与游动参数，鱼群内部合并网格，使用共享生态材质与顶点色。

海边加入 **18 只海鸥**：8 只盘旋、4 只低空掠水、6 只在岸边停栖并间歇短途起飞。海鸥拥有白灰身体、黑色翼尖、黄色喙和脚，独立的左右翼随飞行扇动，盘旋时穿插滑翔。夜间海鸥隐去，雨天飞鸟避雨，岸边海鸥保持停栖。沙滩另有 **16 只小螃蟹**，沿岸线短距离横移，位置高度跟随海岸地形。

这些生物是 OceanManager 管理的海洋环境表现，全部由 `IslandOcean` AA 预制体携带依赖，不增加独立 Update、运行时网格生成或存档字段。OceanSurface 统一调度 CoastalBird 与 CoastalCrab，暂停时位置和翅膀一起冻结，室内隐藏，退出游戏时与海洋一起释放。生成代码位于 `OceanWildlifeSetup.cs`，模型资源仍位于 `Assets/Art/Meshes/Ocean/Ecology`。

地貌与生态由 `OceanBiomeSetup` 在编辑器烘焙到 AA 预制体，BiomeArtVersion 记录迁移，当前版本为 8，重复配置保留已有编辑。径向前 88 个采样以 0.5 米间距覆盖浅滩及珊瑚礁台地，生态重新贴合烘焙后的海床三角面。调整 OceanSurface.GeographySeed 后执行 `Magic Island > Rebuild Ocean Geography And Ecology` 可按新种子重新烘焙；该操作重建生成的海床和生态。旧网格及预制体 GUID 沿用，新增网格位于 `Assets/Art/Meshes/Ocean/Ecology`，生态材质为 `Assets/Art/Materials/Ocean/Ecosystem.mat`。

## 玩家靠近与落水惊扰

OceanManager 将实际玩家位置、垂钓位置和可推进的游戏时间交给 OceanSurface，统一驱动反应。海鸥与螃蟹使用家园位置判断持续威胁；玩家仍在附近时保持逃离状态，离开后先等待安静期，再逐渐恢复，避免循环起飞 / 落地。

- 停栖海鸥在玩家约 3.2 米内受惊，约 0.65 秒展开翅膀、向海面升空；玩家离开后等待 4 秒，再用约 4 秒飞回，额外停栖 8 秒。低空海鸥也会回避附近玩家，高空海鸥照常盘旋。雨夜沿用原有避雨与隐藏规则。
- 螃蟹在玩家约 2.2 米内受惊，约 0.35 秒沿远离玩家的岸线方向横移，最多约 1.7 米。轨迹随岸线弯曲并保持原有离岸距离，完整逃离与恢复过程都留在干沙地，运动高度继续贴合海岸。玩家离开后等待约 2.5 秒，再用约 3.5 秒恢复。
- 首次在鱼群约 7 米内开始垂钓会惊扰鱼群；FishingManager 只在成功抛竿、浮漂入水后通过 OceanManager 再发出一次落水刺激，失败或忙碌抛竿不会触发。鱼群平滑加速并远离落点，鱼群内每条鱼沿自己的方向分散、略微转向，随后逐渐聚拢。安静期约 1.8 秒、恢复约 3.2 秒；持续等待浮漂不会每帧重新惊扰，重复成功抛竿可延长受惊。

各组件 Inspector 的 Disturbance response 提供距离、速度和恢复时间参数。鱼群逃离与散开距离限制在已经烘焙验证的安全范围内（分别最多 0.85 / 0.38 米）；扩大上限时需要同步修改烘焙包络并重建。每条鱼的中心与分散相位保存在网格第二 UV 通道，OceanEcology 通过每群的 MaterialPropertyBlock 驱动变形，不拉伸鱼身、不复制材质。

WildlifeAlarm 的受惊强度、安静期与恢复均由同一暂停时钟推进。暂停和普通模态面板冻结位置、翅膀、散开程度和恢复计时；垂钓中继续推进，室内停止刺激和推进，返回菜单与 AA 实例一起释放。反应是临时环境状态，不写进度存档。

## 海岸互动特效

`OceanInteractionEffects.prefab` 位于 `Assets/Art/Prefabs/Environment`，作为 `IslandOcean` 的嵌套预制体，通过海洋 AA 实例携带模型、材质与着色器依赖。OceanManager 沿用成功抛竿的落水通知，OceanSurface 统一推进特效，不增加独立 Update 或运行时粒子物体创建。

浮漂入水生成两圈错开的扩散涟漪与八颗小水滴，约 0.3–1.4 秒内消散。涟漪着色器读取现有海浪时间、高度和水位，每个顶点贴合实际起伏，避免只把整圈固定在一个平面上。受惊鱼群移动时产生短暂、断开的细水纹；鳐鱼滑行时在尾后产生浅淡的水下沙尘，其位置查询实际烘焙海床三角面。螃蟹逃离时留下三颗细沙粒和一个小沙尘团；雨天省去岸边尘团。

预制体预置 **84 个复用槽位**：10 个涟漪、24 个水滴、12 个鱼群水纹、12 个水下沙尘、16 个岸边沙粒、10 个岸边尘团。槽位满时按种类复用较早的粒子，反复抛竿不会增加对象数量。各类使用共享模型 / 材质，透明度、时间和日照通过 MaterialPropertyBlock 控制，运动结束后归还槽位。

生态特效默认只在距玩家 26 米内生成，鱼群 / 鳐鱼 / 螃蟹分别约每 0.48 / 0.65 / 0.23 秒允许一次。Inspector 可调整这些距离、间隔与水花、水纹、沙尘强度。水下沙尘在透明海水之前绘制，水面涟漪与沙粒在海水之后绘制；低透明度和短寿命保留浅滩与生物轮廓。夜间统一压暗。

所有寿命、运动与发射间隔使用同一个可暂停时间。垂钓时继续，暂停时冻结，室内随海洋隐藏并停止推进，返回菜单时随 AA 实例释放。特效不写存档。`OceanInteractionEffectsSetup` 只在缺失时创建资源，EffectsArtVersion 当前为 1；重复配置保留特效预制体和参数，地貌使用 BiomeArtVersion 8。

## 海水表现

`Assets/Art/Shaders/IslandOcean.shader` 适配当前内置渲染管线和斜俯视正交镜头。依据镜头深度与海面的距离，平滑混合浅海青绿、中层碧蓝和深海蓝色；透明度随水深渐变，近岸保留更多真实海床、珊瑚和礁石颜色。正交镜头使用线性的近远裁剪距离还原深度。

海面保留两组轻微起伏，并用多组流动细波纹计算法线，形成随视角变化的天空反光。阳光反射读取 WeatherManager 的实际太阳方向、颜色和强度；正交镜头使用平行视线，平移镜头不会改变反光方向。雨天增加细碎波纹，压低阳光反射，夜晚阳光强度为零时不会残留太阳高光。

岸边浪花沿水深等值线向沙滩推进，分成窄浪线、碎泡沫和贴岸消散三部分。旋转叠加噪声打散浪花，减少原先单层噪声产生的方块状白边；浪线和浅水光纹使用屏幕导数柔化边缘。浅水中增加缓慢流动的网状光纹，随水深和日照减弱。

碎浪限定在默认约 0.23–0.57 米的贴岸水深内衰减，避免连续浅水平台在浪峰时出现大片白色泡沫；浮漂涟漪和生物扰动使用独立的小范围特效。

海水仍使用单个透明渲染 Pass，通过程序法线与颜色模拟天空反光和光纹；未增加 GrabPass、实时平面反射或全屏后处理。

OceanSurface 通过 MaterialPropertyBlock 设置动画时间、日照、雨量及太阳数据，不修改共享 AA 材质。OceanManager 读取现有时钟和天气：昼夜调整海色，夜间继续使用已压暗的水色和泡沫，雨天减弱波光；普通弹窗和暂停冻结动画，垂钓会话中继续推进海浪，场景切换时停止推进。进入小屋隐藏环境，出门继续使用同一个实例。

## 参数与资源

水材质 `Assets/Art/Materials/Ocean/Water.mat` 可调整浅水 / 中层 / 深水 / 泡沫颜色、深浅过渡深度、浅水透明度、浪线间距及强度、细波纹、天空反光、浅水光纹、波高、速度和阳光反射强度。

| 参数 | 当前默认值 | 作用 |
| --- | --- | --- |
| _DepthRange | 4.6 | 深浅水色与透明度的过渡范围 |
| _ShallowOpacity | 0.22 | 近岸基础不透明度，越低越容易看到海床 |
| _FoamWidth / _FoamStrength | 0.42 / 0.48 | 沿水深方向的浪线间距与浪花强度 |
| _NormalStrength | 0.06 | 细波纹法线强度 |
| _ReflectionStrength | 0.38 | 天空反光强度 |
| _CausticsStrength | 0.045 | 浅水网状光纹亮度 |
| _WaveHeight / _WaveSpeed | 0.035 / 0.65 | 实际起伏高度与动画速度 |
| _Sparkle | 0.10 | 跟随太阳方向的反射强度 |

海面网格的默认局部高度为 -0.22，海床提供从岸边到深海的坡度。OceanSurface.SeaLevel 是预制体高度说明，实际位置由海面 Transform 配置。编辑器重复配置保留当前材质参数和模型。

`Assets/Art/Meshes/Ocean` 保存海面和海岸网格，`IslandShore.shader` 使用顶点色混合草地、沙滩与海床，并按线性颜色空间转换。礁石、珊瑚与水草已替换为可复用的海岸美术预制体，见 [海岸场景美术](CoastalArt.md)。OceanSetup 仅创建缺失资源；CoastArtSetup 一次性同步海床轮廓与美术，保留 `.meta`，后续执行保留已有编辑内容。

早期 `OceanSetup.UpgradeWater` 曾向原海床追加外缘坡面；当前由后续 OceanBiomeSetup 生成扩大后的不规则海床，沿用原网格身份和可行走海岸高度。水色与透明度依照真实地形深度共同过渡。

OceanManager 为游戏镜头开启 DepthTextureMode.Depth，清理时恢复自身添加的深度标记，保留其他深度模式。AA 加载失败、取消、返回菜单和重新加载均释放实例；海洋状态不写存档，本次调整不新增存档字段。

## 地形与玩法衔接

海洋预制体与浅海装饰没有 Collider，使用 Ignore Raycast 层；地面、沙滩和海岸碰撞由 AA IslandTerrain 与 TerrainManager 提供，码头由 FishingManager 加载。角色可走到岸边和码头，摆放、NPC 与旧存档落点使用统一岛屿轮廓，见 [可行走海岸与码头](WalkableCoast.md)。

此次扩展的是水域与水下地形；可行走陆地、码头和已有建设沿用现有范围。浅滩生态为水下景观，当前不包含游泳或涉水采集玩法。

垂钓浮漂读取 OceanSurface.HeightAt，与着色器波浪时间一致；垂钓会话继续计时，所以钓鱼面板内海浪也继续流动，普通暂停仍冻结。岸边植被和浅海装饰已接入，完整参考图风格仍需要进一步完善建筑与角色美术。

## 验证

OceanFlowVerification 使用打包 AA 内容验证着色器、新材质参数、实际太阳方向 / 强度传入、夜间清除太阳高光、镜头深度、实际渲染与波浪变化、真实时钟夜间 / 天气雨天联动、共享材质保持、暂停、进出小屋、边界碰撞保持、菜单释放、失败 / 取消加载和再次进入。输出 OceanVerification.txt 与 OceanDayPreview、OceanWavePreview、OceanShallowsPreview、OceanNightPreview、OceanRainPreview。

扩大后的验证同时检查海面 / 海床范围、干岸高度、实际烘焙海床的连续浅水带、生态种类与数量、鱼群游动与暂停，输出 OceanGeographyPreview 和 OceanReefLagoonPreview。`Tools/VerifyOceanGeography.cs` 对多个种子检查环岛各方向距岸 2–6 米连续浅水、浅滩收窄与更深礁带分布、种子复现、地形连续性、浅滩宽度变化、水下沙洲、外海深度与非法输入。

环境生物验证检查四类鱼群与数量、完整游动周期中的鱼身与海床 / 波谷间距、螃蟹活动范围与贴地高度、海鸥飞行与扇翼、雨夜行为、打包 AA 加载与退出清理。暂停同时检查鱼、海鸥位置、翼姿与螃蟹位置，输出 OceanFishPreview 与 OceanBirdsPreview。

受惊验证包括多个帧率下的安静期 / 恢复、持续接近不反复起落、重复刺激延长、反应中暂停、离开后恢复、螃蟹逃离路径、鱼群散开包络与实际海床，以及真实玩家接近和成功 / 失败抛竿的通知。纯计时验证见 `Tools/VerifyWildlifeResponse.cs`，实际接近预览为 WildlifeGullReactionPreview / WildlifeCrabReactionPreview。

OceanEffectsVerification 检查水滴与涟漪数量、扩散 / 抛物线运动、跟随海浪、暂停寿命、反复触发仍保持 84 个物体、到期回收、远处生态不发射、鱼群 / 鳐鱼 / 螃蟹触发、沙尘贴合海床、夜间日照和共享材质保持。打包 AA 流程同时验证真实抛竿、忙碌抛竿不产生特效、实际暂停、室内隐藏和退出清理。预览为 OceanSplashEffectsPreview、OceanRippleEffectsPreview、OceanSandEffectsPreview、OceanCrabEffectsPreview。

TerrainCoastFlowVerification 验证真实海岸行走边界、码头垂钓及浮漂随波浪起伏；LightingFlowVerification 验证日夜亮度与室内光源隔离。进度保存仍只在每天床边确认睡觉并完成结算后执行。


## 个体鱼群动画

`OceanFishSteering` 使用固定 30 Hz 步长，以三维 Boids 算法逐鱼计算实际位置、速度、朝向和行为状态。`OceanFishBoids` 负责分离、对齐和聚合，巡游提供较弱的共享目标。每步先捕获所有成员的位置和速度，再计算全部邻域；鱼身接触修正也先汇总再提交。渲染按剩余时间在前后两步的位置、偏航和俯仰之间插值，避免 60 / 120 FPS 画面直接跳到 30 Hz 位置。每条鱼通过 UV2 保留独立中心和相位，UV3 保存建模朝向和种类；先还原自身坐标，再进行尾部或胸鳍变形、俯仰和转向。每群仍只有一个合并网格和共享材质，姿态通过 MaterialPropertyBlock 的 `_FishPoses` / `_FishAttitudes` 固定数组写入，无逐鱼 GameObject、逐帧对象创建或材质克隆。CPU 顶点验证与着色器使用相同的俯仰顺序。

所有动画和行为依赖 OceanSurface 的可暂停时钟；受惊仍由现有 WildlifeAlarm 控制，暂停、室内隐藏、AA 释放和睡觉保存约束沿用现有流程。鱼群的 HomeRadius 固定在自己的栖息地，边界限制包含鱼身半径；巡游、觅食、探索和受惊都不会离开这个范围。Renderer 的实例包围盒覆盖整个安全水柱，不改写 AA 共享网格的包围盒。该表现属于环境生态，不参与背包鱼类、钓鱼掉落或进度存档。

OceanSurface 首次初始化时读取 AA 中已有海床网格，缓存与完整栖息圆相交的三角形最高点；水柱上界扣除海浪的最大振幅和安全余量。读取已有烘焙数据不会生成或覆盖地形。各鱼按身体厚度和俯仰后的保守包络收窄可用水层，再错开相位缓慢升降；浅水自动降低振幅和俯仰，鳐鱼保持低位小幅起伏。旧的合法参数与美术资源保留，旧出生点若重叠则在同一栖息体积内确定性地分开。无法容纳完整鱼身或没有安全出生点时初始化失败，由 OceanManager 清理 AA 实例与镜头状态。

`OceanEcologyPolishVerification` 检查两种深度生态、珊瑚数量、柔和配色的明暗顺序、鱼群个体相对距离变化、不同朝向、暂停和合批。`OceanFlowVerification` 检查的是变形后的实际顶点水深与包围盒，包含平静及受惊状态，并通过真实 AA 流程渲染鱼群连续帧和两种珊瑚群落。

## 数量配置、觅食与避障

OceanSurface 的 FishPopulations 按种类配置 Minimum / Maximum，当前默认为银色小鱼 6–10、小丑鱼 3–5、蝴蝶鱼 3–5、鳐鱼 1–2，随机端点均包含。每群分别抽取数量，使用独立的种子随机序列，不消耗玩法随机数。数据随 IslandOcean AA 预制体加载。调整范围或 GeographySeed 后执行 `Magic Island > Rebuild Ocean Geography And Ecology`，重新烘焙合并网格、成员及安全出生点；普通进入游戏沿用烘焙结果，避免每次读档更换景观。范围必须满足 1 ≤ Minimum ≤ Maximum ≤ 32。

编辑器从每块实体珊瑚、礁石及海绵的源顶点烘焙保守水平圆和上下高度。三维导航从 OceanSurface 的完整烘焙障碍中筛选附近对象，保留不同高度的障碍，避免沿用旧固定水层筛选后漏掉上方珊瑚。Boids 提前预测迎面接近，分离范围包含完整鱼身和转向余量；另有独立的接触约束，即使关闭社交权重也不允许身体穿入邻鱼。提交前检查整个三维位移区间，低帧率不会跳过细珊瑚或中间高度的障碍。

受阻后保持短时脱困方向，平滑转向，再重新规划；不会每步突然切换横向速度。等待避让时允许经过相同安全检查的小幅浮力起伏。正常速度按加速度变化，紧急避障和接触可安全减速；实际位移方向决定平滑朝向和俯仰。鱼群不添加物理 Collider。

## Boids 群游参数

在 `IslandOcean` 各鱼群的 `OceanSchool > Boids flocking` 中调整：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| NeighbourRadius | 1.8 米 | 同群邻居的感知距离，对齐与聚合仅考虑范围内成员 |
| SeparationRadius | 0.7 米 | 近距离分离范围，同时考虑鱼身半径，避免大鱼贴得过近 |
| SeparationWeight | 1.8 | 远离过近邻鱼的强度，完全重叠也会确定性地分开 |
| AlignmentWeight | 0.85 | 朝邻鱼平均速度方向转向的强度，静止邻鱼不虚构朝向 |
| CohesionWeight | 0.65 | 朝邻鱼中心靠拢的强度，远处的其他鱼群不参与 |
| CruiseWeight | 0.55 | 共享巡游目标的引导强度 |
| Acceleration | 1.5 米/秒² | 正常加减速上限；障碍阻挡时仍允许立即安全停下 |

`OceanSchool > Three dimensional swimming` 另外提供：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| VerticalRange | 0.22 米 | 常规深度起伏的最大振幅，按实际水柱余量缩小；鳐鱼进一步降低 |
| VerticalSpeed | 0.12 米/秒 | 主动上下游动速度限制 |
| MaximumPitch | 18° | 鱼身最大俯仰，实际限制同时考虑水深和身体尺寸 |

觅食、探索时降低对齐与聚合，让个体可以接近自己的目标；受惊时以逃离为主，分离仍然有效，恢复后自然归群。单只鳐鱼没有虚构邻居，继续独立活动。邻域数组在初始化时分配并重复使用，最多32条鱼的群内查询不创建临时集合。参数随原有 AA 预制体加载，调节权重无需重烘焙地貌；数量、栖息范围和障碍变化仍按前文执行烘焙。本次不新增配置地址、UI 或存档字段。

每条鱼错开时间进入觅食、探索与归群。小丑鱼和蝴蝶鱼按相位选择珊瑚周围不同的安全觅食点；接近目标后减速并沿小范围活动目标继续游动，随后探索、归群。接近目标不再将速度乘到零，避免原地停住和共享目标处堆叠。落水惊扰会中断这些活动，安静并恢复后再归群。

`Tools/VerifyOceanFishBoids.cs` 检查独立邻域规则，包括三维分离、对齐、聚合、迎面接近预测、距离过滤、鱼身间距、重叠分开及单鱼。Unity 菜单 `Magic Island > Verify Fish Boids`（`OceanFishBoidsVerification.Run`）检查着色器导入、实际鱼群行为与合批表现，并输出 `Logs/OceanFishBoidsVerification.txt`；不会切换玩家场景或读写玩家存档。

`Tools/VerifyOceanFishSteering.cs` 是无编辑器环境下的托管检查：读取当前 `IslandOcean.prefab` 的32群实际成员、完整障碍和海床网格数据，直接运行生产转向代码。检查逐步位移、完整身体间距、安全水柱、每条鱼的深度变化、连续停滞、分离 / 对齐 / 聚合控制、暂停、受惊恢复、觅食、绕行、15 / 30 / 60 / 120 FPS 一致性、120 FPS 连续插值与两秒卡帧。使用 Unity 随附的 Mono / C# 编译器，引用 UnityEngine.CoreModule 与 netstandard，并一同编译 OceanFishBoids、OceanFishSteering、OceanSchool、OceanFishMotion、OceanSwimNavigation、WildlifeAlarm、OceanGeography 和 IslandLayout。运行目录为项目根，或把项目根路径作为首个参数；可用第二个参数指定每群模拟秒数，例如 `. 600` 检查每群十分钟。该检查仅使用组件的托管字段，不初始化原生 MonoBehaviour，不能替代 Unity 中的 AA 加载、着色器和画面验收。

本次升级直接读取已有烘焙资源，无需覆盖重建海洋地貌；协作者同步代码后重新构建 Addressables，使新着色器进入打包内容，再执行 `OceanFishBoidsVerification.Run` 和 Packed Play Mode 的鱼群画面验收。

`OceanFishBehaviourVerification` 及现有 `OceanFlowVerification` 同时执行 Boids 集成检查：分离 / 对齐 / 聚合分别作用于实际运动、零权重控制、同一步邻居快照、加速度与非法时间保护。原有数量范围和同种鱼群差异、连续位移的珊瑚间距、整条鱼的范围限制、水面与海床间距、鳐鱼贴底、觅食减速、探索、受惊和恢复、暂停、30 / 60 fps 结果一致及挡路礁石绕行继续回归。
