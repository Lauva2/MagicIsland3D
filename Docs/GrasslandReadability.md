## 表现与资源边界

在原六份合并批次中，识别五顶点低草叶，按连续空间噪声形成低草、中草和少量高草的小斑块。同簇略有高低差，道路边缘降低株高，样区边缘平滑还原原形。低草作为留白底层，较高草簇更容易从斜俯视镜头中识别；草叶改为柔和鼠尾草绿，顶部略浅、下部略深，仍由原季节色与真实光照处理。

只调整选中草叶的非根顶点高度、法线和颜色；草根、株位、水平轮廓、数量、面、全部 UV0–7、GUID 保持。因此原道路留白、花朵、蝴蝶停落点、灌木／石头、树木、地面与碰撞、建设资格及其他区域不变。高度上限为地面以上 0.75 米，保守 bounds 只在需要时向上／下扩展；沿原拨草 1.30 米水平形变限幅和整株建设遮盖。不增加面数、对象、Renderer、材质、运行组件、配置地址、Update 或进度字段。

## 显式维护

入口 **Magic Island > Art > Refine Grassland Grass Readability Sample (Explicit)**。须已完成原拨草样区，并通过原地形、材质、碰撞引用、模型、频道和已知元数据检查；全部计划验证后才写资源，失败还原原网格与 meta。只追加 `MagicIsland.GrasslandReadability.v1` importer 标记，不修改预制体。未知材质／变换／元数据、不可识别模型和部分标记拒绝覆盖。完整标记后的重复入口及普通 Setup 保留后续合法人工改形、调色与参数。

资源仍随原 `IslandTerrain` AA 依赖加载；拨草、回弹、草浪、季节、室内隐藏、建设遮盖和释放继续使用原拥有者，见 [草原拨草样区](GrasslandTouch.md)。普通 Setup 不执行此美术迁移。同步资源后需重新执行 **Build Prototype Addressables**。

## 验证方式

隔离工程运行 `GrasslandReadabilityVerification.BakeAndVerify`，逐顶点核对计划、未选择顶点和根部、原水平坐标、完整 UV、面序、GUID 与保守 bounds；对其余美术文件（包括地面、碰撞、材质和整个预制体）做字节保护。覆盖自定义材质／元数据拒绝，以及后续手调在重复入口、旧拨草／花草入口和普通 Setup 中保留。原六份网格比较夹具仅保留在隔离工程的 `Assets/Editor/GrasslandReadabilityBaseline`，不发布。

`GrasslandReadabilityVerification.After` 构建真正 Packed AA，核对运行实例包含新高度和配色，并用相同正常游玩镜头、位置和风场生成白天／黄昏／雨天的前后对照。接续原拨草零风力 GPU 压弯、暂停、清除与角色实走，样区真实建设／回收、旧建设遮盖、通路、进屋、床边睡觉、五岛读档、返回和 AA 释放。验证使用隔离存档；日志与截图位于忽略目录 `Logs/GrasslandReadability`。

`Bake2.log`、`Packed.log` 均以退出码 0 完成。共识别原样区 1,108 片低草叶、3,324 个非根顶点；目标株高分类为低草 401、中草 536、高草 171，边缘仍按羽化混合原高度。实际改形和配色位于两份 `Meadow undergrowth` 网格；其余四份样区网格只追加完成标记，不改原几何。发布包含两份原网格和六份原 meta，地形预制体逐字节保持，没有新增对象、面、材质、碰撞或存档字段。

本次核对原根部／水平坐标、法线／颜色计划、UV0–7、面序、GUID、未选中花朵及其他美术、自定义数据拒绝和重复／旧入口／普通 Setup 保留手调。Packed 流程确认真实 AA 的高度和色板，生成同镜头白天、黄昏及雨天对照，实际查看白天草叶更清晰、高草不遮住角色，保留原天气光照与道路留白。原拨草 GPU 压弯／暂停／清除、实走、6,936 步通路、样区真实建设／整株遮盖／回收及旧建设重绑、进屋、床边睡觉、五岛继续、返回和 AA 释放均通过，白天不写盘。
