# 草原灌木与苔石精修

2026-10-19。继续只优化草原，对已有树下、路边和花坡小景进行原位细化。

## 显式入口与边界

**Magic Island > Art > Refine Grassland Shrubs And Moss Stones (Explicit)**。工具读取原 `IslandTerrain` 的地表批次，仅处理 `Art Meadow shrubs`、`Island meadow cover` 和 `Grove understory` 中能识别的完整石块／灌木组合。普通 Setup 不执行。

- 按原根部、已知顶点色和原风动权重识别组合，按面连通和重合位置复原两块石头及七个独立叶团。未知配色／不完整模型保留，自定义 importer 元数据、碰撞网格、自定义变换或材质拒绝修改。
- 叶团轻柔圆润化，分别调整高低、宽窄和由暗至亮的层次；原法线与椭球外向法线混合后随形状变换，不重算成尖锐平面。石块沿原位置压低并局部埋地，苔色按表面高度、朝向和固定空间采样变化。
- 完整水平半径不超过各原组合的范围，且继续限制在 1.18 米以内；根部位置、原三角面、全部 UV0–7、风动相位／权重、季节数据和 GUID 保留。实际地面高度用于贴地，原道路、树干、地形、碰撞和建设资格保持。
- 同一组仍共用原根部遮盖，沿 `SeasonalGroundCover`、`MeadowCoverPresentation` 和 `Natural Meadow Cover`；沿用原风场、暂停、室内隐藏及 AA 清理。没有新增 Renderer、材质、批次、逐件对象、Update、Collider、掉落或进度字段。
- 原花草、低草打底、地色图、落叶和生态落点不变，不重新散布小景。仅更新原 AA 网格及 importer 标记，预制体保持。

在已知旧元数据后追加 `MagicIsland.GrasslandShrubStone.v1`，不占用额外 UV；全部完成后重复入口保留后续手调，部分完成或自定义标记拒绝覆盖。首次写入前完成整批计划与边界检查，写入失败还原原网格和 meta。

## 验证入口

`GrasslandShrubStoneVerification.BakeAndVerify` 在隔离工程验证原三角面、GUID、全部 UV、完整根部范围和法线方向；逐顶点保护未选择的花草／落叶，逐文件保护预制体、原地面／碰撞、道路、其他群系、生态和材质。覆盖自定义元数据拒绝，以及后续人工编辑在重复入口、旧入口和普通 Setup 后保持。

隔离工程的 `Assets/Editor/ShrubStoneBaseline` 保存修改前网格，仅用于同帧对照，不发布。`After` 使用真实 Packed AA，核对打包顶点、颜色和法线，输出白天、黄昏和雨天的默认镜头与近景对照；临时切换原网格取景后立即恢复，不改正式资源或存档。实际建设测试优先选择已细化的石块／灌木根部，检查整组 GPU 遮盖、旧建设重绑和回收恢复，并接续原行走、生态、室内、睡觉／继续、返回及 AA 释放流程。

截图和日志位于忽略目录 `Logs/GrasslandShrubStone`。正式工程同步后执行 **Magic Island > Build Prototype Addressables**。前序说明见 [树丛与花坡](GrasslandGroves.md)、[草原地表层次](GrasslandGroundLayers.md)。

## 本轮资源验收

细化 195 组可识别完整小景，共 390 块石头、1,365 个叶团及 610,995 个选中顶点。25 份原候选网格保留各自 GUID，其中 11 份更新顶点／法线／配色，其余保留原几何并记录已完成检查；原花草、低草和未识别组合保持。预制体 2,878 条记录字节一致，地表批次仍为 54，没有新增材质或美术资产。

`Bake.log` 退出码 0，通过原面／GUID、完整 UV0–7、原根部及范围、有效法线方向、未选择花草／落叶、完整预制体、原地面与碰撞、其他群系／生态／材质保护，以及自定义元数据拒绝和后续手调／重复 Setup。修改前夹具只存在隔离工程，未发布。

最终 `PackedFinal.log` 退出码 0。实际 AA 顶点、法线和颜色核对通过，默认镜头及近景白天／黄昏／雨天检查完成。建设夹具进一步按新叶团配色筛选实际细化过的根部，避免只凭整份合并网格标记选到未改形部分；实际提交、整组 GPU 遮盖、旧建设重绑和回收恢复通过。原 6,936 步行走、四兔／六处昆虫、风场与暂停、室内隐藏、床边睡觉、五岛位置继续、无效旧位置／备份、返回及 AA 清理继续通过，没有白天写盘。

发布审计同步 36 份原网格／meta，正式工程与最终隔离资源逐字节一致，2,213 个 GUID 无重复；完整预制体和 AA Profile 原有修改保留，最终源码一致。对照图上排修改前、下排修改后，分别展示路边组合、花草间小景和默认镜头。日志、截图及原网格夹具不入库。

本轮未构建独立 Player、未测量 GPU 性能，未重跑四季专项或全历史存档迁移矩阵；没有新增进度字段或改变保存时机。正式工程仍需重新 Build Prototype Addressables，更新本工程自己的内容包。
