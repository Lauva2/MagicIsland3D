# 体力与劳动

`StaminaManager` 管理运行时体力，`StaminaState` 为纯 C# 状态。GameManager 初始化、恢复、跨日回满和清理；FarmManager 将状态和配置传给 FarmActions，统一协调农田、背包和体力变化。

默认最大体力 100，耕地消耗 3、播种 1、浇水 2、收获 0。`GameConfig` 中的 `MaxStamina`、`HoeStaminaCost`、`SeedStaminaCost`、`WaterStaminaCost`、`HarvestStaminaCost` 可调整数值。上限必须为正，消耗不得为负；允许消耗为 0。

所有操作先校验农田、种子、容量和体力，成功才扣除。重复耕地、重复浇水、无种子、满背包、体力不足均不改变体力。背包事件发出时，农田与体力已提交，避免 UI 看见半完成状态；事件内重复调用农务会被拒绝。

体力不足时提示到床边休息，移动、开背包、交易和睡觉仍然可用。默认收获免费，零体力也能收获有容量的成熟作物。体力不随时间恢复，不强制昏倒。

HUD 在 `FarmHudPanel` 中显示当前／最大体力和体力条；剩余不超过 20% 时使用暖橙色。UI 通过 Model/Controller/View 更新，事件绑定随面板释放而解除。

确认睡觉和调试“下一天”入口执行相同结算，体力回满后自动保存。当前存档版本 11 保存当前体力，读取时校验是否处于配置上限以内。版本 1–3 迁移时补满配置中的体力，保留原有进度；版本 4–9 不会在读档时回满。如果降低上限导致旧体力超出范围，则拒绝该存档，沿用现有配置兼容校验规则。

验证：`Tools/VerifyStamina.cs` 覆盖成功消耗、失败原子性、零体力、免费收获、回满、配置消耗和事件内重复操作；`Tools/VerifySave.cs` 覆盖体力快照、非法范围与旧版本迁移；Unity 完整流程检查 HUD 即时更新、零体力交易、读档后保持当前体力和睡觉恢复保存。
