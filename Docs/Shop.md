# 商店与金币

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

商店另有“养殖用品”入口，切换到 AnimalShopPanel，购买鸡与饲料、出售鸡蛋。默认鸡 50 金币 / 只、饲料 10 / 份、鸡蛋收购 25 / 枚；价格来自 AnimalConfig，交易与养殖 / 库存一起保存。原有作物和鱼类交易保留，见 [鸡舍养殖](Animals.md)。

`EconomyManager` 管理金币，`ShopManager` 管理 AA 摊位实例、商品及交易；`GameManager` 负责初始化、弹窗、输入启停及存档。内部规则 `EconomyState`、`ShopTransactions` 可独立于 Unity 验证。

## 第一版玩法

- 新增苹果树、橙子树两个选项，分别购买树苗 / 出售对应水果，价格为 150 / 40、180 / 50。果树不使用作物季节提示，库存区提示背包摆放与睡觉成长；规则见 [果树](Orchard.md)。
- 顶部共十三项，采用每排五列的三排布局，第三排收购扇贝壳、漂流木和海玻璃，价格分别为 18 / 8 / 25 金币。海滩采集物只收购，不出售，不触发出售作物任务；见 [海滩拾取](BeachForaging.md)。
- 初始金币为 100，由 GameConfig.InitialGold 配置。
- 商店提供芜菁、番茄、玉米三个品种，顶部按钮切换商品；种子购买价分别为 10／20／30，作物出售价格为 25／50／85。价格配置在 ItemCatalog 的 BuyPrice / SellPrice，商品映射来自 CropCatalog；购买种子和出售作物的价格必须大于 0，未使用的方向配置为 0。详见 [作物系统](Crops.md)。
- 顶部另有沙丁鱼、鲈鱼两个选项，收购价 35／65；鱼类只收购，购买按钮禁用。售鱼不触发出售作物的新手任务。详见 [钓鱼](Fishing.md)。
- 商店是农田东南侧带浅绿和奶油白条纹棚布的木质摊位，经 ShopManager 使用 AA 地址 `IslandShop` 加载，地址由 GameConfig.ShopPrefabAddress 配置。靠近至操作范围内，鼠标点击柜台打开商店；每次按钮交易 1 个物品。美术与资源生命周期见 [商店与生产设施美术](FacilityArt.md)。
- 打开商店关闭背包，并暂停角色、镜头及工具输入；关闭按钮或 Esc 恢复。店内暂不提供批量购买或营业时间。
- HUD 显示金币。商店显示余额、价格及库存，不能交易时禁用相应按钮。
- 种子全年出售，库存下方显示当前商品的适宜播种季节和当季是否适宜；非当季购买仍正常。实际播种由 FarmManager 检查季节，见 [日期与季节](CalendarAndSeasons.md)。

## 交易与保存

购买先检查金币和背包容量，出售先检查物品数量及金币溢出。失败不扣金币、不增减物品，也不发送成功变化事件。成功交易后观察者读取到一致的金币与库存；重入交易被拒绝。

金币随农田、背包、角色位置一起在睡觉结算后保存。白天买卖和返回菜单不写进度，睡觉写盘失败在日报重试同一快照。当前存档版本 29，沿用原有交易字段，旧档不赠送鱼或金币。

## UI 与验证

`Assets/Art/Prefabs/UI/ShopPanel.prefab` 使用 TMP 中文、奶油白和暖沙色，按 MVC 实现，经 UIManager 使用地址 `ShopPanel` 加载到 PopUp 层。

`Tools/VerifyShop.cs` 验证购买、出售、满背包、金币不足、缺少物品、溢出和重入；`Tools/VerifySave.cs` 验证金币校验及旧存档迁移。Unity 的 FacilityArtFlowVerification 验证实际 AA 摊位与面板、柜台鼠标射线、距离限制、买卖按钮、睡觉保存与重新加载，以及实例释放和取消加载。
