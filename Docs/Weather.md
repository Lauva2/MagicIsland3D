# 昼夜与天气

WeatherManager 控制当天晴雨、昼夜光照、雨滴表现和雨水浇灌；GameManager 统一初始化、读档、跨日和清理。ConfigurationManager 通过 AA 地址 `WeatherConfig` 加载 `Assets/Config/WeatherConfig.asset`，雨滴材质作为配置依赖随 AA 加载。季节与降雨概率由 AA 配置 `SeasonConfig` 和 CalendarManager 提供。当前使用程序生成的粒子雨滴，尚未接入雨声音效或室内区域。

## 每日天气与农田

新游戏第一天固定晴天。每次睡觉或点击调试“下一天”，先按当天浇水状态结算作物，再按目标日期的季节推进天气，回到 06:00 并自动保存。默认春／夏／秋／冬降雨概率为 30%／20%／40%／15%，在 SeasonConfig 中调整。WeatherConfig.RainChance 保留给没有 CalendarManager 的独立天气初始化使用，正常游戏采用季节概率。

雨天全部已种植的露天农田自动浇水，包括雨中新播种的作物；空地和仅耕地的地块不会浇水。雨水不消耗体力、种子或金币，不直接增加生长进度。跨日最多成长一次，成熟后不继续累积。次日晴天时浇水状态正常清除，次日仍下雨时立即重新浇水。

天气结果由新游戏生成的 WeatherSeed、目标日期和配置概率确定，独立于 Unity 的随机序列。当天结果与种子写入存档，读档恢复当天结果；在配置相同的前提下，未来天气序列保持一致。调整季节概率会影响未来跨日生成的天气，不会重新抽取存档中当天的天气。季节与日期说明见 [日期、季节与播种](CalendarAndSeasons.md)。

## 光照与表现

TimeManager 的游戏分钟决定阳光强度、颜色、方向、环境光和相机天空背景。默认 05:00 开始天亮，08:00 达到日间光照，17:00 开始变暗，20:00 进入夜间；黎明和傍晚平滑过渡并带暖色阳光。夜间保留蓝色环境光和较弱方向光，方便操作。雨天降低阳光并使用灰蓝色天空。

WeatherConfig 中可调整四个时刻、日夜强度、环境／阳光／天空颜色、雨天光照倍率和雨滴数量。时刻需严格递增且处于一天之内，夜间强度为正，雨天倍率大于 0 且不超过 1；配置无效时停止启动。编辑器只创建缺失的资源，不覆盖已有调整。

背包、商店和睡觉弹窗暂停时钟及雨滴运动；关闭后恢复。HUD 的 WeatherText 位于 `FarmHudPanel.prefab`，由 FarmHudModel / FarmHudController / PrototypeHud 显示中文“晴天”或“雨天”。面板继续使用 AA 同名地址和 Common 层。离开场景后清理雨滴、场景引用和天气状态；在原场景内清理时恢复原有光照。

## 存档与验证

当前存档版本 11 保存 WeatherSeed 和当天 Weather。版本 1–5 沿用原有迁移规则，再补固定种子 1 与晴天；版本 5 原有的混种农田、当前种子、金币、时刻和体力保持不变。非法天气枚举或非正种子拒绝恢复。读档雨天只补浇水，不增加生长进度或赠送种子。

- `Tools/VerifyWeather.cs`：94 项断言，检查概率边界、天气序列恢复、非法数据、光照边界和平滑过渡、雨水幂等、跨日成长、存档快照和版本 5 迁移。
- `WeatherFlowVerification.Run`：独立 Unity 工程中构建并加载 AA，检查实际昼夜光照、晴雨 HUD、雨滴暂停／恢复／清理、雨天农务、雨转晴、自动保存、继续游戏、非法存档拒绝和旧存档迁移，输出三种场景预览。
- `GameFlowVerification.Run`：保留原有主菜单、背包、商店、体力、工具、多作物和存档流程检查；验证时固定晴天，使手动浇水断言不受随机天气影响。
