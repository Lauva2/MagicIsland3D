# 草原群系收尾

2026-10-18。接续 [草原主路景观组合](GrasslandComposition.md)，处理草原腹地、南侧支路与西侧湖岸入口，完成本轮草原美术。显式入口为 **Magic Island > Art > Finish Grassland Biome (Explicit)**。普通 Setup 不执行，其他群系的既有精修保留。

后续蝴蝶、萤火虫与原花草风动见 [GrasslandEcology.md](GrasslandEcology.md)；本文件记录静态草原收尾的范围与验证。

## 地表、树冠与疏密

地表以连续、低频的嫩绿／黄绿草色变化分出向阳草甸、林下绿地和近湖湿润地带；仅修改原 Land 网格顶点颜色，不改高度、法线、索引、草色权重或材质。范围在海岸、湖边、群系入口及魔法地标附近渐退，原沙漠／雪地入口与林缘精修不重涂。

原位绿色树冠按完整连通球面筛选，调整高宽比例和上下叶色，水平轮廓只收窄；不移动树干、根位置或实体碰撞。上一轮 UV6 标记选中的树冠保持。草原保留开阔草甸及建设空地，不向腹地塞入新的实体树木。

主路原 Route verge 等距花草只在组合之间的空段筛疏，靠近上一轮景观组合和路标的花草保留。只移除完整、颜色和拓扑仍符合原生成模板的组件三角面；原花朵的花茎、五片花瓣及花芯虽然拓扑分离，仍以整株统一保留或移除，避免悬空花瓣。保留所有原顶点、法线、颜色、UV、边界、其余索引顺序与岩石。自定义颜色或无法识别的组件跳过。

南侧东行支路与西侧湖岸入口复用 `SourceArt/GrasslandComposition` 的 Blender 苔石／矮草／野花模板，沿既有不可建设路肩交错布置、变化朝向及组合。1.05 米完整方形脚印密集采样并检查所有相交建设格，避让上一轮景观，道路中心保留至少 3 米净空，逐顶点读取实际烘焙地面碰撞贴地。新增内容按 128 米分区合并在原 IslandTerrain AA 依赖内的 `Baked landscape / Grassland meadow finish`，复用 Biome Details 共享材质，无新碰撞、灯光、拾取物、运行脚本或逐件更新。

## 手调保护与资源边界

原网格 UV7（Unity `GetUVs(7)`，第八组、最后一组 UV）记录 `x=0/1` 未选中／已选中、`y=-744` 标记。原 UV0–6 保留；其他自定义 UV7 在写入前拒绝覆盖。标记只用于编辑器，Packed 内容可剥离。此后新增美术工具不能再占用额外的 Mesh UV 频道。

已有完整子树时整个操作跳过，保留手调网格和布置；没有子树却存在孤立同名资源时拒绝覆盖。原网格与预制体 GUID、所有地面几何、碰撞、路线、建设资格、其他群系和水域资源保留。整岛显式重建会重做基础大陆网格，本收尾操作不负责自动重做被整岛重建覆盖的内容。

没有新增配置、玩法、持久化字段或迁移，存档保持 v31。正式工程需要执行 **Magic Island > Build Prototype Addressables** 生成使用本轮资源的内容包。

## 验证入口

`GrasslandFinishVerification.BakeAndVerify` 仅在隔离工程运行，检查原地面／碰撞几何、UV0–6、树干与未选中顶点、上一轮树冠、完整组件筛疏、完整建设脚印、法线和三角面，以及原美术字节。还覆盖外部 UV7 拒绝、重复执行、普通 Setup 与手工改形／调色保留。

`OceanWaterAppearanceVerification.RunGrasslandFinishBaseline/RunGrasslandFinish` 使用实际 Packed AA、同机位与固定动画时间，记录清晨／白天／夜间／雨天的草原腹地、南部、东部支路、西侧湖岸、北部、路边近景和总览，并保留沙漠／林缘及原海洋／湖泊对照。运行时核对内容包资源，并用真实 CharacterController 实走原西侧主路和东行支路。`StarterIslandWorldFlowVerification.Run` 覆盖地图、通行、睡觉／读档、室内外切换与 AA 清理。结果输出在忽略的 `Logs/GrasslandFinish`。

用户现已授权按完整顺序实施并改善空旷感，本轮实现与验证入口见 [GrasslandRevitalization.md](GrasslandRevitalization.md)。以下保留此前方向说明。
