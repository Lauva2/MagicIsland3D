# 独立群系岛屿与编辑器传送

2026-10-19。当前实验布局改为五个独立岛屿：沙滩、草原、沙漠、林地、雪地。原生活区作为沙滩岛，农田、设施、码头和出生点保持原坐标；不生成通往大陆的栈道、大陆连续地面、大湖及河口木桥。原大型世界文档作为美术资源历史说明保留。

## 使用

1. 等待 Unity 编译，执行 `Magic Island > Build Prototype Addressables` 更新地形依赖。
2. 从 MainMenu 进入游戏，在室外关闭弹窗、结束工具动作或摆放。
3. 打开 `Magic Island > 测试工具窗口`，点击五个群系按钮之一。编辑模式、初始化、室内、弹窗加载/显示、动作、摆放、结算期间按钮禁用。

窗口参考 `Editor_AnalysisWindow` 的菜单与按钮组织，使用 Unity 内置 EditorWindow，不引入参考工程的 Odin 或业务依赖。窗口只调用 GameManager 的编辑器专用传送接口，不初始化系统、不直接移动角色、不提供存档、发物品或跨日功能；独立 Player 不包含此测试接口。

## 资源与范围

- `BiomeIslandLayout` 统一五岛范围、不规则岸线、高度、建设、地图、声音及测试落点。林地追加到现有 IslandBiome 枚举末尾，不重排旧值。海域没有隐形桥面，移动继续检查完整角色脚印。
- `IslandTerrain` 的同一 AA 地址和 GUID 保持。`StarterIslandWorld.ArtVersion=3` 表示群岛布局，地面分块烘焙在 `Assets/Art/Meshes/Terrain/BiomeIslands`。运行时不生成地形或植被。
- 现有大陆地表内陆高度用于四岛内部，岸边缓降至海平面；沿用共享材质和已完成的植被、花草、地标资源，筛选完整网格连通部件并保留全部原顶点频道。原生活区海洋生态不重排。
- 原完整地形预制体保存在 `Assets/Art/Prefabs/Environment/BiomeIslandSource.prefab`，作为未注册 AA 的美术源快照；原大陆网格与精修资产保留。活动地形不引用它，不实例化旧大陆或栈道。四处地标仍在原坐标。
- 沿用 OceanManager 的统一时钟管理保留下来的陆地生态。群岛没有旧大湖，WorldWaterEcology 的 ArtVersion=2 允许无湖面/鱼群的陆地表现；旧生态版本 1 的校验不放宽。原海洋鱼群、海床、珊瑚、海鸥和螃蟹继续由 IslandOcean 加载。
- `Rebuild Biome Islands (Explicit)` 只在首次切换时写入；已是版本 3 时保留人工编辑。首次写入前完成内存规划与引用校验，失败清理本次新建网格。普通 Setup 不执行此操作。旧 `StarterIslandWorldSetup.Rebuild` 入口转到新工具，旧大陆菜单停止提供。
- 后续草原精修要针对群岛资源设计工具；历史大陆局部精修工具不能当作群岛重建入口。

## 传送边界

GameManager 检查流程、所有模态加载、动作与事务。TerrainManager 在指定岛屿落点周围 12 米内检查真实地面、完整胶囊碰撞与岛屿身份；查询饱和按失败处理。失败不移动角色。成功清除交互目标/鼠标手势、移动惯性和镜头遮挡残留，复用 PlayerManager.RestorePosition 并立即对齐原镜头，再按整体流程恢复输入。无额外 Update、单例、场景或 AA 句柄。

## 存档影响

没有增加持久化字段、没有占用新版本号，仍只在床边确认睡觉保存。传送、开地图、白天操作和返回菜单不写进度。保留生活区以及仍在新岛范围内的旧坐标，加载时恢复实际地面高度。

本次检出的 `SaveData.CurrentVersion` 实际为 30，与 AGENTS.md 记录的 31 存在既有差异；本轮按当前实现验证，不占用 31，也不声称覆盖尚未检出的 v31 魔法探索字段或迁移。该差异需独立核对，不能仅修改版本常量冒充完成迁移。

这次缩小了旧大陆可用范围：旧档人物或建设若位于被移除的大陆/栈道，整份数据按现行位置/建设校验拒绝；不删除、挪动或部分恢复玩家记录，不改写原文件。有效备份仍按原规则尝试。需要恢复这种旧世界时应使用保留的旧版本工程和原档案，不能把源快照当作运行时自动兼容世界。新游戏在首次成功睡觉前仍不覆盖旧档。

## 验证入口

- `BiomeIslandsVerification.BakeAndVerify`：真实预制体、五岛地面、海峡隔离、旧桥移除、可见/碰撞网格一致、源资源保留、重复及普通 Setup 不覆盖。
- `BiomeIslandsVerification.Run`：在隔离工程中构建真实 Packed AA；五岛实际传送、完整障碍阻挡失败、弹窗加载/室内禁用、旧目标清理、地图、真实床边睡觉、五岛位置继续、返回重进、AA 释放及白天无写盘。
- 图片与日志写入忽略目录 `Logs/BiomeIslands`，不入库、不上传；验证结论以实际执行输出为准。

本轮实际结果：`BakeFinal.log` 及最终 `PackedFinal.log` 均成功退出。273 块地面、386 份群岛网格已随原 AA 地形依赖加载；五岛传送、阻挡失败、模态/室内禁用、地图中文字形、床边睡觉、五岛位置继续、旧角色/建筑整档拒绝、有效备份保留及 AA 释放均通过。发布审计核对 777 份美术文件与验证工程一致、2,100 个 GUID 无重复；原美术资源与原 AA Profile 的已有修改保留，源快照保留原预制体全部记录（仅根名随文件名改变）。仅清理 Unity 空 YAML 值的行尾空格，不改变序列化含义。本轮未构建独立 Player，未执行全部历史存档迁移矩阵或 GPU 性能测量。
