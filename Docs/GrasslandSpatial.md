# 草原样区空间层次与植物群落

接续样区配色收尾，仅调整原半径 24 米样区。以三片大小不同的宽缓分布区组织现有小景：奶白花前缘、柔黄花前缘与较远处浅丁香花前缘，灌木形成中层轮廓，外围草簇衔接，群落之间留低草空地。具体根部采用独立固定种子、随机偏移、空间噪声和实际资源筛选，不消耗玩法随机数；未推广至全岛或其他群系。

## 显式资源入口

`Magic Island > Art > Compose Grassland Spatial Sample (Explicit)`。首次完整预检和规划，后续重复执行保持手调；普通 Setup 不执行。

三片区域相对原样区中心布置，分别约为西侧偏北、东侧偏南和较远的西北侧。现有混合小景中只有原正权重灌木叶团局部抬高，水平位置与颜色不变，原石块和花保持；纯草在群落内略提高、外围降低，间隔空地按噪声筛去少量完整草根面。道路附近 3.65 米内的原纯草保持，样区边缘逐渐恢复原高度；旧草根及其顶点仍保留。

少量新灌木采用原七叶团模板中第 1／3／5 个完整叶团组成的轻量变体，改变比例和朝向形成较高的中层轮廓。新花带复用原 Blender 整枝模板，低草使用弯曲叶片；每个组合共用根部并追加到原两份 Meadow undergrowth 网格。完整静态水平半径不超过 1.16 米，沿原 1.30 米运动范围检查样区、道路净空、真实地面坡差、固定实体、其他非草景物和小兔路线；灌木／花／草组间距按大小区分。

保留原六份网格 GUID、索引格式、全部旧 UV0–7、根部、RGB／alpha、旧水平位置和剩余面顺序；只调整被选中旧草／叶团高度与法线，扩充保守 bounds，并追加新几何。原 UInt16 批次拒绝溢出，不通过升级格式、拆新批次或运行时生成绕过预算。蝴蝶实际停落 Foliage、动物数据、地色图、道路／Shader、预制体、碰撞、地形与建设资格保持。

新增几何随原 IslandTerrain AA 依赖加载，继续复用原材质、季节／风动／拨草与整根建设遮盖拥有者。没有新 Renderer、GameObject、材质、Update、配置或存档字段；保存点与存档版本不变。

## 中断与人工编辑保护

在原六份 importer 追加 `MagicIsland.GrasslandSpatial.v1`。写前备份六份网格和元数据，首份写入 `MagicIsland.GrasslandSpatial.Pending.v1`，资源完成后按顺序提交，首份最后完成。进行中、部分完成、未知元数据／UV／材质／模板或非原静态网格拒绝覆盖；异常还原原文件。完成后重复、前序入口和普通 Setup 保留后续人工编辑，不删除标记重新叠加。

## 验证与同步

`GrasslandSpatialVerification.BakeAndVerify` 只在隔离工程运行：精确计划与几何／法线／配色／全部旧频道核对，检查完整草根筛疏、旧 XZ／颜色／面顺序、新组合范围／道路净空、原索引格式；逐文件保护预制体、生态、材质和其他美术。覆盖自定义材质／元数据、进行中／部分完成拒绝，以及重复／前序入口／普通 Setup 保留手调。

`After` 接续真实 Packed AA 主菜单流程，核对实际资源，输出相同正常镜头白天／黄昏／雨天对照；沿原真实角色穿行录像检查视线和通行。建设夹具优先选本轮新组合，验证整根 GPU 遮盖、旧建设重绑与回收；继续通路、生态、拨草／暂停／清除、进屋、床边睡觉、五岛继续与 AA 清理，白天不得写盘。

夹具仅在隔离工程 `Assets/Editor/GrasslandSpatialBaseline`，日志／对照／视频／审计在忽略目录 `Logs/GrasslandSpatial`。同步后重新执行 **Build Prototype Addressables**，前往草原测试落点在正常镜头下确认；满意后再决定推广。

## 本轮烘焙和验收结果

隔离烘焙退出码 0：7 组原灌木局部提高，594 簇原草按群落内外调整高度，25 簇间隔散草整根筛疏。新增 6 组中层灌木、11 组单枝花带和 45 组衔接草簇，合计 62 个组合、11,646 个顶点；西侧／东侧／较远侧各有两组新灌木。原六份网格与元数据保留 GUID 和索引格式，UInt16 批次未溢出。原频道／XZ／配色／剩余面序与范围、其他美术保护、未知数据拒绝及重复／前序入口／普通 Setup 保留手调检查通过。

Packed AA 流程退出码 0。核对实际打包的顶点、法线、颜色、全部 UV 和面，检查正常镜头白天／黄昏／雨天对照；真实 CharacterController 穿行 100 帧，视频编码并解码核对为 4 秒／25 fps。原 6,936 步通路、四只小兔／六处昆虫栖息区、草叶 GPU 拨动／暂停／清除通过；建设优先使用本轮新增组合，完整根部遮盖、旧建设重绑和回收恢复通过。进屋、床边睡觉、五岛继续、非法落点拒绝、返回重进与 AA 清理通过，白天未写盘。

最终仅同步六份原网格及各自元数据，原预制体、地色图、AA Profile、材质、Shader、碰撞和其他美术逐文件保持。代码／依赖与隔离验证输入一致，资源 GUID 无重复。未单独构建 Player、测量 GPU 性能或重跑全历史存档迁移矩阵；样区效果仍由用户实景确认后再决定推广。
