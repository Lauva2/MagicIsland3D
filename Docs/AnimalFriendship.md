# 鸡的互动与亲密度

当前进度统一在每天睡觉结算后保存；白天操作仅修改运行状态，面板手动保存和返回菜单保存已取消，设置单独持久化。睡觉失败只重试该次固定快照。规则见 [暂停与睡觉存档](PauseAndSettings.md)。

鸡舍照料面板为每只鸡显示独立状态卡：名字、亲密度数值与进度条、关系阶段、今日喂食和摸摸状态。默认 ID 1 叫“小白”、ID 2 叫“团团”，名字来自 AA AnimalConfig，始终按稳定 ID 对应。

| 操作 / 阶段 | 默认规则 |
| --- | --- |
| 摸摸 | 每只鸡每天一次，亲密度 +5 |
| 喂食 | 每只鸡当天首次成功喂食，亲密度 +2 |
| 陌生 | 0–29 |
| 熟悉 | 30–69 |
| 亲近 | 70–100 |

亲密度上限 100，增加时截断到上限。满亲密度仍可每天摸摸一次并获得爱心反馈，实际增长为零时提示“亲密度已满”。每只鸡的互动日期分别记录；新买的鸡以零亲密度、未摸摸状态入住，已喂过的鸡不会因为补喂新鸡再次增加亲密度。

## 交互与反馈

走近鸡舍，点击打开 CoopPanel，再点击对应鸡的“摸摸”。当天已互动按钮显示“今天已摸摸”并禁用，空名额显示等待入住。办公室仍显示只读状态卡，不能在办公室或通过远距离、关闭的面板互动；即使办公室面板打开时把角色移到鸡舍，也不会切换为照料模式。

摸摸不扣饲料、金币或体力，不生成鸡蛋或推进农务任务。喂食必须完整扣除本次所有未喂鸡的饲料，成功后才给对应鸡增加亲密度；缺料、产物容量不足和重复喂食不增加。每日产蛋仍由统一跨日结算处理，亲密度与互动日期不会重复结算产物。

成功摸摸后，对应状态卡和鸡头上显示粉色爱心。面板使用 HeartGraphic 绘制图形，世界中使用 ChickenHeart 网格和材质，都不依赖字体中的爱心字符。世界爱心朝向相机、上浮并淡出，约 1.4 秒结束；面板模态暂停闲动时，反馈仍可播放并结束。读取存档不会重播瞬时效果。

## 框架与资源

- `AnimalState` 保存并校验每只鸡的 Affinity / LastPetDay，处理独立每日限制、喂食奖励、阶段和上限。查询与快照返回独立副本，拒绝无效恢复时不修改现有状态。
- `AnimalManager` 同步世界反馈并管理状态；`GameManager` 检查游戏状态、面板模式、距离和操作锁，统一保存和清理。通知回调中的重复摸摸、喂食、关闭、返回菜单和跨日请求被拦截。
- `CoopPanel` 继续通过 AA 加载到 PopUp 层，使用 MVC、中文 TMP、两条只读 Slider 和每只鸡的独立按钮。按钮不需要用户输入名字，名字和增长参数可以在 AnimalConfig 调整。
- `AnimalConfig` 新增 ChickenNames、PetAffinity 和 FeedAffinity。要求恰好两个不同非空名字、长度最多 12 且无控制字符，增长参数在 1–100。完整参数和已经调整的美术 / 布局保留，编辑器仅补缺失字段、组件和模型子节点。

## 存档

版本 22 在每条 SavedChicken 中新增 Affinity 和 LastPetDay，与原 Id / FedDay、待收鸡蛋、库存、金币和订单一起保存。亲密度必须为 0–100，互动日期必须为 0–当前日期，已互动记录需要正亲密度；未知鸡 ID、重复 ID、未来日期等拒绝加载，并沿用有效备份恢复。

版本 21 及以前为已有鸡补零亲密度和未互动日期，保留既有喂食日期、产物、库存、金币、已完成订单与当天订单池，不按历史照料补发亲密度。已喂鸡当天不能再获得喂食奖励，但可以使用新加入的摸摸互动。当前版本再次升级不会清空已获得的亲密度或互动日期。

摸摸和喂食成功后更新运行状态，睡觉时统一保存，失败保留完整运行结果，并通过照料面板“保存进度”重试，不再增加亲密度。读档保留每只鸡的当天限制；新游戏创建空养殖状态，退出释放模型、效果和面板引用。

## 验证

`Tools/VerifyAnimalFriendship.cs` 覆盖 0–100 边界、每只鸡的独立喂食和摸摸、新买鸡只给自身喂食奖励、阶段边界、满亲密度互动、缺料 / 蛋容量不奖励、通知与重入、无效恢复原子性、快照独立、v20 / v21 迁移及连续每日照料。

`AnimalFriendshipFlowVerification.Run` 在隔离 Unity 工程构建 AA，验证名字 / 参数、模型和图形爱心、真实买鸡 / 喂食 / 摸摸按钮、两张状态卡与实际 Canvas 网格、距离 / 办公室 / 模态限制、原子通知与保存失败重试、独立阶段和上限、缺新字段的 v21 迁移、已完成扩展池订单保留、异常存档拒绝、读档限制、瞬时效果释放和新游戏。

版本 23 起，亲密度达到 70 且已喂食的鸡次日有 25% 概率产优质鸡蛋。仍每只一枚，按结算时亲密度决定资格。版本 22 已有亲密度和当日互动记录保留，见 [优质鸡蛋](QualityEggs.md)。
