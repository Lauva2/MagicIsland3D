# 草原样区小景与草甸衔接

后续小径边缘的断续草土过渡见 [草原路肩样区](GrasslandPathEdge.md)，保留本轮小景。

接续 [野花组合](GrasslandWildflower.md)，仍只处理原拨草样区。当前样区以开阔花草为主，缺少灌木层，因此补少量矮灌木、半埋苔石和低草小组，保留已有石块、花草落点、蝴蝶停落资源和树木。没有扩展到整个草原或其他群系。

## 显式资源入口

**Magic Island > Art > Refine Grassland Edge Sample (Explicit)**。普通 Setup 不执行。使用独立固定种子，从真实草簇密度、空间噪声和安全范围选择少量位置，组间至少 5.5 米，保留开阔空隙；材质、颜色和模型沿用原美术体系。复用原灌木及 Blender 石块／整枝花模板，灌木整体尺寸、高低与朝向错开，苔石略埋地，石边搭配贴地草和少量奶白小花。

完整静态水平半径不超过 1.16 米，沿原 1.30 米运动包络检查道路、实际地面高差、实体、其他非草景物和小兔路线。新增部分只追加到原两份 `Meadow undergrowth` 网格，同组灌木、石块、草与花共用根部；沿原 AA、共享 Meadow Flora 材质及季节／风动／拨草／建设整组遮盖拥有者。没有新对象、Renderer、材质、碰撞、Update 或进度字段。

小景中心筛疏完整原草簇的面，保留全部旧顶点；周边草高平滑降低，保留原 XZ、颜色、根部、UV0–7 和其余面顺序。树下规则读取原树冠遮挡组件的实际锚点，只有树冠邻近样区时才局部筛疏；本轮样区没有树下落点，不额外加树或扩大范围。原花朵、石块、未选中草叶、地色图、地形／碰撞、建设资格、预制体、动物和其他岛保持。

在原六份样区 mesh importer 追加 `MagicIsland.GrasslandEdge.v1`。首次先完整规划并备份，首份资源写入 `MagicIsland.GrasslandEdge.Pending.v1` 后才写网格，其余完成标记写入后最后提交首份；部分完成、进行中标记、未知元数据／材质／频道拒绝覆盖，写入异常还原资源。全部完成后重复入口、前序入口和普通 Setup 保留合法手调。原 GUID、索引格式和频道不变。

## 验证与交接

`GrasslandEdgeVerification.BakeAndVerify` 在隔离工程检查计划与实际网格、整簇筛疏、原剩余面序、旧顶点／UV 前缀、原草 XZ／颜色、原花石／样区外保护、完整新组合范围及道路净空；逐文件保护地形、碰撞、预制体、蝴蝶落点、材质与其他美术。覆盖自定义材质／元数据、进行中／部分标记拒绝，以及手工调色后重复、前序入口和普通 Setup 保留。

`After` 构建真正 Packed AA，核对打包后的几何、法线、颜色与 UV，输出相同正常游玩镜头下白天／黄昏／雨天对照。建设夹具优先选择本轮新增的完整小景根部，接续真实摆放、整组 GPU 遮盖、旧建设重绑和回收，以及拨草、暂停、通路、生态、室内、床边睡觉、五岛继续和 AA 清理。比较夹具仅在隔离工程的 `Assets/Editor/GrasslandEdgeBaseline`，日志与截图在忽略目录 `Logs/GrasslandEdge`，均不发布。

## 本轮资源结果

烘焙 7 组小景，其中 5 组搭配单枝小花；筛去中心重叠的 5 簇原草面，周边 58 簇草降低高度，新增 22,460 个顶点。矮灌木按正常游玩镜头复核后提高到约半米至七十多厘米，宽度随组变化；组合数量、原落点、安全包络及道路净空保持。更新原六份网格及各自元数据，原 GUID、预制体、地色图、材质、碰撞及动物落点保持。

最终尺寸的隔离烘焙验证通过，覆盖原资源保护、自定义／进行中／部分标记拒绝和重复／前序入口／普通 Setup 保留手调。没有增加配置或进度字段，保存时机不变。未单独构建 Player、测量 GPU 性能或执行全历史存档迁移矩阵。

最终尺寸的 Packed AA 流程退出码 0，实际几何／法线／UV／配色与编辑器烘焙资源一致。完成正常镜头下白天／黄昏／雨天同帧对照；原 6,936 步道路实走、草叶 GPU 拨动／暂停／清除、小兔和昆虫检查通过。建设验证使用本轮追加的真实小景根部，摆放、整组 GPU 遮盖、旧建设重绑与回收恢复通过；进屋、床边睡觉至第二日、五岛继续、模态／非法落点拒绝、返回重进及 AA 清理通过，白天未写盘。截图左侧修改前、右侧修改后。

同步后执行 **Build Prototype Addressables**，前往草原测试落点查看样区。仍须用户确认样区后再决定推广。
